前置知识：1.2 节的三个典型方程、多元微分的变量代换与链式法则。

1.4 二阶线性方程的分类

  前几节推出的三个方程：波动、热传导、拉普拉斯，形式各异，但都是二阶线性。这一节要表明：它们之间的差别有一个统一的判别准则，而且这个判别直接决定了数值解法怎么设计。

1.4.1 一般形式

  两个自变量的二阶半线性方程（主部线性，低阶项可含未知函数）：

$$A u_{xx} + 2B u_{xy} + C u_{yy} + D u_x + E u_y + F u = G \tag{1.4.1}$$

  其中 $A,B,C,D,E,F,G$ 是 $(x,y)$ 的函数。

为什么中间项系数写 $2B$ 而不是 $B$？这是为了后面配完全平方时式子整齐。如果写成 $B$，判别式会变成 $B^2-4AC$，多出系数，容易出错。教材普遍采用 $2B$ 的写法。

  三个典型方程的主部系数：

方程 $A$ $B$ $C$ $B^2-AC$
波动 $u_{tt}=a^2u_{xx}$，即 $u_{tt}-a^2u_{xx}=0$ $-a^2$ $0$ $1$ $a^2>0$
热传导 $u_t=a^2u_{xx}$，即 $u_t-a^2u_{xx}=0$ $-a^2$ $0$ $0$ $0$
拉普拉斯 $u_{xx}+u_{yy}=0$ $1$ $0$ $1$ $-1<0$

  （热传导方程把 $t$ 当作 $y$。）

  马上看出规律：三种情形对应 $\Delta = B^2-AC$ 的正、零、负。

1.4.2 判别准则与特征方程

  定义：在点 $(x,y)$ 处，按 $\Delta = B^2-AC$ 的符号分类

判别式 类型
$B^2-AC > 0$ 双曲型
$B^2-AC = 0$ 抛物型
$B^2-AC < 0$ 椭圆型

  当 $A,B,C$ 是变系数的函数时，方程在不同区域可能是不同类型——称为混合型方程。最著名的例子是特里科米（Tricomi）方程：

$$u_{xx} + y u_{yy} = 0 \tag{1.4.2}$$

  $A=1$，$B=0$，$C=y$，$\Delta = -y$：

  • $y<0$：双曲型（亚声速区）
  • $y=0$：抛物型（声速线）
  • $y>0$：椭圆型（超声速区）

  这个方程在空气动力学里描述跨声速流动——从亚声速到超声速的过渡。

特征方程

  特征方程定义为

$$A,dy^2 - 2B,dx,dy + C,dx^2 = 0 \tag{1.4.3}$$

  或等价地（把 $dy/dx$ 视为未知）：

$$A\left(\frac{dy}{dx}\right)^2 - 2B\frac{dy}{dx} + C = 0 \tag{1.4.4}$$

  它的根给出特征方向：

$$\frac{dy}{dx} = \frac{B \pm \sqrt{B^2-AC}}{A} \tag{1.4.5}$$

  分类与特征根的关系一目了然：

类型 特征根 特征线
双曲型 两个相异实根 两族实特征线
抛物型 一个重根 一族实特征线
椭圆型 一对共轭复根 无实特征线

"特征线"的物理意义：它是扰动传播的路径。

  • 波动方程有两条实特征线 $x\pm at=\text{const}$，正对应波向左右传播——这就是达朗贝尔公式里 $f(x-at)$ 和 $f(x+at)$ 的来源；
  • 热传导只有一族特征线 $x=\text{const}$（垂直于 $t$ 轴），所以扰动沿空间瞬时传播，没有"波前"；
  • 拉普拉斯方程没有实特征线，因此不存在"沿某方向传播"的概念——它是静态的。

1.4.3 化标准型

  引入新自变量

$$\xi = \xi(x,y), \qquad \eta = \eta(x,y)$$

  由链式法则，二阶导数变换为

$$u_{xx} = u_{\xi\xi}\xi_x^2 + 2u_{\xi\eta}\xi_x\eta_x + u_{\eta\eta}\eta_x^2 + \cdots$$

  （省略含一阶导的项。）代入 (1.4.1)，新的主部系数为

$$\bar A = A\xi_x^2 + 2B\xi_x\xi_y + C\xi_y^2$$
$$\bar B = A\xi_x\eta_x + B(\xi_x\eta_y+\xi_y\eta_x) + C\xi_y\eta_y$$
$$\bar C = A\eta_x^2 + 2B\eta_x\eta_y + C\eta_y^2$$

  关键观察：

$$\bar B^2 - \bar A\bar C = (B^2-AC)(\xi_x\eta_y - \xi_y\eta_x)^2 \tag{1.4.6}$$

  由于雅可比行列式 $J = \xi_x\eta_y-\xi_y\eta_x \ne 0$（变换可逆），$\Delta$ 的符号在可逆变换下不变。

  这就是分类的坐标不变性：方程的"型"是内在的，不因换坐标而改变。所以我们可以选合适的坐标把它化成最简形式。

  化标准型的目标：取 $\xi,\eta$ 使 $\bar A = \bar C = 0$（双曲/抛物）或 $\bar A = \bar C$、$\bar B=0$（椭圆）。

双曲型：两族实特征线

  取 $\xi,\eta$ 分别为两个一阶方程的解：

$$\xi(x,y) = \text{const} \text{ 满足 } \frac{dy}{dx} = \frac{B+\sqrt{B^2-AC}}{A}$$
$$\eta(x,y) = \text{const} \text{ 满足 } \frac{dy}{dx} = \frac{B-\sqrt{B^2-AC}}{A}$$

  则 $\bar A = \bar C = 0$，方程化为

$$u_{\xi\eta} + \text{(低阶项)} = 0 \tag{1.4.7}$$

  这就是第一标准型。再令 $\alpha = \xi+\eta$，$\beta = \xi-\eta$，得第二标准型：

$$u_{\alpha\alpha} - u_{\beta\beta} + \text{(低阶项)} = 0 \tag{1.4.8}$$

  例：波动方程 $u_{tt}-a^2u_{xx}=0$。把 $t$ 记作 $y$，则 $A=-a^2,B=0,C=1$：

$$\frac{dy}{dx} = \frac{0\pm\sqrt{a^2}}{-a^2} = \mp\frac{1}{a}$$

  即 $y\mp x/a=\text{const}$，也就是 $x\mp at=\text{const}$。取 $\xi = x-at$，$\eta = x+at$，得到

$$u_{\xi\eta}=0 ;\Longrightarrow; u = f(\xi)+g(\eta) = f(x-at)+g(x+at)$$

  这正是达朗贝尔公式的通解形式。特征线变换直接把波动方程变成了"两边可分离"的形式。

抛物型：一族特征线

  取 $\xi$ 满足单特征方程，$\eta$ 任取与 $\xi$ 独立的函数。则 $\bar A=0$，且由 $\bar B^2-\bar A\bar C = 0$ 得 $\bar B=0$，标准型为

$$u_{\eta\eta} + \text{(低阶项)} = 0 \tag{1.4.9}$$

  例：热传导方程 $u_t-a^2u_{xx}=0$。特征方程给出 $\frac{dt}{dx}=0$，即特征线是 $t=\text{const}$（水平线）。取 $\xi=t$，$\eta=x$，方程本身就是标准型。

椭圆型：无实特征线

  特征根是复数，取 $\xi,\eta$ 为复特征方程解的实部与虚部。得到

$$u_{\xi\xi} + u_{\eta\eta} + \text{(低阶项)} = 0 \tag{1.4.10}$$

  例：拉普拉斯方程本身就是标准型——这解释了为什么它叫"标准"。

1.4.4 分类的意义：为什么这么重要

  分类不只是数学上的整理，它决定了：

定解条件的形式

类型 初始条件 边界条件
双曲 必须 有无皆可
抛物 必须 必须
椭圆 不能有 必须

  1.3.4 的 Hadamard 反例就是"给椭圆型方程加初值"的必然失败。

解的性质

类型 光滑性 依赖域 可逆性
双曲 保留初始正则性 有限（锥内） 可逆
抛物 瞬时无限光滑 无限 不可逆
椭圆 无穷光滑（解析） 全边界 无时间概念

数值方法的约束（这是最实际的一条）

  在后面的数值解系列里，分类直接决定算法：

类型 显式格式的要求 典型方法
双曲 CFL 条件 $\dfrac{a\Delta t}{\Delta x}\le1$ 特征线法、Lax-Wendroff、迎风格式
抛物 显式格式要求 $\dfrac{a\Delta t}{\Delta x^2}\le\dfrac12$（非常苛刻） Crank-Nicolson、隐格式
椭圆 无时间推进，必须解线性方程组 迭代法（Jacobi/SOR）、共轭梯度、多重网格

  为什么椭圆型不能做时间步进？因为它没有时间变量。如果你硬把 $y$ 当时间做推进，就回到了 Hadamard 反例——数值上表现为误差指数增长，完全算不出来。

  为什么抛物型的显式格式条件苛刻？$\Delta t \sim \Delta x^2$——网格加密一倍，时间步必须缩小到四分之一。这就是为什么热传导方程通常用隐格式（无条件稳定）。

  为什么双曲型受 CFL 约束？信息以速度 $a$ 传播，时间步内走的路程 $a\Delta t$ 不能超过一个网格 $\Delta x$，否则数值依赖域覆盖不到真实依赖域。

易错点

  1. 判别式是 $B^2-AC$ 而不是 $B^2-4AC$——因为主部写成 $2B$；
  2. $A=0$ 时特征方程的写法：$\frac{dy}{dx}=\frac{B\pm\sqrt{B^2-AC}}{A}$ 在 $A=0$ 时要特别处理（此时应解 $dx/dy$ 的方程）；
  3. 变系数方程的"型"是逐点的，混合型方程在不同区域是不同的类型；
  4. 化标准型不改变方程的本质，(1.4.6) 保证 $\Delta$ 符号不变。如果有人算出"换了坐标变成另一种型"，那是算错了；
  5. 椭圆型不是"没有特征线"，而是"没有实特征线"——复特征线存在，只是物理上无意义。
