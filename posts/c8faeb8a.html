前置知识：5.1 节（变分原理与弱形式）。Sobolev 空间的细节（5.2、5.3）本节不需要，先跳过也完全能读。

一句话概括这一节

  5.1 节得到了弱形式：

$$\int_\Omega\left(\nabla u\cdot\nabla v+quv\right)dx = \int_\Omega fv\quad dx \qquad\text{对所有 } v\in V \tag{5.4.1}$$

  但这一式既不能直接用，也不能直接算。 因为 $v$ 有无穷多个，$u$ 属于无限维空间。

  这一节要解决的问题是：如何把无限维的问题变成一个有限的线性方程组 $A\mathbf{u}=\mathbf{b}$？

  两条路：

路径 出发点 直觉
Ritz 法 极小化能量泛函 $J(u)$ 在候选函数里找"最省力"的那个
Galerkin 法 让残差与测试空间正交 保证"每个方向上都算平衡"

  下面看它们如何导向同一个方程。

5.4.1 Ritz 法：找一个"最省力"的近似

直观：像用弹簧连接重物

  回忆 5.1 节的能量泛函：

$$J(u) = \frac12\int_\Omega\left(|\nabla u|^2+qu^2\right)dx - \int_\Omega fu\quad dx \tag{5.4.2}$$

  它就是一个"总能量"：

  • $\frac12\int|\nabla u|^2$：应变能（变形越剧烈能量越大）
  • $\frac12\int qu^2$：地基弹性能
  • $-\int fu$：外力做的功（力越大、位移越大，功越多，总能量越低）

  物理事实：系统会停在这个能量的最低点（平衡态）。

  Ritz 法就是模仿这个过程：不再对所有可能的 $u$ 求极小（做不到），而是在一个有限的候选集里找最小的。

怎么把"无限"变"有限"

  取一族基函数 $\phi_1,\phi_2,\dots,\phi_N$（自己选，这是关键），令

$$u_N = \sum_{j=1}^N c_j\phi_j \tag{5.4.3}$$

  于是 $J(u_N)$ 变成了关于系数 $c_1,\dots,c_N$ 的普通多元函数。求极小就是求偏导为零：

$$\frac{\partial J}{\partial c_i} = 0, \qquad i=1,\dots,N \tag{5.4.4}$$

  把 (5.4.2) 代入并求导（$c_j$ 线性出现，求导很直接）：

$$\sum_{j=1}^N c_j\int_\Omega\left(\nabla\phi_j\cdot\nabla\phi_i+q\phi_j\phi_i\right)dx = \int_\Omega f\phi_i\quad dx \tag{5.4.5}$$

  这就是一个线性方程组！

$$A_{ij} = \int_\Omega\left(\nabla\phi_j\cdot\nabla\phi_i+q\phi_j\phi_i\right)dx, \qquad b_i = \int_\Omega f\phi_i\quad dx \tag{5.4.6}$$

Ritz 法的三步：

  1. 选基函数 $\phi_1,\dots,\phi_N$
  2. 算矩阵 $A_{ij}$ 与右端 $b_i$（积分）
  3. 解方程组 $A\mathbf{c}=\mathbf{b}$

第 1 步是整个方法的核心——选得好坏直接决定精度与计算量。有限元（5.6、5.7）就是"选分片多项式"这一特例。

5.4.2 Galerkin 法：让残差"往每个方向投影都为零"

直观：调琴

  设想你在调一架钢琴。听不出整体对不对，但可以逐个方向检查：

  • 从左敲一下，看这一部分是不是平衡的
  • 从右敲一下，再看

  Galerkin 法就是这件事：把近似解代回原方程，得到一个"残差"，要求它在每个测试方向上都为零。

具体做法

  设近似解 $u_N = \sum c_j\phi_j$，代回弱形式，定义残差：

$$r(v) = \int_\Omega\left(\nabla u_N\cdot\nabla v+qu_Nv\right)dx - \int_\Omega fv\quad dx \tag{5.4.7}$$

  若 $u_N$ 是真解，则 $r(v)=0$ 对所有 $v$。

  但 $u_N$ 不是真解，不可能对无穷多 $v$ 都为零。退一步——只要求对基函数为零：

$$r(\phi_i)=0, \qquad i=1,\dots,N \tag{5.4.8}$$

  写开：

$$\sum_{j=1}^N c_j\int_\Omega\left(\nabla\phi_j\cdot\nabla\phi_i+q\phi_j\phi_i\right)dx = \int_\Omega f\phi_i\quad dx \tag{5.4.9}$$

  与 Ritz 法得到的 (5.4.5) 一模一样。

两条完全不同的思路，得到同一个方程——这不是巧合。

原因：

  • Ritz 法要求 $\frac{d}{dc_i}J=0$
  • Galerkin 法要求 $r(\phi_i)=0$

而这两件事在对称问题上等价，因为 $J$ 的导数恰好就是残差。

这给了我们两个"入口"：

Ritz Galerkin
需要泛函 需要 不需要
适用面 只对对称问题 对称、非对称都行
直觉 物理（最小能量） 代数（残差正交）

所以工程上默认用 Galerkin——它不依赖"存在一个能量泛函"这个前提。

5.4.3 两者何时等价

等价的条件

  若 $a(u,v)$ 对称（即 $a(u,v)=a(v,u)$），则 Ritz 法与 Galerkin 法给出同一个近似解。

  若 $a(u,v)$ 不对称，则 Ritz 法用不了（因为不存在对应的对称能量泛函），只能用 Galerkin。

典型的非对称问题：

$$-u^{\prime\prime}+bu^{\prime} = f \tag{5.4.10}$$

  弱形式是

$$a(u,v) = \int(u^{\prime}v^{\prime}+bu^{\prime}v)dx$$

  这里 $a(u,v)\ne a(v,u)$——对流项让矩阵不对称。

非对称的严重后果：矩阵不再是"对称正定"，很多好用的方法失效

  1. 不能保证有极小值——Ritz 法的物理直觉崩了
  2. CG 法不能用（2.5 节）——得换成 GMRES / BiCGSTAB
  3. 稳定性更难保证——可能出现 4.3 节那种"数值振荡"

这也解释了为什么"对流主导"问题特别难：$b$ 一大，矩阵的对称性被破坏得越厉害，有限元就要加稳定化（SUPG、VMS 等）才能用。

对初学者：看到"-u'' + bu' = f"这种方程要立刻警觉——它不是"普通的 Poisson 加个低阶项"，而是从"对称"跳到"非对称"的质变。

5.4.4 Cea 引理：为什么近似的近似也不错

  Ritz 法和 Galerkin 法都只在一个有限维子空间 $V_h$ 里找解。自然要问：

用 $V_h$ 里的 $u_h$，去近似真解 $u$，误差有多大？

  Cea 引理回答这个问题：

$$ \lVert u-u_h \rVert_V \le \frac{M}{\alpha}\min_{v_h\in V_h}\lVert u-v_h \rVert_V \tag{5.4.11}$$

  其中 $M$ 是 $a$ 的有界常数，$\alpha$ 是强制常数（5.3 节）。

  读法：有限元解与真解的距离，与"子空间里离真解最近的那个元素"距离是同一个量级——只差一个常数 $M/\alpha$。

Cea 引理为什么是有限元理论的基石

它把"数值方法的误差"转化成了"逼近论的误差"。

也就是说：

  • 你不需要分析数值格式本身
  • 只需要回答一个纯粹的逼近问题：用分片多项式能多好地逼近 $u$？

接下来的事就简单了：

  • 分片线性逼近足够光滑的 $u$：$L^2$ 误差 $O(h^2)$，$H^1$ 误差 $O(h)$（5.2 节）
  • 分片 $k$ 次多项式：$L^2$ 误差 $O(h^{k+1})$，$H^1$ 误差 $O(h^k)$

于是有限元的收敛阶就自动得到了——这就是 5.6、5.7 要展开的内容。

注意常数 $M/\alpha$：它衡量"问题的病态程度"。若 $\alpha$ 很小（接近退化），误差可能被放大很多倍。这就是为什么"接近奇异的方程"即使方法正确也会算不准。

Cea 引理的证明（可选读）

前提：$a$ 有界（常数 $M$）且强制（常数 $\alpha$）。$u_h$ 满足 $a(u_h,v_h)=f(v_h)$ 对所有 $v_h\in V_h$。

第一步：误差的"正交性"

因为真解 $u$ 也满足 $a(u,v)=f(v)$，两式相减（$v$ 取 $v_h$）：

$$a(u-u_h, v_h) = 0 \qquad\text{对所有 } v_h\in V_h \tag{1}$$

这叫 Galerkin 正交性——误差与整个子空间 $V_h$ 正交。

第二步：对任意 $v_h\in V_h$，插入中间项

$$\lVert u-u_h\rVert^2 \le \frac{1}{\alpha}a(u-u_h,u-u_h) \qquad\text{（强制性）}$$

$$= \frac1\alpha a(u-u_h, u-v_h) \qquad\text{（加上 } a(u-u_h,v_h)=0\text{）}$$

$$\le \frac{M}{\alpha}\lVert u-u_h\rVert\cdot\lVert u-v_h\rVert \qquad\text{（有界性）}$$

第三步：两边约去 $\lVert u-u_h\rVert$

$$\lVert u-u_h\rVert \le \frac{M}{\alpha}\lVert u-v_h\rVert$$

对 $v_h$ 取下确界即得结论。$\blacksquare$

证明只用了三件事：强制性、有界性、Galerkin 正交性。没有任何对 $u$ 光滑性的额外要求——这就是引理的强大之处。

5.5 代码：Ritz 与 Galerkin 得到同一矩阵

运行后会看到：

  1. 数值积分得到的矩阵与解析值完全一致（偏差在 $10^{-16}$ 量级）
  2. 矩阵对称（$\lVert A-A^{\mathsf{T}}\rVert=0$）
  3. 最小特征值 $>0$——对称正定，可以用 CG
  4. 特征值就是 2.2 节那个三对角矩阵的谱

为什么分片线性基函数导出三对角矩阵？因为 $\phi_i$ 与 $\phi_j$ 只在相邻时才有重叠——支集是局部的。这是所有有限元矩阵稀疏性的根源。

5.6 小结

概念 内容
Ritz 法 在候选集里极小化能量泛函 $J$
Galerkin 法 让残差与基函数正交
等价条件 $a$ 对称时两者等价
非对称 只能用 Galerkin；矩阵不对称、CG 失效
Cea 引理 $\Vert u-u_h\Vert\le\frac{M}{\alpha}\min\Vert u-v_h\Vert$
引理的意义 数值误差 ⟹ 逼近误差，简化了全部理论

易错点

  1. Ritz 法只适用于对称问题，非对称时必须用 Galerkin；
  2. Cea 引理不要求 $u$ 光滑，光滑性只影响逼近误差那一项；
  3. 常数 $M/\alpha$ 不能忽略，病态问题的误差会被放大；
  4. 基函数的支集越局部，矩阵越稀疏——这是有限元的效率来源；
  5. "Galerkin 正交"不是"残差处处为零"，只是"在每个测试方向上为零"。

  下一节 5.5 讲谱方法——它的基函数是全局的（三角函数/正交多项式），与有限元刚好相反：精度极高但矩阵稠密。
