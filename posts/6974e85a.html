3.1 为什么需要积分变换法

  分离变量法有一个前提：区域有界。有界才有离散的本征值谱，才谈得上级数展开。但很多实际问题是无界的：

  • 一根"无限长"的弦（远端的反射还没传到观察点）
  • 无限大薄板上的温度分布
  • 半无限区域上的问题

  这些问题的本征值变成连续的，级数变成积分——这就是傅里叶积分。积分变换法是分离变量法在连续谱上的自然推广。

  核心思想：把偏微分方程对整个空间变量 $x$ 做变换，把对 $x$ 的微分变成一个代数因子，从而把 PDE 化为关于 $t$ 的 ODE（或代数方程）。这与分离变量"把 PDE 拆成 ODE"的目标一致，但操作路径不同。

3.2 傅里叶变换

3.2.1 定义与基本性质

  对 $f(x)$（在 $(-\infty,\infty)$ 上绝对可积且分段光滑），定义傅里叶变换：

$$\hat{f}(\omega) = \mathscr{F}f = \int_{-\infty}^{\infty} f(x)e^{-i\omega x},dx \tag{3.2.1}$$

  以及逆变换：

$$f(x) = \mathscr{F}^{-1}\hat{f} = \frac{1}{2\pi}\int_{-\infty}^{\infty}\hat{f}(\omega)e^{i\omega x},d\omega \tag{3.2.2}$$

符号约定不唯一：有的教材把 $1/(2\pi)$ 放在正变换，有的把它拆成 $1/\sqrt{2\pi}$ 各放一半，还有的把 $e^{-i\omega x}$ 写成 $e^{-2\pi i\nu x}$。本文全篇统一采用 (3.2.1)(3.2.2)。做题时如果对不上答案，先检查约定是否一致——这是最常见的"算错"来源。

  本节要用的核心性质（都不加证明，只列结果）：

性质 表达式
线性 $\mathscr{F}[af+bg] = a\hat{f}+b\hat{g}$
微分 $\mathscr{F}[f'] = i\omega\hat{f}$，$\mathscr{F}[f''] = -\omega^2\hat{f}$
平移 $\mathscr{F}[f(x-a)] = e^{-i\omega a}\hat{f}(\omega)$
伸缩 $\mathscr{F}[f(ax)] = \dfrac{1}{\lvert a\rvert}\hat{f}\left(\dfrac{\omega}{a}\right)$
卷积 $\mathscr{F}[f*g] = \hat{f}\hat{g}$
高斯 $\mathscr{F}[e^{-x^2}] = \sqrt{\pi}e^{-\omega^2/4}$

  其中微分性质是关键：把一个二阶导数变成乘上 $-\omega^2$，PDE 里最难处理的部分立刻变成代数运算。

3.2.2 无界弦的自由振动

  考虑：

$$\begin{cases} u_{tt} = a^2u_{xx}, & -\infty < x < \infty,\ t>0 \ u(x,0) = \varphi(x), \quad u_t(x,0) = \psi(x) \end{cases} \tag{3.2.3}$$

  没有边界条件——这就是无界弦，扰动从初始位置向两侧传出去，永不返回。

  对 $x$ 做傅里叶变换，记 $U(\omega,t) = \mathscr{F}u(\cdot,t)$。由微分性质：

$$U_{tt} = a^2(-\omega^2)U ;\Longrightarrow; U_{tt} + a^2\omega^2U = 0 \tag{3.2.4}$$

  PDE 变成了 ODE。初始条件也变换：

$$U(\omega,0) = \hat{\varphi}(\omega), \quad U_t(\omega,0) = \hat{\psi}(\omega) \tag{3.2.5}$$

  方程 (3.2.4) 是简谐振动，角频率为 $a\lvert\omega\rvert$，解为

$$U(\omega,t) = \hat{\varphi}(\omega)\cos(a\omega t) + \frac{\hat{\psi}(\omega)}{a\omega}\sin(a\omega t) \tag{3.2.6}$$

  （这里 $\cos(a\omega t)$ 是偶函数，所以 $\lvert\omega\rvert$ 可以去掉。）

  下一步是逆变换。利用欧拉公式把三角函数拆开：

$$\cos(a\omega t) = \frac{e^{ia\omega t}+e^{-ia\omega t}}{2}, \quad \sin(a\omega t) = \frac{e^{ia\omega t}-e^{-ia\omega t}}{2i}$$

  代入 (3.2.6)：

$$U = \frac{1}{2}\left[\hat{\varphi}e^{ia\omega t} + \hat{\varphi}e^{-ia\omega t}\right] + \frac{1}{2ia\omega}\left[\hat{\psi}e^{ia\omega t} - \hat{\psi}e^{-ia\omega t}\right] \tag{3.2.7}$$

  由平移性质，$e^{\pm ia\omega t}\hat{f}(\omega)$ 对应 $f(x \pm at)$。前两项直接逆变换：

$$\mathscr{F}^{-1}\left[\hat{\varphi}e^{\pm ia\omega t}\right] = \varphi(x\pm at) \tag{3.2.8}$$

  后两项需要处理 $1/(i\omega)$ 因子。关键恒等式：

$$\mathscr{F}^{-1}\left[\frac{\hat{\psi}(\omega)}{i\omega}\right] = \int_{-\infty}^{x}\psi(\xi),d\xi$$

  这个可以自己验证：对 $\Psi(x) = \int_{-\infty}^x\psi(\xi)d\xi$ 求导得 $\Psi' = \psi$，由微分性质 $\mathscr{F}[\Psi'] = i\omega\hat{\Psi} = \hat{\psi}$，即 $\hat{\Psi} = \hat{\psi}/(i\omega)$ ✓

  于是后两项逆变换为

$$\frac{1}{2a}\left[\int_{-\infty}^{x+at}\psi(\xi)d\xi - \int_{-\infty}^{x-at}\psi(\xi)d\xi\right] = \frac{1}{2a}\int_{x-at}^{x+at}\psi(\xi),d\xi \tag{3.2.9}$$

  合并 (3.2.8) 与 (3.2.9)：

$$u(x,t) = \frac{\varphi(x+at)+\varphi(x-at)}{2} + \frac{1}{2a}\int_{x-at}^{x+at}\psi(\xi),d\xi \tag{3.2.10}$$

  这正是达朗贝尔公式。 第 1 章里我们是用"通解 + 初始条件"凑出来的，这里用积分变换重新导出了同一个结果——两种方法互为印证。

为什么这个方法值得讲：如果初始条件里还带一边界（比如半无界弦 $x>0$，端点固定），达朗贝尔公式就要手动做偶延拓；而傅里叶变换配合半无界的正弦/余弦变换则更"机械"。更复杂的、带外力项的问题用变换法尤其省事——见 3.4 节的非齐次例题。

3.2.3 非齐次情形：带外力项的波动方程

  例 3.2.1 求解

$$\begin{cases} u_{tt} = a^2u_{xx} + f(x,t), & -\infty<x<\infty \ u(x,0) = 0, \quad u_t(x,0) = 0 \end{cases}$$

  解： 变换后

$$U_{tt} + a^2\omega^2U = \hat{f}(\omega,t), \quad U(\omega,0)=0,; U_t(\omega,0)=0 \tag{3.2.11}$$

  这是强迫振动，初值为零。它的通解可用常数变易法，但更直接的是冲量响应思路：在 $t=\tau$ 时刻加了强度为 $\hat{f}(\omega,\tau)d\tau$ 的冲量，引起的响应为

$$\frac{\hat{f}(\omega,\tau)}{a\omega}\sin\big(a\omega(t-\tau)\big),d\tau \quad (t>\tau)$$

  （与 (3.2.6) 的第二项同形。）总响应是这些冲量的叠加：

$$U(\omega,t) = \int_0^t \frac{\hat{f}(\omega,\tau)}{a\omega}\sin\big(a\omega(t-\tau)\big),d\tau \tag{3.2.12}$$

  现在要逆变换。关键在于识别 $\dfrac{\sin(a\omega s)}{a\omega}$（记 $s=t-\tau$）的逆变换：

$$\mathscr{F}^{-1}\left[\frac{\sin(a\omega s)}{a\omega}\right]$$

  由 3.2.2 的推导可知，$\dfrac{\sin(a\omega s)}{a\omega}$ 是某个矩形脉冲的傅里叶变换。具体地，记

$$G(x,s) = \frac{1}{2a}\left[H(x+as) - H(x-as)\right] = \begin{cases} \dfrac{1}{2a}, & \lvert x\rvert < as \ 0, & \lvert x \rvert > as \end{cases}$$

  其中 $H$ 是赫维赛德阶跃函数（$x<0$ 时为 $0$，$x>0$ 时为 $1$）。直接计算它的变换：

$$\hat{G} = \frac{1}{2a}\int_{-as}^{as}e^{-i\omega x}dx = \frac{1}{2a}\cdot\frac{e^{i\omega as}-e^{-i\omega as}}{i\omega} = \frac{\sin(a\omega s)}{a\omega} ✓$$

  所以逆变换就是矩形脉冲。再由卷积定理（$\mathscr{F}^{-1}[\hat{f}\hat{G}] = f*G$）：

$$u(x,t) = \int_0^t \left[\int_{-\infty}^{\infty} f(x',\tau)G(x-x',t-\tau),dx'\right]d\tau$$

  代入 $G$ 的分段形式，内层积分只在 $\lvert x-x'\rvert < a(t-\tau)$ 即 $x-a(t-\tau) < x' < x+a(t-\tau)$ 上非零：

$$u(x,t) = \frac{1}{2a}\int_0^t\int_{x-a(t-\tau)}^{x+a(t-\tau)} f(x',\tau),dx',d\tau \tag{3.2.13}$$

  这就是无界弦受迫振动的解。它的物理意义极清晰：点 $(x,t)$ 处的位移，只受过去在这条"光锥"内发生的外力影响——即满足 $\lvert x-x'\rvert < a(t-\tau)$ 的区域。

这个结果把因果性写成了积分的积分限。而积分域的形状（特征锥）直接来自波动方程的特征线 $x' = x \pm a(t-\tau)$。这也解释了为什么第 1 章要单独讨论特征线——它决定了信息传播的边界。

3.3 小结

环节 无界弦自由振动 无界弦受迫振动
变换后方程 $U_{tt}+a^2\omega^2U = 0$ $U_{tt}+a^2\omega^2U = \hat{f}$
逆变换关键 平移性质 + $1/(i\omega)$ 恒等式 矩形脉冲 + 卷积定理
结果 达朗贝尔公式 特征锥内的二重积分

易错点

  1. 微分性质符号：$\mathscr{F}[f''] = -\omega^2\hat{f}$，负号不能丢（很多人写成 $+\omega^2$）；
  2. $1/(i\omega)$ 的逆变换是积分从 $-\infty$ 到 $x$，不是从 $0$ 开始；
  3. 阶跃函数的走向：$H(x)\to1$ 当 $x>0$，积分上下限与它的乘积要仔细核对；
  4. 变换法默认函数在无穷远处足够快地衰减，否则积分不收敛。这一点在物理模型上对应"扰动源有限"。

  下一节讲拉普拉斯变换，它处理的是关于 $t$ 的初值问题——把时间微分变成乘 $s$，特别适合半无界杆的热传导这类"有初值、有边界、但时间方向单向"的问题。

  傅里叶变换法的系统论述参见[1]吴小庆.数学物理方程及其应用参考资料。
