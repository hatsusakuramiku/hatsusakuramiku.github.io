前置知识：1.2 节（线性差分方程、特征根、Gronwall 不等式）、1.4 节（阶数条件）。

三个问题的关系

  一个数值格式好不好，要回答三个问题：

  1. 相容性：格式是否"逼近"了原方程？——差步长取零，格式还原成微分方程吗？
  2. 稳定性：误差会不会被放大？——扰动有界吗？
  3. 收敛性：步长取零，数值解是否趋于真解？

  Lax 等价定理（对线性问题）把它们串起来：

$$\boxed{\text{相容} + \text{稳定} \iff \text{收敛}} \tag{1.5.1}$$

  这一定理是数值 ODE 与数值 PDE 理论的基石——只需验证相容性和稳定性，收敛性自动成立。本节把这三件事一个个讲清楚。

1.5 相容性

1.5.1 局部截断误差与相容性定义

  一般 $r$ 步线性多步法：

$$\sum_{j=0}^{r}\alpha_j y_{k+j} = h\sum_{j=0}^{r}\beta_j f_{k+j} \tag{1.5.2}$$

  局部截断误差（LTE）：把精确解代入，两边之差除以 $h$：

$$T_k = \frac{1}{h}\left[\sum_{j=0}^r\alpha_j y(t_{k+j}) - h\sum_{j=0}^r\beta_j y^{\prime}(t_{k+j})\right] \tag{1.5.3}$$

  （除以 $h$ 是为了让 $T_k$ 有"每单位步长"的量纲。）

  泰勒展开 $y(t_{k+j}) = \sum_{m}\frac{(jh)^m}{m!}y^{(m)}(t_k)$，得到

$$T_k = \sum_{m=0}^{\infty}\frac{h^{m-1}}{m!}\left[\sum_{j=0}^r j^m\alpha_j - m\sum_{j=0}^r j^{m-1}\beta_j\right]y^{(m)}(t_k) \tag{1.5.4}$$

  定义：若 $T_k = O(h^p)$，称格式是 $p$ 阶的。

  相容性：$p \ge 1$，即 $T_k\to0$（$h\to0$）。

  相容性条件（由 $m=0,1$ 两个条件）：

$$\sum_{j=0}^r\alpha_j = 0 \quad\text{且}\quad \sum_{j=0}^r j\alpha_j = \sum_{j=0}^r\beta_j \tag{1.5.5}$$

  第一式是 1.4 节讲过的 $\sum\alpha_j=0$；第二式是"一阶精确"。

只满足第一式是不够的。

若 $\sum\alpha_j=0$ 但 $\sum j\alpha_j \ne \sum\beta_j$，则 $T_k = O(1)$——格式不相容，误差不随 $h$ 减小而减小，这样的格式完全无用。

两个条件必须同时满足才叫相容。

1.5.2 第一特征多项式

  把系数写成多项式：

$$\rho(r) = \sum_{j=0}^{r}\alpha_j r^j, \qquad \sigma(r) = \sum_{j=0}^r\beta_jr^j \tag{1.5.6}$$

  $\rho$ 称为第一特征多项式，$\sigma$ 为第二特征多项式。

  于是相容性条件 (1.5.5) 可写成漂亮的形式：

$$\rho(1) = 0, \qquad \rho^{\prime}(1) = \sigma(1) \tag{1.5.7}$$

  验证：$\rho(1)=\sum\alpha_j=0$ ✓；$\rho^{\prime}(1) = \sum j\alpha_j$，$\sigma(1)=\sum\beta_j$ ✓

$\rho(1)=0$ 的必然性：任何相容格式都必须有 $r=1$ 作为 $\rho$ 的根。

物理意义：常数是齐次差分方程的解（$f\equiv0$ 时 $y$ 为常数，差分 $\sum\alpha_j\cdot1=0$）。

这个根称为主根（principal root）。

1.6 零稳定性

1.6.1 定义

  零稳定性（zero-stability）研究的是齐次问题（$f\equiv0$）：

$$\sum_{j=0}^r\alpha_j y_{k+j} = 0 \tag{1.6.1}$$

  定义：若 (1.6.1) 的任意解都满足

$$|y_k| \le C\max_{0\le j<r}|y_j|, \qquad \forall k \ge r \tag{1.6.2}$$

其中 $C$ 与 $k$ 无关（但与区间长度可能有关），则称格式是零稳定的。

  "零"的意思：$h\to0$ 时（对应 $z=h\lambda\to0$）的稳定性——即试验方程的 $\lambda\to0$ 极限。

1.6.2 根条件（Root Condition）

  由 1.2 节的差分方程理论，(1.6.1) 的解是 $\sum c_i r_i^k$（$r_i$ 是 $\rho$ 的根），重根时含 $k^m$ 因子。

  零稳定性等价于根条件：

所有根的模 $\le 1$，且模恰为 1 的根都是单根。

欧拉式地写：$\rho(r)=0$ 的根 ${r_i}$ 满足

$$|r_i| \le 1, \qquad \text{若 } |r_i|=1 \text{ 则 } r_i \text{ 单重} \tag{1.6.3}$$

为什么"模为 1 必须是单根"：

若 $|r|=1$ 是二重根，解含 $k\cdot r^k$ 项，模为 $k$——随 $k$ 线性增长，不满足 (1.6.2) 的"一致有界"要求。

而 $|r|<1$ 时即使重根也衰减，所以允许。

1.6.3 几个格式的零稳定性检验

Euler 法：$\rho(r) = r-1$，根 $r_1=1$（单重）✓ 零稳定

AB2：$y_{k+1}=y_k+\frac{h}{2}(3f_k-f_{k-1})$，即 $\alpha_0=\frac12, \alpha_1=-1, \alpha_2=\frac12$

$$\rho(r) = \frac12 - r + \frac12r^2 = \frac12(r-1)^2$$

  根 $r=1$ 是二重根！由判据——AB2 不是零稳定的？

  结论似乎不对。 AB2 是标准教材里公认的零稳定格式，说明上面的书写有误，回头检查：

  重新核对系数：AB2 的格式写作

$$y_{k+2} = y_{k+1} + \frac{h}{2}(3f_{k+1} - f_k)$$

  即 $\alpha_0=0$（对 $y_k$ 的系数），$\alpha_1=-1$，$\alpha_2=1$。代入：

$$\rho(r) = -r + r^2 = r(r-1)$$

  根 $r=0$ 与 $r=1$，都是单根 ✓ 零稳定。

  我刚才把 $y_k$ 的系数写错了——$y_k$ 的系数是 0（AB2 里 $y_k$ 不出现），不是 $\frac12$。$\frac12$ 是 $f_{k-1}$ 的系数（属于 $\sigma$）。

这是个真实的教学陷阱，值得停下来看。

写 $\rho$ 时只取 $y$ 的系数 $\alpha_j$，不取 $f$ 的系数 $\beta_j$。

我第一次写 $\rho(r)=\frac12-r+\frac12r^2$ 时，把 $\frac12$ 既是 $\beta_0$（AB2 显式格式 $\beta_0=0$，这里写错了）又当成了 $\alpha_0$——混淆了两个多项式。

正确做法：先明确列出 $\alpha_j$（$y$ 的系数）和 $\beta_j$（$f$ 的系数）两行，再分别代入。

  完整的 AB2 系数（写成 $y_{k+2}-y_{k+1} = \frac{h}{2}(3f_{k+1}-f_k)$）：

$$\alpha = (0,\ -1,\ 1), \qquad \beta = (-\tfrac12,\ \tfrac32,\ 0)$$

$$\rho(r) = -r+r^2 = r(r-1) ;\Longrightarrow; r=0,1 ; \text{单根} ✓$$

  Milne-Simpson（1.4 节）：$y_{k+2}-y_k = \frac{h}{3}(f_k+4f_{k+1}+f_{k+2})$

$$\alpha = (-1,\ 0,\ 1), \quad \rho(r) = r^2-1 = (r-1)(r+1)$$

  根 $r = \pm1$，都是单根 ✓ 零稳定（但如 1.4 节所说，实用中弱不稳定，因为 $r=-1$ 这个寄生根会带来振荡）。

  这个例子说明：零稳定是必要条件而非充分条件，不能保证实际好用。

1.7 收敛性：Dahlquist 等价定理

1.7.1 定理陈述

  Dahlquist 等价定理：

对线性多步法 (1.5.2)，若右端函数 $f(t,y)$ 关于 $y$ 满足 Lipschitz 条件，则

格式收敛 $\iff$ 格式相容且零稳定

  更精确地说：设格式是 $p$ 阶相容的，且零稳定，则整体误差为 $O(h^p)$。

1.7.2 证明思路（必看）

  核心技巧：把数值解和精确解都写成"扰动累积"的形式。

  记 $y_j = y(t_j)$ 为精确解在节点上的值，$\eta_j = y_j - y(t_j)$ 为整体误差。

  精确解满足（带一个残差项）：

$$\sum_{j=0}^r\alpha_j y(t_{k+j}) = h\sum_{j=0}^r\beta_j f(t_{k+j}, y(t_{k+j})) + hT_k$$

  数值解满足：

$$\sum_{j=0}^r\alpha_j y_{k+j} = h\sum_{j=0}^r\beta_j f(t_{k+j}, y_{k+j})$$

  两式相减，并用 Lipschitz 条件（$|f(t,y_1)-f(t,y_2)|\le L|y_1-y_2|$）：

$$\left|\sum_{j=0}^r\alpha_j\eta_{k+j}\right| \le hL\sum_{j=0}^r|\beta_j||\eta_{k+j}| + h|T_k| \tag{1.7.1}$$

  这就是一个"误差的差分方程"，右端有源项 $h|T_k|$。

  接下来两步：

  1. 零稳定性保证：这个差分方程的解被源项和控制，即存在常数 $C_1$ 使
    $$\max_j|\eta_{k+j}| \le C_1\left[\max_{0\le i<r}|\eta_i| + h\sum_{i=r}^{k}|\eta_i| + h\sum|T_i|\right]$$
    （这一步正是"根条件"的作用——若根条件不满足，误差会被放大，得不到这个界。）

  2. Gronwall 不等式（1.2 节）把上面的界化成指数型：
    $$|\eta_k| \le C\left[\max_{0\le i<r}|\eta_i| + h\sum|T_i|\right]e^{L(t_k-a)}$$

  代入 $|T_i|\le Mh^{p}$（$p$ 阶相容），得

$$|\eta_k| \le C\left[\max|\eta_i| + M h^p (b-a)\right]e^{L(b-a)} = O(h^p) \quad\blacksquare$$

  注意起步值：$\max_{0\le i<r}|\eta_i|$ 必须在 $O(h^p)$ 量级，否则误差被它主导——这就是 1.3 节强调"起步值精度必须够"的原因。

这个证明的结构值得记住：

$$\text{局部误差的差分方程} \xrightarrow{\text{零稳定}} \text{误差被源项控制} \xrightarrow{\text{Gronwall}} \text{指数型界}$$

三步都可以机械地套用。同一个模板在数值 PDE 的收敛性证明里也完全适用（第 2~4 章会反复出现）。

1.7.3 为什么"稳定"是必需的

  反例：考虑格式

$$y_{k+2} - 3y_{k+1} + 2y_k = -hf_{k+1} \tag{1.7.2}$$

  相容性检查：

$$\rho(r) = r^2-3r+2 = (r-1)(r-2)$$

$$\rho(1)=0 ✓,\quad \rho^{\prime}(1) = 2-3 = -1,\quad \sigma(1) = -1 ✓$$

  相容！ 而且能验证它是 1 阶的。

  零稳定性检查：根 $r=1, r=2$。$|2|>1$ → 零不稳定！

  后果：即使 $h\to0$，误差中的 $2^k$ 分量依然存在（对固定长度区间，$k = (b-a)/h\to\infty$，$2^k$ 会趋于无穷）。

  这个格式完全不能用，尽管它满足相容性。

这个反例的教训：

相容性只保证"局部每一步都逼近"，但不保证"全局不放大"。一个每步都正确的格式，可以因为误差被指数放大而彻底失效。

这也是为什么 Dahlquist 等价定理要两个条件并列——缺一不可。

1.8 收敛阶与误差主项

  定义：若整体误差 $|y_k - y(t_k)| = O(h^p)$，称格式是 $p$ 阶收敛的。

  对相容且零稳定的格式，收敛阶 = 相容阶 = 方法的阶。

  误差主项：由 (1.5.4)，阶为 $p$ 时 $h^{p-1}$ 项为零，第一个非零项是 $h^p$：

$$T_k = C,h^p,y^{(p+1)}(t_k) + O(h^{p+1}), \qquad C = \frac{1}{(p+1)!}\left[\sum j^{p+1}\alpha_j-(p+1)\sum j^p\beta_j\right]$$

  $C$ 称为误差常数。它在数值上很重要——两个同为 4 阶的方法，$|C|$ 小的实际精度更高。

  常见方法的误差常数：

方法 阶 误差常数 $C$
Euler 1 $\frac12$
梯形（AM2） 2 $-\frac{1}{12}$
AB2 2 $\frac{5}{12}$
AB3 3 $\frac{3}{8}$
AB4 4 $\frac{251}{720}$
AM4 4 $-\frac{19}{720}$

观察：AM4 的误差常数 $-\frac{19}{720}\approx-0.026$，AB4 的 $\frac{251}{720}\approx0.349$——相差 13 倍。

虽然同为 4 阶，隐式的 AM4 实际精度远超显式的 AB4。这就是"阶相同，性能可以差很多"的具体数字。

1.10 小结

概念 定义 判据 / 工具
相容性 $T_k\to0$ $\rho(1)=0$ 且 $\rho^{\prime}(1)=\sigma(1)$
零稳定性 齐次解一致有界 $\rho$ 的根：模 $\le1$，模 1 的根单重
收敛性 误差 $\to0$ Dahlquist：相容 + 零稳定 $\iff$ 收敛
收敛阶 误差 $=O(h^p)$ $= $ 相容阶（在零稳定前提下）

易错点

  1. 写 $\rho$ 时只取 $y$ 的系数 $\alpha_j$，不要混入 $f$ 的系数 $\beta_j$（本文第 1.6.3 节演示了这个错误）；
  2. 相容性有两个条件，只满足 $\sum\alpha_j=0$ 不够；
  3. 模为 1 的重根也算不稳定——解中会出现 $k\cdot r^k$ 的线性增长项；
  4. 相容 $\ne$ 收敛：1.7.3 的反例相容但发散；
  5. 零稳定是必要的不是充分的：Milne-Simpson 零稳定但实用中弱不稳定。

  下一节 1.6 讲 Runge-Kutta 法——单步法的高阶代表，它绕开了"寄生根"问题，但需要多算几次 $f$。
