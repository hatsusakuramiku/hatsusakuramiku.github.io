本文要做什么

  黎曼积分要求两件事：区间有限、函数有界。这两条一破，积分就"不存在"。

  但很多实际问题里它们都会破：

  • 概率论：正态分布的积分 $\displaystyle\int_{-\infty}^{\infty}\mathrm{e}^{-x^2/2},\mathrm{d}x$ ——无限区间
  • 物理：点电荷的电势 $\displaystyle\int_0^R\frac{\mathrm{d}r}{r}$ ——被积函数在 0 处无界

  **广义积分（反常积分）**就是把这些情形救回来的方法。

  核心问题：

$$\int_1^{\infty}\frac{\mathrm{d}x}{x}=\infty\quad\text{发散},\qquad \int_1^{\infty}\frac{\mathrm{d}x}{x^2}=1\quad\text{收敛}$$

  同样趋于 0，为什么一个收敛一个发散？

  答案在于趋于零的"速度"——这正是本文要讲清的东西。

  推进顺序：

  1. 两类广义积分的定义
  2. $p$-积分的完整分类（本文核心）
  3. 敛散判别的四种工具
  4. 条件收敛——最微妙的部分

前置知识

定积分与极限（不熟可以展开）

定积分（3.1 节）：要求区间有限、函数有界。

极限存在：$\lim\limits_{A\to\infty}F(A)$ 存在 ⟺ 对任意 $\varepsilon>0$ 存在 $M$，使 $A>M$ 时 $|F(A)-L|<\varepsilon$。

本文的定义方式："用有限的上界逼近"

  $\displaystyle\int_a^{\infty}f$ 的定义是

$$\lim_{A\to\infty}\int_a^{A}f(x),\mathrm{d}x$$

  先算一个正常的定积分，再取极限——这就是全部思路。

  所以广义积分本质上是"极限"，不是"积分"。 这个认识能省很多力气。

两类广义积分

第一类：无穷区间

$$\int_a^{\infty}f(x),\mathrm{d}x:=\lim_{A\to\infty}\int_a^{A}f(x),\mathrm{d}x$$

  若极限存在（有限），称收敛；否则发散。

  下限为 $-\infty$、或两端都无限的情形类似：

$$\int_{-\infty}^{b}f=\lim_{B\to-\infty}\int_B^bf,\qquad \int_{-\infty}^{\infty}f=\int_{-\infty}^{c}f+\int_c^{\infty}f$$

$\int_{-\infty}^{\infty}$ 必须从某个中间点拆开，两边都收敛才算收敛

  错误做法：直接算 $\lim\limits_{A\to\infty}\displaystyle\int_{-A}^{A}f$

  这叫柯西主值，与广义积分不是一回事。

  例：$f(x)=x$。

$$\lim_{A\to\infty}\int_{-A}^Ax,\mathrm{d}x=0\qquad\text{（主值）}$$

  但 $\displaystyle\int_0^{\infty}x,\mathrm{d}x=\infty$，所以广义积分发散。

  区别在于：主值强制两边用同一个速度趋近，广义积分允许各走各的。

  随机变量的期望存在性这类问题就用广义积分的定义，不能用主值。

第二类：无界函数（瑕积分）

  若 $f$ 在 $b$ 附近无界（$b$ 称瑕点）：

$$\int_a^bf(x),\mathrm{d}x:=\lim_{\varepsilon\to0^+}\int_a^{b-\varepsilon}f(x),\mathrm{d}x$$

  注意 $\varepsilon\to0^+$ 必须从右侧——否则会采到函数定义域外。

  判断瑕点在哪：$b$ 是瑕点 ⟺ $\lim\limits_{x\to b^-}|f(x)|=\infty$。

混合型要拆开

  若既有无穷区间又有瑕点，比如 $\displaystyle\int_1^{\infty}\frac{\mathrm{d}x}{\sqrt{x(x-1)}}$：

  $x=1$ 是瑕点（分母为 0），区间又无限。必须拆成两段，通常拆在"好"的点上：

$$\int_1^{2}+\int_2^{\infty}$$

  两段都收敛，整体才收敛。

核心：p-积分

无穷区间的 p-积分

$$\int_1^{\infty}\frac{\mathrm{d}x}{x^p}\quad\begin{cases}\text{收敛},&p>1\\ \text{发散},&p\le1\end{cases}$$

完整计算

  $p\ne1$ 时：

$$\int_1^{A}x^{-p},\mathrm{d}x=\left[\frac{x^{1-p}}{1-p}\right]_1^A=\frac{A^{1-p}-1}{1-p}$$

  让 $A\to\infty$：

  • $p>1$：$1-p<0$，$A^{1-p}\to0$，极限 $=\dfrac{0-1}{1-p}=\dfrac{1}{p-1}$（有限）→ 收敛
  • $p<1$：$1-p>0$，$A^{1-p}\to\infty$ → 发散

  $p=1$ 时：

$$\int_1^{A}\frac{\mathrm{d}x}{x}=\ln A\to\infty$$

  → 发散 ✓

  所以临界点是 $p=1$，而且是"严格大于才收敛"——$p=1$ 恰好落在发散一侧。

瑕点的 p-积分

$$\int_0^{1}\frac{\mathrm{d}x}{x^p}\quad\begin{cases}\text{收敛},&p<1\\ \text{发散},&p\ge1\end{cases}$$

  注意不等号方向反了！

完整计算

$$\int_{\varepsilon}^{1}x^{-p},\mathrm{d}x=\frac{1-\varepsilon^{1-p}}{1-p}\qquad(p\ne1)$$

  让 $\varepsilon\to0^+$：

  • $p<1$：$1-p>0$，$\varepsilon^{1-p}\to0$，极限 $=\dfrac{1}{1-p}$ → 收敛
  • $p>1$：$1-p<0$，$\varepsilon^{1-p}\to\infty$ → 发散

  $p=1$：$\displaystyle\int_\varepsilon^1\frac{\mathrm{d}x}{x}=-\ln\varepsilon\to\infty$ → 发散

  所以瑕点时**$p<1$ 收敛**。

两类 p-积分的结论正好相反

情形 收敛条件
$\displaystyle\int_1^\infty x^{-p}$ $p>1$
$\displaystyle\int_0^1 x^{-p}$ $p<1$

  为什么相反：因为这两件事是"镜像"的。

  无穷区间是 $x\to\infty$，$x^{-p}$ 要衰减得足够快（$p$ 大）才积得动。

  瑕点是 $x\to0$，$x^{-p}$ 要爆炸得足够慢（$p$ 小）才积得动。

  记忆方法：用 $x=1/t$ 换元，两者可以互换——所以结论必然对称。

  用具体数字感受：

$$\int_1^{\infty}\frac{\mathrm{d}x}{x^{1.0001}}\ \text{收敛}\qquad \int_1^{\infty}\frac{\mathrm{d}x}{x^{0.9999}}\ \text{发散}$$

  只差 0.0002，一个是有限一个是无穷。 这就是临界点的尖锐性。

为什么要关心 p-积分

  因为它是所有敛散判别的"标尺"。

  绝大多数判别法最后都归结为："$f$ 与某个 $x^{-p}$ 比较，看看 $p$ 是多少"。

  所以记住 $p=1$ 这个临界值，比记住公式本身更重要。

敛散判别四工具

工具一：直接比较

  设 $0\le f\le g$ 在 $[a,\infty)$ 上。

  • $g$ 的积分收敛 ⟹ $f$ 的积分收敛（"大的收敛，小的必收敛"）
  • $f$ 的积分发散 ⟹ $g$ 的积分发散（"小的发散，大的必发散"）

  证明：单调有界。$F(A)=\displaystyle\int_a^Af$ 单调递增，被 $\displaystyle\int_a^\infty g$ 界住，所以收敛。

"单调有界定理"又出现了

  整个判别法的基础是：$F(A)$ 是单调函数（因为 $f\ge0$）。

  而单调有界必收敛——这是 1.1 节用完备性推出来的。

  所以看似"技术性"的收敛判别，地基仍是实数的完备性。

  注意：这个判别法要求 $f\ge0$。若 $f$ 有正有负，$F(A)$ 不单调，判别法失效。

工具二：极限比较（最常用）

  设 $f,g>0$，且

$$\lim_{x\to\infty}\frac{f(x)}{g(x)}=c$$

  • $0<c<\infty$ → $f$ 与 $g$ 同敛散
  • $c=0$ → $g$ 收敛 ⟹ $f$ 收敛
  • $c=\infty$ → $g$ 发散 ⟹ $f$ 发散

  这个最实用：只要看 $f$ 在无穷远处像什么。

例：$\displaystyle\int_1^{\infty}\frac{\mathrm{d}x}{\sqrt{x^3+1}}$

  $x\to\infty$ 时，$\dfrac{1}{\sqrt{x^3+1}}\sim\dfrac{1}{x^{3/2}}$。

  $p=\frac32>1$ → 收敛。

例：$\displaystyle\int_1^{\infty}\frac{x+\sin x}{x^2},\mathrm{d}x$

  $x\to\infty$ 时，$\dfrac{x+\sin x}{x^2}\sim\dfrac{1}{x}$。

  $p=1$ → 发散。

"$\sim$" 的用法要小心

  严格说，$\dfrac{f}{g}\to1$ 才能写 $f\sim g$。

  但这里的例子 $f=\frac{x+\sin x}{x^2}$ 和 $g=\frac1x$ 的比值：

$$\frac{f}{g}=\frac{x+\sin x}{x}=1+\frac{\sin x}{x}\to1\quad\checkmark$$

  所以是对的。

  但如果 $f=\dfrac{x+\sin(2x)}{x^2}$，比值仍是 $1+\dfrac{\sin 2x}{x}\to1$ ✓

  问题是：$\sin x$ 项虽然是 $O(1)$，但积起来不收敛（$\int\frac{\sin x}{x}$ 是条件收敛的）。所以严格做要分开处理：

$$\int\frac{x}{x^2}+\int\frac{\sin x}{x^2}$$

  第一项发散，第二项收敛（$|\sin x/x^2|\le1/x^2$），所以整体发散 ✓

  结论仍然对，但推理要更细致。

工具三：Dirichlet 判别法

  若：

  1. $\displaystyle\int_a^Af(x),\mathrm{d}x$ 有界（对一切 $A$）
  2. $g(x)$ 单调且 $g(x)\to0$（$x\to\infty$）

则 $\displaystyle\int_a^{\infty}f(x)g(x),\mathrm{d}x$ 收敛。

  经典应用：$\displaystyle\int_1^{\infty}\frac{\sin x}{x},\mathrm{d}x$ 收敛。

  验证：

  • $f=\sin x$，$\displaystyle\int_0^A\sin x,\mathrm{d}x=1-\cos A\in[0,2]$ 有界 ✓
  • $g=\frac1x$ 单调递减趋于 0 ✓

  所以收敛。

这个积分不是绝对收敛

  $\displaystyle\int_1^{\infty}\left|\frac{\sin x}{x}\right|,\mathrm{d}x$ 发散。

  理由：$|\sin x|\ge\sin^2x$，而

$$\int_1^{\infty}\frac{\sin^2x}{x},\mathrm{d}x=\int\frac{1-\cos 2x}{2x},\mathrm{d}x=\frac12\int\frac{\mathrm{d}x}{x}-\frac12\int\frac{\cos2x}{x},\mathrm{d}x$$

  前一项发散（$p=1$），后一项收敛（Dirichlet）。所以整体发散。

  这就是"条件收敛"——收敛但绝对值不收敛。

  这意味着不能随意重排或拆分（见下面的警告）。

工具四：Abel 判别法

  若：

  1. $\displaystyle\int_a^{\infty}f$ 收敛
  2. $g$ 单调有界

则 $\displaystyle\int_a^{\infty}fg$ 收敛。

  与 Dirichlet 的区别：Dirichlet 要求 $g\to0$，Abel 只要求 $g$ 有界。

条件收敛的两道陷阱

陷阱一：绝对收敛才能随意拆分

定理：若 $\displaystyle\int|f|$ 收敛（绝对收敛），则 $\displaystyle\int f$ 收敛，且可以任意拆分区间。

  但条件收敛的不能随意拆。

例：$\displaystyle\int_0^{\infty}\frac{\sin x}{x},\mathrm{d}x$ 收敛（值 $=\frac\pi2$）。

  但若拆成 $\displaystyle\int_0^{\infty}\left(\frac{\sin x}{x}+\frac{|\sin x|}{x}\right)\mathrm{d}x-\int_0^{\infty}\frac{|\sin x|}{x}\mathrm{d}x$……

  两个都发散，却"相减"得到收敛值——这说明拆分流于形式，不能这样做。

陷阱二：Riemann 重排定理

  对条件收敛的级数，改变求和顺序会改变结果——甚至可以让它等于任何数。

  （级数版本更直观，见 4.1 节。）

  对积分，类似的现象是：不能随意拆成"无穷多个小块的和再重排"。

"绝对收敛"为什么这么重要

  绝对收敛 = 可以当作"有限的加法"来处理：

  • 可以重排
  • 可以拆项
  • 可以加括号
  • 可以乘起来

  条件收敛什么都不行——每做一步都要重新论证。

  实际工作中：先判断是否绝对收敛；若不是，再小心处理。

  这与 4.1 节的级数完全平行——那里也有"绝对收敛 ⟺ 可重排"的结论。

常见错误

错误一：混淆两类 p-积分的条件

  $\displaystyle\int_1^\infty x^{-p}$ 收在 $p>1$；$\displaystyle\int_0^1 x^{-p}$ 收在 $p<1$。

  记混了全错。

错误二：对 $\int_{-\infty}^{\infty}$ 用主值

  $\displaystyle\int_{-\infty}^{\infty}x,\mathrm{d}x$ 发散，不是 0。

  0 是主值。

错误三：条件收敛时用比较判别法

  比较判别法要求 $f\ge0$。对 $\frac{\sin x}{x}$ 不能直接比较。

  要用 Dirichlet/Abel，或用 $\left|\int\right|$ 的估计。

错误四：忘记检查瑕点

  $\displaystyle\int_0^2\frac{\mathrm{d}x}{x-1}$ 有两个瑕点（$x=1$）？

  准确说 $x=1$ 在区间内部，必须拆成 $\int_0^1+\int_1^2$ 分别判断。

  这里两段都发散 → 整体发散。

  若误用主值会得到 0（$x=1$ 对称），但那是错的。

错误五：以为"$f\to0$"就能保证积分收敛

  $\frac1x\to0$，但 $\int_1^\infty\frac{\mathrm{d}x}{x}$ 发散。

  必须看趋于 0 的速度。

错误六：以为"绝对收敛"和"收敛"是一回事

  $\int_1^\infty\frac{\sin x}{x}$ 收敛但不绝对收敛。

小结

概念 内容
无穷区间 $\lim_{A\to\infty}\int_a^Af$
瑕积分 $\lim_{\varepsilon\to0^+}\int_a^{b-\varepsilon}f$
$\int_1^\infty x^{-p}$ $p>1$ 收敛
$\int_0^1 x^{-p}$ $p<1$ 收敛
比较判别 $0\le f\le g$：大的收敛 ⟹ 小的收敛
极限比较 $f\sim g$ ⟹ 同敛散
Dirichlet $\int f$ 有界 + $g$ 单调趋 0
Abel $\int f$ 收敛 + $g$ 单调有界
条件收敛 收敛但 $\int|f|$ 发散，不能随意重排
地基 所有判别法基于单调有界（= 完备性）
