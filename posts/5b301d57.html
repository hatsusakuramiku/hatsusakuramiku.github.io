5.1 一个统一的视角

  到这里我们已经学会了三种解法：分离变量、积分变换、级数展开。它们看起来各自独立，但本质上是同一件事的不同写法。这一章用一个抽象的工具把它们统一起来。

  先做一次观察：很多 PDE 都能写成演化方程的形式

$$\frac{\partial u}{\partial t} = L u \tag{5.1.1}$$

  其中 $L$ 是只作用于空间变量的线性算子。例如：

方程 $L$
热传导 $u_t = a^2u_{xx}$ $a^2\partial_x^2$
波动方程（写成方程组） 特殊结构，见 5.3
薛定谔方程 $iu_t = -\frac{1}{2}u_{xx}$ $\frac{i}{2}\partial_x^2$

  对 (5.1.1)，如果 $L$ 只是一个数，解就是 $u = e^{Lt}u_0$。对算子来说，这个公式依然成立——只要把 $e^{Lt}$ 按泰勒级数定义。

5.1.1 算子指数的定义

  设 $L$ 是某个适当的函数空间上的线性算子，定义

$$e^{tL} = \sum_{n=0}^{\infty}\frac{t^n}{n!}L^n = I + tL + \frac{t^2}{2}L^2 + \cdots \tag{5.1.2}$$

  这里 $L^n$ 表示算子 $L$ 作用 $n$ 次，$L^0 = I$。

  关键性质（与数值情形完全相同）：

$$e^{tL}e^{sL} = e^{(t+s)L}, \qquad \frac{d}{dt}e^{tL} = Le^{tL} = e^{tL}L \tag{5.1.3}$$

  第二条是对算子形式的导数：它能把指数算子"拉出来"，这正是解演化方程的关键。

5.1.2 热传导方程的算子解

  考虑带初值的齐次问题：

$$\begin{cases} u_t = a^2u_{xx}, & x\in\mathbb{R} \ u(x,0) = f(x) \end{cases} \tag{5.1.4}$$

  形式解：

$$u(\cdot,t) = e^{a^2t\partial_x^2}f \tag{5.1.5}$$

  验证：$\dfrac{\partial}{\partial t}e^{a^2t\partial_x^2}f = a^2\partial_x^2 e^{a^2t\partial_x^2}f = a^2u_{xx}$ ✓

  现在把它展开成显式表达式。展开 (5.1.2)：

$$e^{a^2t\partial_x^2}f(x) = \sum_{n=0}^\infty\frac{(a^2t)^n}{n!}\frac{\partial^{2n}f}{\partial x^{2n}}(x) \tag{5.1.6}$$

  这个级数在 $f$ 光滑时收敛，但不是最方便的形式。更实用的是利用热核：

$$e^{a^2t\partial_x^2}f(x) = \int_{-\infty}^\infty\frac{1}{2a\sqrt{\pi t}}e^{-\frac{(x-\xi)^2}{4a^2t}}f(\xi),d\xi \tag{5.1.7}$$

  右边内层就是热核（与 3.2.4 节的 $\partial\Phi/\partial t$ 同形）：

$$K(x,\xi;t) = \frac{1}{2a\sqrt{\pi t}}e^{-\frac{(x-\xi)^2}{4a^2t}} \tag{5.1.8}$$

  为什么 (5.1.7) 成立：把 $e^{a^2t\partial_x^2}$ 用傅里叶变换对角化。$\partial_x^2$ 在傅里叶基 $e^{i\omega x}$ 下是乘 $-\omega^2$，所以

$$e^{a^2t\partial_x^2}e^{i\omega x} = e^{-a^2t\omega^2}e^{i\omega x}$$

  于是对 $f$ 的傅里叶积分表示逐项作用，再用高斯积分的逆变换，就得到 (5.1.7)。

注意这里同时用到了三章的内容：

  • 算子指数（本章）
  • 傅里叶变换对角化（第 3 章）
  • 热核（3.2.4 节的杜哈梅）

它们本来就是同一个解的三种描述。

5.1.3 与分离变量的对应：本征函数对角化

  在有界区域上，$L$ 有离散本征值 $\lambda_n$ 与本征函数 $\varphi_n$。此时算子指数最容易算——因为它在每个本征函数上就是乘一个数：

$$e^{tL}\varphi_n = e^{\lambda_n t}\varphi_n \tag{5.1.9}$$

  把初始条件按本征函数展开 $f = \sum a_n\varphi_n$，则

$$u = e^{tL}f = \sum_n a_n e^{\lambda_n t}\varphi_n \tag{5.1.10}$$

  这正是分离变量法的结果。 只不过分离变量是"先分离再解 ODE"，算子法是"先求本征函数再乘指数"——只是顺序不同。

  这就是为什么 4.1 节的施图姆-刘维尔理论是核心：它保证了 $L$ 有一组完备的本征函数，从而 $e^{tL}$ 可以被完整地"对角化"。

  统一图景：三种方法都是对角化。

方法 对角化的基 $L$ 作用后的结果
分离变量 ${\varphi_n}$（离散） $\lambda_n\varphi_n$
傅里叶变换 ${e^{i\omega x}}$（连续） $-\omega^2e^{i\omega x}$
拉普拉斯变换 不变（作用于 $t$） $L\to s$

"级数解法"这个名字的来历：当基是离散本征函数时，$e^{tL}f$ 展开成级数 $\sum a_ne^{\lambda_nt}\varphi_n$；当基是连续谱时，展开成积分。算子记法 $e^{tL}$ 同时覆盖两者，这就是"算子级数法"的含义。

5.1.4 杜哈梅原理的算子形式

  带源项的非齐次问题：

$$\begin{cases} u_t = Lu + F(t), & t>0 \ u(0) = 0 \end{cases} \tag{5.1.11}$$

  形式地，把非齐次方程看成"无数个瞬时源"的叠加。$t=\tau$ 时刻的源 $F(\tau)d\tau$ 在之后经过 $t-\tau$ 的演化，贡献为 $e^{(t-\tau)L}F(\tau)d\tau$。于是

$$u(t) = \int_0^t e^{(t-\tau)L}F(\tau),d\tau \tag{5.1.12}$$

  验证：直接求导。注意积分上限也含 $t$：

$$\frac{du}{dt} = e^{0\cdot L}F(t) + \int_0^t\frac{\partial}{\partial t}\left[e^{(t-\tau)L}\right]F(\tau)d\tau = F(t) + L\int_0^te^{(t-\tau)L}F(\tau)d\tau$$

  即 $u_t = F + Lu$ ✓，且 $t=0$ 时积分上限为零，$u(0)=0$ ✓。

  这是 3.2.4 节杜哈梅原理的最一般形式。 那次是对"阶跃输入"做叠加，这次是对"任意源"做叠加，本质上相同。

  该式也叫Duhamel 公式或常数变易公式的算子版本。在数值计算中，它被离散成

$$u(t+\Delta t) \approx e^{\Delta t L}u(t) + \int_t^{t+\Delta t}e^{(t+\Delta t-\tau)L}F(\tau)d\tau$$

  ——这就是指数积分器（exponential integrator）的来源，用于刚性 PDE 的长时间计算。

5.2 算子的形式演算技巧

  算子指数不只是记号，还有可操作的形式演算规则，许多书上的"技巧解法"都能从这里推出。

平移算子

  取 $L = \partial_x$，则 $e^{a\partial_x}$ 作用在 $f$ 上：

$$e^{a\partial_x}f(x) = \sum_{n=0}^\infty\frac{a^n}{n!}f^{(n)}(x) = f(x+a) \tag{5.2.1}$$

  这就是泰勒展开！ 于是"平移"就是"乘 $e^{a\partial_x}$"。

  应用：一阶方程 $u_t = a u_x$（单向波）的解为

$$u(x,t) = e^{at\partial_x}u_0(x) = u_0(x+at) \tag{5.2.2}$$

  ——波形以速度 $a$ 向左平移，符合直觉。

波动方程为什么不能直接写成 $e^{tL}$

  若硬要写 $u_{tt}=a^2u_{xx}$ 为 $u_t = Lu$，那 $L$ 必须满足 $L^2 = a^2\partial_x^2$，即 $L = \pm a\partial_x$。但取哪一个？两个都必要。

  正确做法是化为一阶方程组。令 $v = u_t$：

$$\frac{\partial}{\partial t}\begin{pmatrix}u\v\end{pmatrix} = \begin{pmatrix}0&I\a^2\partial_x^2&0\end{pmatrix}\begin{pmatrix}u\v\end{pmatrix} \tag{5.2.3}$$

  这个 $2\times2$ 算子矩阵的指数就是

$$\exp\left[t\begin{pmatrix}0&I\a^2\partial_x^2&0\end{pmatrix}\right] = \begin{pmatrix}\cosh(at\partial_x)&\frac{1}{a\partial_x}\sinh(at\partial_x)\a\partial_x\sinh(at\partial_x)&\cosh(at\partial_x)\end{pmatrix}$$

  涉及 $\partial_x^{-1}$（积分），所以这个写法能"形式"地用，但要注意积分常数。相比之下，分离变量和达朗贝尔公式要实用得多。

算子指数法的适用边界：它最适合一阶演化方程（热传导、反应扩散、薛定谔）。对二阶时间导数的问题（波动方程），算子指数会把问题变成算子矩阵，反而不如直接分离变量。不要为了优雅而牺牲可操作性。

乘法算子与解代数方程

  另一个有用的事实：若 $L$ 是乘法算子（乘 $g(x)$），则 $e^{tL}$ 也是乘 $e^{tg(x)}$。这给出很多"乘性"问题的解。

与常微分方程的联系

  一阶线性常微分方程 $y^{\prime} = \lambda y$，$y(0)=y_0$，解为 $y= e^{\lambda t}y_0$。把它当作"算子 $L=\lambda$（数）"的特例，形式完全一致。

  常数变易公式的经典形式（对 ODE）：

$$y(t) = e^{\lambda t}y_0 + \int_0^te^{\lambda(t-\tau)}f(\tau)d\tau$$

  这与 (5.1.12) 的形式完全对应——PDE 的杜哈梅原理不过是 ODE 常数变易法在函数空间中的翻版。

5.3 三个例子的统一验证

  用同一个初值 $f(x) = e^{i\omega x}$ 试三种问题，看算子法是否给出预期结果。

热传导：$u_t = a^2u_{xx}$

$$u = e^{a^2t\partial_x^2}e^{i\omega x} = e^{-a^2t\omega^2}e^{i\omega x}$$

  高频分量 ($\omega$ 大) 衰减极快，低频分量存活——这就是热传导的平滑效应（抛物型方程的特征）。

波动方程：$u_{tt} = a^2u_{xx}$，初值 $f$、初速零

  由算子矩阵公式（或直接分离变量），得

$$u = \cos(at\partial_x)f = \frac{1}{2}\left[e^{iat\partial_x} + e^{-iat\partial_x}\right]f = \frac{f(x+at)+f(x-at)}{2}$$

  ——达朗贝尔公式的一半（另一半来自初速项）。注意 $\cos(at\partial_x)$ 的泰勒展开收敛后就是和 $f(x\pm at)$ 的平均，与 (5.2.1) 一致。

薛定谔：$iu_t = -\frac{1}{2}u_{xx}$，即 $u_t = \frac{i}{2}u_{xx}$

$$u = e^{\frac{i}{2}t\partial_x^2}e^{i\omega x} = e^{-\frac{i}{2}t\omega^2}e^{i\omega x}$$

  模长不变（$|e^{-i\cdots}|=1$），只是相位旋转——这是幺正演化，与热传导的衰减形成鲜明对比（椭圆/抛物 vs 双曲的差别）。

这个三角对照很好地展示了三类方程的本质差别：

方程类型 算子指数因子 模长演化
热传导 $e^{-a^2t\omega^2}$ 指数衰减
波动 $\cos(at\omega)$ 振荡（有界）
薛定谔 $e^{-i t\omega^2/2}$ 不变

5.4 小结

  本系列五章的内容，可以用一句话串起来：

所有解法都是"找一个能让微分算子变成乘法的基"，然后 $e^{tL}$ 就是把本征值指数化。

章 方法 做的"基"
1 定解问题的提法 —
2 分离变量 离散本征函数 ${\varphi_n}$
3 积分变换 连续本征函数 $e^{i\omega x}$、$e^{st}$
4 级数解法 施图姆-刘维尔理论：保证基存在
5 算子级数法 统一的算子指数表述

易错点

  1. 算子可交换时才能随意用指数法则。$e^{A+B}=e^Ae^B$ 只在 $[A,B]=0$ 时成立——这对空间算子通常没问题（都是乘性/微分算子且只在一个变量上），但时间与空间算子不可交换；
  2. $e^{tL}$ 的展开需要 $L$ 有界或满足适当条件，否则级数可能不收敛。实用上只要能"对角化"就没问题；
  3. 波动方程的算子矩阵写法会出现 $\partial_x^{-1}$，积分常数不能随便丢；
  4. 不要混淆"算子指数"与"数值指数"：$e^{tL}$ 是算子，作用在函数上；把它当成一个数会全乱。

  下一节 5.2 把算子指数背后的谱理论展开，并展示数值格式如何统一为 $e^{\Delta tL}$ 的有理逼近。
