3.3 格林函数

  前面两节用傅里叶变换和拉普拉斯变换解决了一类问题。但变换法有个前提：区域必须让变换适用（全空间用傅里叶，半空间带初值用拉普拉斯）。有界区域的非齐次方程怎么办？

  答案是格林函数。它的思想极其简单：先求一个点源引起的响应，再用叠加原理把任意源表示成点源的积分。

3.3.1 从叠加原理到点源响应

  考虑有界区域上的泊松方程：

$$\begin{cases} \Delta u = -f(M), & M \in \Omega \ u|_{\partial\Omega} = 0 \end{cases} \tag{3.3.1}$$

  $f(M)$ 可以看作在每一点 $M'$ 处放置了强度为 $f(M')dV'$ 的"源"。如果已知在 $M'$ 处放置单位点源后，场地里各点的响应，那么总的 $u$ 就是所有点源响应的叠加。

  记这个单位点源响应为 $G(M, M')$，它满足

$$\Delta_M G = -\delta(M - M'), \qquad G|_{\partial\Omega} = 0 \tag{3.3.2}$$

  其中 $\delta$ 是狄拉克 delta 函数。这个 $G$ 就叫格林函数（Green's function）。

  注意下标 $M$：微分是对场点 $M$ 做的，源点 $M'$ 只是参数。于是叠加给出

$$u(M) = \int_\Omega G(M,M')f(M'),dV' \tag{3.3.3}$$

为什么 (3.3.3) 成立：把 $f$ 写成 $f(M) = \int_\Omega f(M')\delta(M-M')dV'$。由于方程线性，每个 $\delta$ 产生的响应是 $G(M,M')f(M')dV'$，积分即得。这就是狄拉克 delta 函数的筛选性质在 PDE 上的直接体现。

3.3.2 一维格林函数

  例 3.3.1 求区间 $[0,l]$ 上方程 $-u'' = f(x)$，边界 $u(0)=u(l)=0$ 的格林函数。

  解： 格林函数满足

$$\begin{cases} -G_{xx} = \delta(x-x'), & 0<x<l \ G(0,x') = G(l,x') = 0 \end{cases} \tag{3.3.4}$$

  当 $x \ne x'$ 时右端为零，方程为 $G_{xx}=0$，解是分段线性函数：

$$G(x,x') = \begin{cases} c_1 x, & 0 \le x < x' \ c_2(x-l), & x' < x \le l \end{cases} \tag{3.3.5}$$

  （这里已用了 $G(0)=0$ 与 $G(l)=0$。）两个待定常数由两个条件确定：

连续条件：$G$ 本身在 $x=x'$ 处连续（这是物理上位移/温度不能突变的要求）：

$$c_1x' = c_2(x'-l) \tag{3.3.6}$$

跳跃条件：对 (3.3.4) 从 $x'-\epsilon$ 到 $x'+\epsilon$ 积分，令 $\epsilon\to0$：

$$-\left[G_x\right]_{x'-}^{x'+} = 1 ;\Longrightarrow; -(c_2 - c_1) = 1 ;\Longrightarrow; c_1 - c_2 = 1 \tag{3.3.7}$$

  联立 (3.3.6)(3.3.7)。由 (3.3.7) 得 $c_1 = c_2+1$，代入 (3.3.6)：

$$(c_2+1)x' = c_2(x'-l) ;\Longrightarrow; c_2x' + x' = c_2x' - c_2l ;\Longrightarrow; c_2 = -\frac{x'}{l}$$

$$c_1 = 1 - \frac{x'}{l} = \frac{l-x'}{l}$$

  所以

$$G(x,x') = \begin{cases} \dfrac{x(l-x')}{l}, & 0\le x \le x' \[6pt] \dfrac{x'(l-x)}{l}, & x' \le x \le l \end{cases} \tag{3.3.8}$$

  检验对称性：$G(x,x') = G(x',x)$ ✓。这不是巧合——格林函数在任何自伴算子下都对称，这是施图姆-刘维尔理论的一个推论（第 4 章会讲）。

  应用：设 $f(x)=1$，则

$$u(x) = \int_0^l G(x,x'),dx' = \int_0^x\frac{x'(l-x)}{l}dx' + \int_x^l\frac{x(l-x')}{l}dx'$$

  第一项：$\frac{l-x}{l}\cdot\frac{x^2}{2}$。第二项：$\frac{x}{l}\left[l(l-x) - \frac{l^2-x^2}{2}\right] = \frac{x}{l}\cdot\frac{l^2-2lx+x^2}{2} = \frac{x(l-x)^2}{2l}$。

$$u(x) = \frac{(l-x)x^2 + x(l-x)^2}{2l} = \frac{x(l-x)(x + l - x)}{2l} = \frac{x(l-x)}{2} \tag{3.3.9}$$

  验证：$-u'' = -(-1) = 1 = f$ ✓，且 $u(0)=u(l)=0$ ✓。这正是"弦在均匀荷载下的挠度"，抛物线形状符合直觉。

3.3.3 二维与三维基本解

  全空间（无边界）的格林函数称为基本解，记作 $\Phi$。由对称性可以设 $\Phi$ 只依赖距离 $r$。

  三维：$\Delta\Phi = -\delta(\mathbf{r})$。在 $r\ne0$ 处 $\Delta\Phi=0$。球对称调和函数的形式是 $A + B/r$，无穷远处取零，所以 $\Phi = B/r$。

  要把 $B$ 定出来，用高斯散度定理：在以原点为心、半径 $R$ 的小球上积分 $\Delta\Phi = -\delta$：

$$\int_{V}\Delta\Phi,dV = \oint_{\partial V}\frac{\partial\Phi}{\partial r}dS = \oint\frac{\partial}{\partial r}\left(\frac{B}{r}\right)dS = \oint\left(-\frac{B}{R^2}\right)4\pi R^2 = -4\pi B$$

  而 $\int_V-\delta,dV = -1$。故 $B = \dfrac{1}{4\pi}$：

$$\Phi(\mathbf{r}) = \frac{1}{4\pi r}, \qquad \Delta\left(\frac{1}{4\pi r}\right) = -\delta(\mathbf{r}) \tag{3.3.10}$$

  这就是静电场中点电荷电位的形状（只差一个 $1/\varepsilon_0$）。事实上库仑定律与格林函数是同一个数学对象。

  二维：同理，二维球对称调和函数是 $A + B\ln r$，得

$$\Phi(\mathbf{r}) = -\frac{1}{2\pi}\ln r, \qquad \Delta\left(-\frac{1}{2\pi}\ln r\right) = -\delta(\mathbf{r}) \tag{3.3.11}$$

  系数 $-\frac{1}{2\pi}$ 由周长为 $2\pi R$ 定出。

  一维：$-\Phi'' = -\delta(x)$，即 $\Phi'' = \delta(x)$，得 $\Phi = -\dfrac{|x|}{2}$。

为什么维度不同形式不同：因为球面面积随维度变化（$4\pi r^2$ 与 $2\pi r$）。这也是为什么二维拉普拉斯方程的解是 $\ln r$（与 2.3 节的圆环问题一致），而三维是 $1/r$——它们都是对应维度的基本解。

3.3.4 边界处理：镜像法

  基本解满足无界区域的方程，但不满足边界条件。要获得有界区域的格林函数，需要加上齐次方程的解来"修正"边界。

  例 3.3.2 半空间 $z>0$，边界 $z=0$ 上 $G=0$。求格林函数。

  解： 在源点 $M'=(x',y',z')$ 处放点源。它的基本解是 $\dfrac{1}{4\pi|\mathbf{r}-\mathbf{r}'|}$，但在 $z=0$ 处不为零。

  镜像法：在对称位置 $M''=(x',y',-z')$ 放一个等量异号的镜像源 $-\delta$。两个源叠加后：

$$G = \frac{1}{4\pi}\left[\frac{1}{|\mathbf{r}-\mathbf{r}'|} - \frac{1}{|\mathbf{r}-\mathbf{r}''|}\right] \tag{3.3.12}$$

  在 $z=0$ 平面上，$\mathbf{r}$ 与 $\mathbf{r}'$、$\mathbf{r}''$ 的距离相等（因为 $z'$ 与 $-z'$ 到 $z=0$ 对称），两项相消，$G=0$ ✓。

  这就是静电场里的"镜像电荷法"——接地导体板前放一个电荷，等效于板后来一个异号电荷。

  再看一维的例 3.3.1 用镜像法：区间 $[0,l]$，源在 $x'$。由于是两个边界，需要无穷多个镜像（每次反射都产生新的镜像），位置为 $\pm x' + 2nl$。求和后得到的正是 (3.3.8) 的分段线性函数——不过用镜像法求和会得到无穷级数形式，不如直接分段求解简洁。

镜像法只对"几何对称"的边界有效（平面、球面、圆柱面）。对一般形状的边界，必须回到分离变量法或者数值方法。这也是为什么下面的"本征展开"是更通用的构造方式。

3.3.5 本征展开构造格林函数

  有界区域的通用构造法：把 delta 函数按本征函数展开。

  设算子 $L$ 的本征值问题 $L\varphi_n = \lambda_n\varphi_n$，$\varphi_n|_{\partial\Omega}=0$，且 ${\varphi_n}$ 完备正交。把 $\delta(M-M')$ 展开：

$$\delta(M-M') = \sum_n a_n\varphi_n(M), \quad a_n = \frac{1}{N_n}\int_\Omega\delta(M-M')\varphi_n(M)dV = \frac{\varphi_n(M')}{N_n}$$

  其中 $N_n = \int\varphi_n^2 dV$ 是模的平方。于是

$$\delta(M-M') = \sum_n \frac{\varphi_n(M)\varphi_n(M')}{N_n} \tag{3.3.13}$$

  再设 $G = \sum_n b_n\varphi_n(M)$，代入 $LG = -\delta$：

$$\sum_n b_n\lambda_n\varphi_n = -\sum_n\frac{\varphi_n(M)\varphi_n(M')}{N_n}$$

  逐项比较（正交性保证可比较）：

$$b_n = -\frac{\varphi_n(M')}{\lambda_n N_n}$$

  所以

$$G(M,M') = -\sum_{n}\frac{\varphi_n(M)\varphi_n(M')}{\lambda_n N_n} \tag{3.3.14}$$

  这就是用本征函数构造格林函数的一般公式。它把"求格林函数"化归为"解本征值问题"，而后者在分离变量法里已经练得很熟了。

  用一维例验证：$L = -\dfrac{d^2}{dx^2}$，$\varphi_n = \sin\frac{n\pi x}{l}$，$\lambda_n = (n\pi/l)^2$，$N_n = l/2$。代入：

$$G(x,x') = \sum_{n=1}^\infty \frac{2}{l}\cdot\frac{l^2}{n^2\pi^2}\sin\frac{n\pi x}{l}\sin\frac{n\pi x'}{l} = \frac{2l}{\pi^2}\sum_{n=1}^\infty\frac{\sin\frac{n\pi x}{l}\sin\frac{n\pi x'}{l}}{n^2} \tag{3.3.15}$$

  这个级数与 (3.3.8) 的分段线性函数是同一个东西——只是用了不同的展开方式。傅里叶级数在这里把一个分段函数展成了正弦级数。

3.4 小结

构造方式 适用场景 缺点
分段积分 + 跳跃条件 一维、低维 高维难以手工处理
基本解 + 镜像法 对称几何（平面/球/柱） 需要几何对称
本征函数展开 任意有界区域 得到无穷级数，收敛性需讨论

易错点

  1. 格林函数方程的符号：$\Delta G = -\delta$ 还是 $+\delta$，取决于原方程写 $\Delta u = -f$ 还是 $\Delta u = f$，要统一；
  2. 跳跃条件的方向：由 $-[G_x]$ 还是 $+[G_x]$ 得 1，取决于方程前的符号，推导一遍最保险；
  3. 三维基本解的常数是 $1/(4\pi)$，不是 $1/(4\pi^2)$ 或别的——用高斯定理算一遍就不会记错；
  4. 一维基本解是 $-\lvert x\rvert/2$，不是 $-x/2$，绝对值不能丢。

  第 3 章到此结束。第 4 章将回到级数解法，但目标不同：不再满足于"在直角/极/球坐标下能分离的几个例子"，而是建立施图姆-刘维尔理论，把所有这类问题的本征函数放在一个统一的框架里，并处理贝塞尔函数与勒让德多项式展开的完整理论。

  格林函数的构造方法参见[1]吴小庆.数学物理方程及其应用参考资料。
