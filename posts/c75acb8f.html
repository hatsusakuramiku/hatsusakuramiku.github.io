前置知识：1.2 节（线性差分方程）、1.3 节（Adams 格式与系数）。

1.4 待定系数法：系统化的构造流程

  1.3 节用插值法导出了 Adams 格式的系数。但插值法依赖"先想清楚用哪些点"，而且计算 $\int P_{r-1}$ 的代数也不轻松。

  待定系数法是更系统的途径：直接设一般形式、用"多项式精确"的要求反推系数。它不依赖任何插值直觉，可以机械执行。

1.4.1 一般的 $r$ 步线性多步法

  $r$ 步线性多步法的一般形式（为方便，把方程写成 $y^{\prime}=f(t,y)$）：

$$\sum_{j=0}^{r}\alpha_j y_{k+j} = h\sum_{j=0}^{r}\beta_j f_{k+j} \tag{1.4.1}$$

  约定：$\alpha_r = 1$（除以 $\alpha_r$ 归一化）。若 $\beta_r = 0$，格式显式；若 $\beta_r\ne0$，格式隐式。

  待定系数：$\alpha_0,\dots,\alpha_{r-1}$（$r$ 个）和 $\beta_0,\dots,\beta_r$（$r+1$ 个），共 $2r+1$ 个未知数。

记号需要注意：不同教材的指标起点不一致。本文统一用**"$r$ 步 = 用到 $y_{k}, \dots, y_{k+r}$ 共 $r+1$ 个值"**，与 1.3 节的 AB$r$（$r$ 阶，用 $r$ 个 $f$ 值）不冲突——那里的 AB$r$ 在本文记号下是 $r-1$ 步。

做题时先看清教材的步数定义，否则系数会错一位。

1.4.2 阶数与相容性条件

  定义：把精确解代入 (1.4.1)，定义局部截断误差为

$$T_{k+r} = \sum_{j=0}^{r}\alpha_j y(t_{k+j}) - h\sum_{j=0}^{r}\beta_j y^{\prime}(t_{k+j}) \tag{1.4.2}$$

  若 $T = O(h^{p+1})$，称格式的阶为 $p$。

  用泰勒展开求阶数：把 $y(t_{k+j})$ 和 $y^{\prime}(t_{k+j})$ 在 $t_k$ 处展开（$t_{k+j} = t_k + jh$）：

$$y(t_{k+j}) = \sum_{m=0}^{\infty}\frac{(jh)^m}{m!}y^{(m)}(t_k), \qquad y^{\prime}(t_{k+j}) = \sum_{m=0}^\infty\frac{(jh)^m}{m!}y^{(m+1)}(t_k)$$

  代入 (1.4.2)，按 $h^m y^{(m)}$ 的幂次整理。要求对尽可能高的 $m$ 系数为零：

$$\sum_{j=0}^r j^m\alpha_j = m\sum_{j=0}^r j^{m-1}\beta_j, \qquad m = 0,1,2,\dots \tag{1.4.3}$$

  这就是阶数条件。前几个写出来：

$m$ 条件 名称
0 $\sum\alpha_j = 0$ 相容性条件
1 $\sum j\alpha_j = \sum\beta_j$ 一阶条件
2 $\sum j^2\alpha_j = 2\sum j\beta_j$ 二阶条件

  $m=0$ 就是相容性：$\sum\alpha_j=0$。它的意义是"$f\equiv0$ 时，常数是解"。

两个方程组的计数：

  • 未知数 $2r+1$ 个，但 $\alpha_r=1$ 已固定，实际 $2r$ 个自由
  • 每个 $m$ 给一个方程

理论上可以解到 $m = 2r-1$，即最高阶 $2r-1$。

但Dahlquist 第一障碍定理：$r$ 步线性多步法的阶最高是

$$p_{\max} = \begin{cases} r+1, & r \text{ 为奇数} \ r+2, & r \text{ 为偶数} \end{cases}$$

（零稳定的前提下。）阶数超过这个值，格式必然不稳定，不能用。

这就是不能无限追求高阶的根本原因——不是算不出来，是算出来也没法用。

1.4.3 待定系数法算例：Milne-Simpson

  用 2 步格式（$r=2$，用 $y_k, y_{k+1}, y_{k+2}$）构造一个隐式格式。

  设

$$y_{k+2} - y_k = h(\beta_0f_k + \beta_1f_{k+1} + \beta_2f_{k+2}) \tag{1.4.4}$$

  这里 $\alpha_0=-1, \alpha_1=0, \alpha_2=1$，满足相容性 $\sum\alpha = 0$ ✓

  用 $m=1,2,3$ 三个条件解 $\beta_0,\beta_1,\beta_2$：

  • $m=1$：$0\cdot(-1)+1\cdot0+2\cdot1 = (-1+0+1)\beta_0+\dots$ 仔细算：

$$\sum j\alpha_j = 0\cdot(-1)+1\cdot0+2\cdot1 = 2$$
$$\sum\beta_j = \beta_0+\beta_1+\beta_2$$

给 $2 = \beta_0+\beta_1+\beta_2$。

  • $m=2$：

$$\sum j^2\alpha_j = 0+0+4 = 4, \qquad 2\sum j\beta_j = 2(0\cdot\beta_0+1\cdot\beta_1+2\cdot\beta_2) = 2\beta_1+4\beta_2$$

给 $4 = 2\beta_1+4\beta_2$，即 $\beta_1+2\beta_2 = 2$。

  • $m=3$：

$$\sum j^3\alpha_j = 0+0+8 = 8, \qquad 3\sum j^2\beta_j = 3(\beta_1+4\beta_2)$$

给 $8 = 3\beta_1+12\beta_2$。

  解方程组：由第二式 $\beta_1 = 2-2\beta_2$，代入第三式：

$$8 = 3(2-2\beta_2)+12\beta_2 = 6 - 6\beta_2+12\beta_2 = 6+6\beta_2 ;\Longrightarrow; \beta_2 = \frac13$$

$$\beta_1 = 2 - \frac23 = \frac43, \qquad \beta_0 = 2 - \frac43 - \frac13 = \frac13$$

  得到 Milne-Simpson 格式：

$$y_{k+2} = y_k + \frac{h}{3}\left(f_k + 4f_{k+1} + f_{k+2}\right) \tag{1.4.5}$$

  这正是 Simpson 求积公式作用在 $[t_k,t_{k+2}]$ 上。它是 4 阶的（对 3 次多项式精确）。

Milne-Simpson 有个著名的问题：它是 4 阶，但弱不稳定（不是零稳定）。

它的特征多项式 $r^2-1=0$ 有两个根 $r=\pm1$——模都为 1，且都是单根，所以零稳定（满足判据）。但左半平面的稳定区域很小，实际用时会振荡。

教训：满足零稳定判据只是必要条件。实际可用性还要看稳定区域的大小。

1.5 预估-校正格式

  隐式格式（AM 系列、Milne-Simpson）精度高、稳定性好，但每步要解方程。能不能既拿到隐式格式的精度，又避免迭代？

  预估-校正（Predictor-Corrector） 的思路是：

  1. 用一个显式格式（便宜的）算出 $y_{k+r}$ 的估测值 $\bar y_{k+r}$ —— 预估（Predictor）
  2. 把它代入隐式格式的右端，算出更准的值 —— 校正（Corrector）
  3. 只校正一次（或几次），不迭代到收敛

  注意：PECE（Predict-Evaluate-Correct-Evaluate）是一个独立的格式，它不是在求隐式格式的精确解。它的精度和稳定性需要单独分析。

1.5.1 以 AB2 + AM2 为例

  预估（AB2）：$\bar y_{k+2} = y_{k+1} + \frac{h}{2}(3f_{k+1} - f_k)$

  计算 $\bar f_{k+2} = f(t_{k+2}, \bar y_{k+2})$

  校正（AM2 即梯形）：$y_{k+2} = y_{k+1} + \frac{h}{2}(\bar f_{k+2} + f_{k+1})$

  计算 $f_{k+2} = f(t_{k+2}, y_{k+2})$（供下一步用）

  这是一个 2 步 2 阶的 PECE 格式。

PECE 的阶数判定规则：

设预估器是 $p$ 阶、校正器是 $q$ 阶，则

  • 若 $p \ge q-1$，PECE 的阶 = $q$
  • 若 $p < q-1$，PECE 的阶 = $p+1$

所以想让 PECE 达到校正器的阶，预估器的阶不能太低。

例如：AB4（4 阶）+ AM4（4 阶，即 AM 用 4 个点）→ PECE 是 4 阶；但 AB3（3 阶）+ AM4 → 只有 4 阶；AB2（2 阶）+ AM4 → 只有 3 阶。

常用搭配是 AB$r$ + AM$r$（同阶配对），这样 PECE 保持 $q$ 阶且每步只算两次 $f$。

1.5.2 校正迭代的收敛性

  为什么不迭代到收敛？分析一下。

  校正公式的一般形式（只需解 $y_{k+r}$）：

$$y_{k+r} = \Psi + h\beta_r f(t_{k+r}, y_{k+r})$$

  不动点迭代的收敛条件是映射的导数模小于 1：

$$\left|h\beta_r\frac{\partial f}{\partial y}\right| < 1 ;\Longrightarrow; |h\beta_r L| < 1 \tag{1.5.1}$$

  其中 $L$ 是 Lipschitz 常数。

  对 AM4，$\beta_r = 9/24$，条件是 $hL < 24/9\approx 2.67$。通常 $hL$ 不大，收敛很快。

  但刚性问题（$L$ 很大）时，可能需要 $h$ 极小才能收敛——这时不如直接用牛顿迭代，或者选显式的 PECE（不迭代）。

为什么 PECE 比"迭代到收敛"更实用：

  • 代价：每步 $f$ 的调用次数固定（PECE 是 2 次，而迭代到收敛可能 5~10 次）
  • 精度：PECE 的精度通常只比完全收敛略低（差一个很小的因子）
  • 可预测：成本固定，适合实时/嵌入式场景

这是"足够好"哲学的典型例子——不做最精确的，做性价比最高的。

1.6 代码实现

运行对比会发现：Milne-Simpson 的误差不一定比 AB4-AM4 小，尽管两者都是 4 阶。

原因有二：

  1. Milne-Simpson 的误差常数更大（$-\frac{1}{90}$ vs $-\frac{19}{720}$，量级相近但结构不同）
  2. 它的稳定区域小，对 $y'=-10y$ 这类衰减问题，步长稍大就振荡

这印证了前面的教训：阶数相同，实际表现可能差很多——要看误差常数和稳定区域。

1.7 小结

构造方法 步骤 得到
插值法 选点 → 构造插值多项式 → 区间积分 AB/AM 系数（1.3 节）
待定系数法 设一般形式 → 泰勒展开 → 令系数为零 任意结构的多步法
概念 要点
相容性条件 $\sum\alpha_j=0$，最基础的必要条件
阶数条件 $\sum j^m\alpha_j = m\sum j^{m-1}\beta_j$，$m=0,1,\dots,p$
Dahlquist 第一障碍 $r$ 步零稳定格式最高阶为 $r+1$（$r$ 奇）或 $r+2$（$r$ 偶）
PECE 阶数规则 $p\ge q-1$ 时阶为 $q$；否则 $p+1$
校正迭代收敛 要求 $\vert h\beta_rL\vert<1$

易错点

  1. 补相容性是最基础的检验：$\sum\alpha_j=0$，任何格式都必须满足；
  2. Dahlquist 障碍：阶数超了必然不稳定，不是"精度会下降"而是"根本不能用"；
  3. PECE 不是隐式格式的近似，它是一个独立格式，阶数要按规则单独判定；
  4. Milne-Simpson 弱不稳定，零稳定判据通过了但实用价值有限；
  5. 起步值阶数不够会毁掉高阶格式——用同阶或更高阶的单步法起步。

  下一节 1.5 进入收敛性理论的系统化：相容性 + 零稳定性 ⟺ 收敛性（Dahlquist 等价定理），这是整个多步法理论的皇冠。
