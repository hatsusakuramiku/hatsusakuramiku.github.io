2.2 非齐次条件的处理

  2.1 节处理的是最"干净"的情形：方程齐次、边界条件齐次。实际的物理问题很少这么配合——弦的一端可能被外力拉着做周期运动，杆的内部可能有热源，这些都会让方程或边界条件带上非齐次项。本节解决两个问题：

  1. 边界条件非齐次怎么办？答案是变量代换，把非齐次边界"吃掉"；
  2. 方程非齐次怎么办？答案是本征函数展开，把非齐次项按本征函数展开后逐个求解。

2.2.1 为什么非齐次边界条件无法直接分离变量

  回看 2.1 节的关键一步。设 $u(x,t) = X(x)T(t)$，代入两端固定的齐次边界条件 $u(0,t) = u(l,t) = 0$：

$$X(0)T(t) = 0, \quad X(l)T(t) = 0$$

  要使上式对任意 $t$ 成立，只能让 $X(0) = X(l) = 0$。这样边界条件被"吸收"进了 $X(x)$ 的常微分方程，问题就被拆开了。

  但如果边界条件是非齐次的，例如左端固定、右端以给定规律运动：

$$u(0, t) = 0, \quad u(l, t) = \mu(t) \neq 0 \tag{2.2.1}$$

代入 $u = X T$ 得

$$X(l)T(t) = \mu(t)$$

  这里出现了矛盾：$X(l)$ 是常数，$T(t)$ 是单个变量 $t$ 的函数，而 $\mu(t)$ 是任意的已知函数。一般情况下，不存在一个常数和另一个关于 $t$ 的函数相乘后恰好等于给定的 $\mu(t)$。

  除非 $\mu(t)$ 本身恰好是"常数 × 某个 $t$ 的函数"这种平凡形式——那又回到了可分离的情形，没有一般性。

核心区别：齐次边界条件只约束空间部分 $X(x)$（常数条件），非齐次边界条件约束的是 $X$ 与 $T$ 的乘积（动摇了可分离性）。这就是为什么必须先做代换。

2.2.2 变量代换：构造一个"吃掉"非齐次项的函数

  思路很直接：找一个辅助函数 $v(x,t)$，让它恰好满足原来的非齐次边界条件，然后令 $w = u - v$。这样 $w$ 就满足齐次边界条件了。

  以 (2.2.1) 为例，设

$$v(x,t) = \frac{x}{l}\mu(t) \tag{2.2.2}$$

  验证一下：$v(0,t) = 0$ ✓（与左端条件一致），$v(l,t) = \mu(t)$ ✓（与右端条件一致）。

  令 $w(x,t) = u(x,t) - v(x,t)$，则

$$w(0,t) = u(0,t) - v(0,t) = 0 - 0 = 0$$
$$w(l,t) = u(l,t) - v(l,t) = \mu(t) - \mu(t) = 0$$

  边界条件齐次化了。 但代价是方程变了。把 $u = w + v$ 代回原方程 $u_{tt} = a^2u_{xx}$：

$$\frac{\partial^2}{\partial t^2}(w + v) = a^2\frac{\partial^2}{\partial x^2}(w + v)$$

$$w_{tt} - a^2w_{xx} = -(v_{tt} - a^2 v_{xx}) \tag{2.2.3}$$

  再算右端。由 (2.2.2)：

$$v_{tt} = \frac{x}{l}\mu''(t), \quad v_{xx} = 0$$

  于是

$$w_{tt} - a^2w_{xx} = -\frac{x}{l}\mu''(t) \equiv f(x,t) \tag{2.2.4}$$

  边界条件齐次了，方程变成非齐次的。 这是必然的代价——非齐次性不会凭空消失，只会从一个位置转移到另一个位置。下面 2.2.3 处理这个新的非齐次方程。

  初始条件也要跟着变：

$$w(x,0) = u(x,0) - v(x,0) = \varphi(x) - \frac{x}{l}\mu(0)$$
$$w_t(x,0) = \psi(x) - \frac{x}{l}\mu'(0)$$

常见的辅助函数选法

  $v(x,t)$ 的选择不唯一，只要满足边界条件即可。下面是几种典型情形（设边界为 $u(0,t) = \mu_1(t)$，$u(l,t) = \mu_2(t)$）：

边界条件类型 推荐 $v(x,t)$ 说明
$u(0,t)=0,\quad u(l,t)=\mu(t)$ $\dfrac{x}{l}\mu(t)$ 线性插值
$u(0,t)=\mu_1,\quad u(l,t)=\mu_2$（常数） $\dfrac{\mu_2-\mu_1}{l}x + \mu_1$ 取 $v$ 不依赖 $t$，此时 $v_{tt}=0$，方程不变
一般情形 $\mu_1(t),\mu_2(t)$ $\dfrac{\mu_2(t)-\mu_1(t)}{l}x + \mu_1(t)$ 方程右端会出现 $-v_{tt}$
自由端 $u_x(l,t)=0$ 需按导数的形式构造 见下文

一个重要技巧：如果 $\mu_1, \mu_2$ 都是常数（比如弦的一端被固定在一个抬高位置上），那么取 $v(x) = \frac{\mu_2-\mu_1}{l}x + \mu_1$ 时 $v_{tt} \equiv 0$，原方程完全不发生变化，只需要改初始条件。这是最省事的情形，值得优先利用。

例 2.2.1：一端以正弦规律运动的弦

  求解

$$\begin{cases} u_{tt} = a^2u_{xx}, & 0<x<l,\quad t>0 \ u(0,t) = 0, \quad u(l,t) = A\sin\omega t, & t \ge 0 \ u(x,0) = 0, \quad u_t(x,0) = 0, & 0 \le x \le l \end{cases}$$

  解： 取 $v(x,t) = \frac{x}{l}A\sin\omega t$。则

$$v_{tt} = -\frac{x}{l}A\omega^2\sin\omega t, \quad v_{xx} = 0$$

  令 $w = u - v$，得

$$\begin{cases} w_{tt} - a^2w_{xx} = \dfrac{x}{l}A\omega^2\sin\omega t, & 0<x<l \ w(0,t) = w(l,t) = 0 \ w(x,0) = 0, \quad w_t(x,0) = -\dfrac{x}{l}A\omega \end{cases}$$

  边界条件已齐次，接下来用本征函数展开处理非齐次方程。先求对应的本征值问题：

$$X'' + \lambda X = 0, \quad X(0) = X(l) = 0 \quad\Longrightarrow\quad \lambda_n = \left(\frac{n\pi}{l}\right)^2, \quad X_n = \sin\frac{n\pi x}{l}$$

  把 $w$ 和右端项都按本征函数展开：

$$w(x,t) = \sum_{n=1}^\infty T_n(t)\sin\frac{n\pi x}{l}$$

  右端项 $f(x,t) = \dfrac{A\omega^2}{l}x\sin\omega t$ 也展开：

$$f(x,t) = \sum_{n=1}^\infty f_n(t)\sin\frac{n\pi x}{l}, \quad f_n(t) = \frac{2}{l}\int_0^l \frac{A\omega^2}{l}x\sin\omega t \cdot \sin\frac{n\pi x}{l}dx$$

  算这个积分。设 $k = n\pi/l$：

$$\int_0^l x\sin kx \thinspacedx = \left[-\frac{x\cos kx}{k} + \frac{\sin kx}{k^2}\right]_0^l = -\frac{l\cos n\pi}{k} = -\frac{l(-1)^n}{k} = -\frac{l^2(-1)^n}{n\pi}$$

  所以

$$f_n(t) = \frac{2}{l}\cdot\frac{A\omega^2}{l}\sin\omega t \cdot\left(-\frac{l^2(-1)^n}{n\pi}\right) = -\frac{2A\omega^2(-1)^n}{n\pi}\sin\omega t$$

  代回方程，比较 $\sin\frac{n\pi x}{l}$ 的系数（由正交性，各阶独立）：

$$T_n''(t) + \left(\frac{n\pi a}{l}\right)^2 T_n(t) = -\frac{2A\omega^2(-1)^n}{n\pi}\sin\omega t \tag{2.2.5}$$

  初始条件同样展开。$w(x,0) = 0$ 给出 $T_n(0) = 0$；$w_t(x,0) = -\frac{A\omega}{l}x$ 展开得

$$T_n'(0) = \frac{2}{l}\int_0^l\left(-\frac{A\omega}{l}x\right)\sin\frac{n\pi x}{l}dx = \frac{2A\omega(-1)^n}{n\pi}$$

  现在解常微分方程 (2.2.5)。记固有频率 $\omega_n = \frac{n\pi a}{l}$，它的通解是

$$T_n(t) = C_n\cos\omega_n t + D_n\sin\omega_n t + T_n^*(t)$$

  其中 $T_n^$ 是特解。当 $\omega \neq \omega_n$（非共振）时，设 $T_n^ = B_n\sin\omega t$，代入：

$$B_n(-\omega^2 + \omega_n^2) = -\frac{2A\omega^2(-1)^n}{n\pi}$$

$$B_n = \frac{2A\omega^2(-1)^n}{n\pi(\omega^2 - \omega_n^2)}$$

  由 $T_n(0) = C_n = 0$ 得 $C_n = 0$。再由 $T_n'(0) = D_n\omega_n + B_n\omega = \frac{2A\omega(-1)^n}{n\pi}$：

$$D_n = \frac{2A\omega(-1)^n}{n\pi\omega_n} - \frac{B_n\omega}{\omega_n} = \frac{2A\omega(-1)^n}{n\pi\omega_n}\left[1 - \frac{\omega^2}{\omega^2 - \omega_n^2}\right] = -\frac{2A(-1)^n\omega_n}{n\pi(\omega^2-\omega_n^2)}$$

  于是

$$T_n(t) = \frac{2A(-1)^n}{n\pi(\omega^2-\omega_n^2)}\left[\omega^2\sin\omega t - \omega_n\omega\sin\omega_n t\right]$$

  最终解为

$$u(x,t) = \frac{x}{l}A\sin\omega t + \sum_{n=1}^\infty T_n(t)\sin\frac{n\pi x}{l}$$

共振情形：当 $\omega = \omega_n$（外部激励频率等于某阶固有频率）时，上述分母为零，说明解的形式要改。此时特解应取 $t\cos\omega_n t$ 的形式，振幅随时间线性增长——这就是共振现象。物理上弦会被越震越大，数学上表现为无界解。实际问题中阻尼会使它变得有界，但在无阻尼模型里就是发散的。

2.2.3 非齐次方程的本征函数展开法

  上一节已经用到了这个方法，这里系统讲一遍。考虑

$$\begin{cases} u_{tt} = a^2u_{xx} + f(x,t), & 0<x<l,\quad t>0 \ u(0,t) = u(l,t) = 0 \ u(x,0) = \varphi(x), \quad u_t(x,0) = \psi(x) \end{cases} \tag{2.2.6}$$

  步骤一：先解对应的齐次问题的本征值问题（注意：只看边界条件，忽略非齐次项和初始条件）：

$$X'' + \lambda X = 0, \quad X(0) = X(l) = 0 \quad\Longrightarrow\quad \lambda_n = (n\pi/l)^2,\quad X_n = \sin\frac{n\pi x}{l}$$

  步骤二：把 $u$、$f$、$\varphi$、$\psi$ 全部按这组本征函数展开：

$$u(x,t) = \sum_{n=1}^\infty T_n(t)\sin\frac{n\pi x}{l} \tag{2.2.7}$$
$$f(x,t) = \sum_{n=1}^\infty f_n(t)\sin\frac{n\pi x}{l}, \quad f_n(t) = \frac{2}{l}\int_0^l f(x,t)\sin\frac{n\pi x}{l}dx \tag{2.2.8}$$

  步骤三：把 (2.2.7)、(2.2.8) 代入方程，逐项求导（假设解足够光滑、级数可逐项微分）：

$$\sum_n \left[T_n'' + \omega_n^2 T_n - f_n\right]\sin\frac{n\pi x}{l} = 0, \quad \omega_n = \frac{n\pi a}{l}$$

  由 ${\sin\frac{n\pi x}{l}}$ 的线性无关性，括号内必须对每个 $n$ 为零：

$$T_n''(t) + \omega_n^2 T_n(t) = f_n(t), \quad n = 1,2,3,\cdots \tag{2.2.9}$$

  步骤四：初始条件也逐项比较：

$$T_n(0) = \varphi_n, \quad T_n'(0) = \psi_n \tag{2.2.10}$$

  其中 $\varphi_n, \psi_n$ 分别为 $\varphi, \psi$ 的傅里叶正弦系数。

  步骤五：对每个 $n$ 解常微分方程 (2.2.9) 配初始条件 (2.2.10)。由常数变易法：

$$T_n(t) = \varphi_n\cos\omega_n t + \frac{\psi_n}{\omega_n}\sin\omega_n t + \frac{1}{\omega_n}\int_0^t f_n(\tau)\sin\omega_n(t-\tau)d\tau \tag{2.2.11}$$

  最后把 $T_n$ 代回 (2.2.7) 得到形式解。

  这就是"本征函数展开法"（又称特征函数展开法）。它的本质是：用本征函数系作为一组"坐标基"，把无穷维的偏微分方程问题投影成无穷多个一维的常微分方程问题。

式 (2.2.11) 就是受迫振动的标准公式。前三项分别是：初始位移引起的自由振动、初始速度引起的自由振动、以及外力 $f$ 从 $0$ 到 $t$ 持续作用产生的受迫振动。可以看到外力每一项都带权重 $\sin\omega_n(t-\tau)$，即过去的激励以固有频率"回响"到现在。

例 2.2.2：常力作用下的弦

  一根两端固定的弦，从静止开始受均匀横向常力作用：

$$\begin{cases} u_{tt} = a^2u_{xx} + F_0, & 0<x<l,\quad t>0 \ u(0,t) = u(l,t) = 0 \ u(x,0) = 0, \quad u_t(x,0) = 0 \end{cases}$$

  解： 本征函数仍为 $\sin\frac{n\pi x}{l}$。展开常力 $F_0$：

$$f_n = \frac{2}{l}\int_0^l F_0\sin\frac{n\pi x}{l}dx = \frac{2F_0}{l}\cdot\frac{l}{n\pi}\left[1 - \cos n\pi\right] = \frac{2F_0}{n\pi}\left[1-(-1)^n\right]$$

  $n$ 偶时 $f_n = 0$；$n$ 奇时 $f_n = \frac{4F_0}{n\pi}$。

  由于 $\varphi_n = \psi_n = 0$，由 (2.2.11)：

$$T_n(t) = \frac{f_n}{\omega_n}\int_0^t\sin\omega_n(t-\tau)d\tau = \frac{f_n}{\omega_n}\cdot\frac{1-\cos\omega_n t}{\omega_n} = \frac{f_n}{\omega_n^2}\left(1-\cos\omega_n t\right)$$

  代入 $\omega_n = n\pi a/l$：

$$T_n(t) = \frac{l^2 f_n}{n^2\pi^2a^2}\left(1-\cos\frac{n\pi a}{l}t\right)$$

  对奇数 $n$，记 $n = 2m-1$，则 $f_n = \frac{4F_0}{n\pi}$：

$$u(x,t) = \frac{4F_0 l^2}{\pi^3 a^2}\sum_{m=1}^\infty \frac{1}{(2m-1)^3}\left[1-\cos\frac{(2m-1)\pi a}{l}t\right]\sin\frac{(2m-1)\pi x}{l}$$

  物理检验：括号内的 $1-\cos\omega_n t$ 在 $t=0$ 时为零，符合初始静止；当 $t\to\infty$ 时它围绕 $1$ 振荡，说明弦围绕某个偏离平衡位置的平均形状振动。这个平均形状正是方程 $a^2 u_{xx} + F_0 = 0$ 配齐次边界条件的静力学解：

$$\bar{u}(x) = \frac{F_0}{2a^2}x(l-x)$$

  可以验证，展开式里令 $1-\cos(\cdots) \to 1$ 得到的正是这条抛物线。这是"强迫力造成的稳态偏移 + 围绕它振动"的典型图像。

2.3 小结

  本节解决了两类非齐次性，完整的求解流程可以归纳为一张决策树：

情形 处理方法 关键点
方程齐次、边界齐次 直接分离变量 2.1 节的内容
方程非齐次、边界齐次 本征函数展开法 把 $f$ 按本征函数展开，逐项解 ODE
方程齐次、边界非齐次 变量代换齐次化 构造 $v$ 满足边界，令 $w = u-v$；方程会变非齐次
两者都非齐次 先齐次化再用展开法 先做代换，再处理新方程的非齐次项

易错点提醒

  1. 代换后忘了改初始条件。$w(x,0) = \varphi(x) - v(x,0)$，很多人直接把原初始条件套上去；
  2. 代换后忘了改方程。$w$ 满足的方程右端多了 $-v_{tt} + a^2v_{xx}$，不是原来的齐次方程；
  3. 当边界值是常数时，取 $v$ 只依赖 $x$，$v_{tt} = 0$，方程可以不变——这是最优选择，别错过；
  4. 本征函数展开时，$f(x,t)$ 要按 $x$ 展开（$t$ 当作参数），不要糊里糊涂当成对 $t$ 展开；
  5. 共振要单独讨论，$\omega = \omega_n$ 时分母为零，特解形式要改。

  下一节将把分离变量法推广到极坐标系，处理圆域上的拉普拉斯方程与圆形膜的振动，那里会遇到贝塞尔方程和欧拉方程。

  非齐次边界的齐次化技巧参见[1]吴小庆.数学物理方程及其应用参考资料。
