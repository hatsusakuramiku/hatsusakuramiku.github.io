前置知识：3.1 节（三个基本格式）、2.4 节（极值原理）、线性代数（谱半径、矩阵范数）。

稳定性的严格定义

  3.1 节用极值原理给出了显式格式的稳定性条件，但那个论证不算严格。本节先给出定义，再给三种系统的分析方法。

3.6 定义

  设差分格式可以写成（把第 $k$ 层所有网格值排成向量 $U^k$）：

$$U^{k+1} = C(\Delta t),U^k + \Delta t,F^k \tag{3.6.1}$$

  其中 $C$ 是转移矩阵（对显式格式是 $(I+rL_h)$ 的形式）。

  定义（稳定性）：若对任意 $T>0$，存在与 $\Delta t,\Delta x$ 无关的常数 $K$，使得对所有满足 $k\Delta t\le T$ 的 $k$：

$$|U^k| \le K,|U^0| \tag{3.6.2}$$

则称格式是稳定的。

这个定义的要点：

  1. 一致性：$K$ 必须与 $\Delta t$、$\Delta x$ 无关。若 $K$ 随网格加密而增大，那就不算稳定。
  2. 只在有限时间上：$k\Delta t\le T$。对 $t\to\infty$ 的行为是"渐近稳定性"，强度不同。
  3. 依赖范数：$|\cdot|$ 的选择很重要。$|\cdot|_\infty$ 与 $|\cdot|_2$ 可能给出不同结论。

注意：稳定性是"误差不放大"，不是"解的幅值不增大"。虽然对热传导问题，真解本身就在衰减，两者看起来相似。

3.7 三种方法的定位

方法 适用条件 优点 缺点
直接估计法 系数非负（极值原理适用） 最严格、给出 $L^\infty$ 范数界 只对特定格式有效
矩阵法 矩阵可对角化/正规 给出 $L^2$ 范数界 需算特征值
von Neumann 线性 + 常系数 + 周期边界 最快、给出充要条件 边界条件被忽略

  关键提醒：von Neumann 法最简单，但它的适用条件最严——必须是线性常系数周期边界。这一点经常被忽略（3.3 节会详细展开）。

3.8 直接估计法

  思路：直接从差分公式的系数符号推稳定。

  对显式格式 (3.1.3)：

$$u_i^{k+1} = r,u_{i-1}^k + (1-2r)u_i^k + r,u_{i+1}^k$$

  若 $r\le1/2$，三个系数非负且和为 1，所以

$$|u_i^{k+1}| \le r|u_{i-1}^k| + (1-2r)|u_i^k| + r|u_{i+1}^k| \le \max_j|u_j^k|$$

  取最大值得

$$\max_i|u_i^{k+1}| \le \max_i|u_i^k| \tag{3.8.1}$$

  递推即得 $\max_i|u_i^k|\le\max_i|u_i^0|$——在 $|\cdot|_\infty$ 范数下稳定，$K=1$ ✓

  若 $r>1/2$，系数 $1-2r<0$，上面的不等式不成立。可以构造一个反例显示会放大——不稳定。

直接估计法的价值：它给出的结论比 von Neumann 更强：

  • von Neumann 给 $L^2$ 范数稳定
  • 直接估计给 $L^\infty$ 范数稳定（更严格）

而且不需要假设周期边界——任何边界条件都行。

代价：只有当格式的系数结构"足够好"（非负组合）时才能用。对隐式格式，直接估计法需要额外技巧（解三对角方程组后估计）。

3.9 矩阵法

  思路：把差分格式写成矩阵形式，用矩阵的谱判稳定性。

  显式格式 (3.1.3) 写成矩阵形式：

$$U^{k+1} = (I + rA),U^k, \qquad U^0 = \varphi$$

  其中 $A$ 是一维二阶差分矩阵：

$$A = \begin{pmatrix}
-2 & 1 & & \\
1 & -2 & 1 & \\
& \ddots & \ddots & \ddots
\end{pmatrix}_{(N-1)\times(N-1)} \tag{3.9.1}$$

  于是 $U^k = (I+rA)^kU^0$，稳定性要求

$$\rho(I+rA) \le 1 \tag{3.9.2}$$

3.9.1 $A$ 的特征值

  $A$ 是一个经典的三对角 Toeplitz 矩阵，其特征值有解析式：

$$\lambda_j^{(A)} = -4\sin^2\frac{j\pi h}{2l}, \qquad j = 1,\dots,N-1 \tag{3.9.3}$$

  最小的是 $j=1$（约 $-4\cdot\frac{\pi^2h^2}{4l^2} = -(\pi h/l)^2$），最大的是 $j=N-1$（约 $-4$）。

  于是 $I+rA$ 的特征值：

$$\lambda_j = 1 - 4r\sin^2\frac{j\pi h}{2l}$$

  稳定条件：$|\lambda_j|\le1$ 对所有 $j$：

  • 上界：$1-4r\sin^2\le1$ ✓ 自动满足
  • 下界：$1-4r\sin^2\ge-1$，最坏情况 $\sin^2=1$，得 $r\le1/2$ ✓

  与前面完全一致。

矩阵法的一个重要细节：$\rho(I+rA)\le1$ 并不自动推出 $|(I+rA)^k|\le K$。

原因是：若 $A$ 不可对角化或有非正规性，$|M^k|$ 可能远大于 $\rho(M)^k$。

  • 对可对角化的矩阵：$|M^k|_2 = \rho(M)^k$（在 2-范数下）
  • 对非正规矩阵：$|M^k|$ 可能先增大再衰减——叫瞬态增长（transient growth）

$A$ 是对称矩阵（实对称），可以正交对角化——所以这里没问题。但对流扩散方程的矩阵不对称，就必须小心了。这是很多论文里出错的来源。

3.9.2 隐式格式的矩阵法

  隐式格式写成

$$(I - rA),U^{k+1} = U^k ;\Longrightarrow; U^{k+1} = (I-rA)^{-1}U^k$$

  $I-rA$ 的特征值是 $1+4r\sin^2(\cdots)\ge1$，所以其逆的特征值 $\le1$——无条件稳定 ✓

  CN 格式：

$$U^{k+1} = (I-\tfrac r2A)^{-1}(I+\tfrac r2A),U^k$$

  转移矩阵的特征值是 $\frac{1-2r\sin^2}{1+2r\sin^2}$，绝对值 $\le1$——无条件稳定 ✓

3.10 von Neumann（Fourier）方法

3.10.1 基本步骤

  思路：把误差展开成 Fourier 级数，看每个频率分量的放大因子。

  第 1 步：设误差的某个 Fourier 模态

$$e_i^k = \lambda^k e^{i\omega x_i} = \lambda^k e^{i\omega ih} \tag{3.10.1}$$

  第 2 步：代入差分格式，解出放大因子 $\lambda(\omega)$。

  第 3 步：稳定性 $\iff$ $|\lambda(\omega)|\le1$ 对所有 $\omega\in[-\pi/h,\pi/h]$ 成立。

3.10.2 三个格式的放大因子

显式：

$$\lambda = 1-4r\sin^2\frac{\omega h}{2}$$

  $|\lambda|\le1$ ⟺ $4r\sin^2\le2$ ⟺ $r\le\frac{1}{2}$ ✓

隐式：

$$\lambda = \frac{1}{1+4r\sin^2\frac{\omega h}{2}}$$

  分母恒 $\ge1$，$|\lambda|\le1$ 无条件 ✓

CN：

$$\lambda = \frac{1-2r\sin^2\frac{\omega h}{2}}{1+2r\sin^2\frac{\omega h}{2}}$$

  分子绝对值 $\le$ 分母，$|\lambda|\le1$ 无条件 ✓

3.10.3 适用范围（关键限制）

von Neumann 方法的适用条件非常严格，超出范围时用它估误差属于超纲：

  1. 线性：非线性方程的稳定性不能这样判
  2. 常系数：变系数时 $\lambda$ 依赖位置，不能做全局 Fourier 分解
  3. 周期边界：非周期边界会反射波，Fourier 模态不是特征函数
  4. 两个自变量（一维空间 + 时间）
  5. 最多两层时间步：多步法的放大因子是矩阵，不是标量

违反其中任何一条，von Neumann 给出的结论都只是必要条件甚至完全无效。

例：对流扩散方程（一阶项），矩阵不对称，"von Neumann 稳定"的格式仍然可能因瞬态增长而爆炸。

3.10.4 一个技巧：放大因子的几何意义

  把 $\lambda(\omega)$ 画在复平面上，$|\lambda|\le1$ 就是单位圆内。

  对显式格式（$r$ 取不同值）：

$r$ $\lambda$ 的范围 稳定
$r=0.1$ $[0.6,\ 1]$（实轴线段） ✓
$r=0.5$ $[-1,\ 1]$（正好填满直径） ✓ 临界
$r=0.6$ $[-1.4,\ 1]$（超出圆） ✗

  $r=0.5$ 时 $\lambda$ 恰好遍历 $[-1,1]$——这是"临界稳定"。再多一点就出去。

这个几何图像解释了为什么 $r=1/2$ 是精确的边界：

$\lambda = 1-4r\sin^2(\theta)$，当 $\sin^2$ 从 0 变到 1 时，$\lambda$ 从 1 线性降到 $1-4r$。

要让它不低于 $-1$：$1-4r\ge-1$，即 $r\le1/2$。

二维情况下，两个方向的 $\sin^2$ 会叠加（$\lambda = 1-4r_x\sin^2-4r_y\sin^2$），最坏情况两者同时取 1，所以条件是 $4(r_x+r_y)\le2$，正方形网格下 $r\le1/4$。

3.11 代码：数值验证放大因子

运行后会看到：

$r=0.5$ 时显式的放大因子恰好是 1——临界稳定。$r=0.51$ 就超到 1.04 了。

隐式的放大因子恒 $\le1$（在 $r=0.5$ 时等于 1），CN 更是严格 $<1$。

矩阵法那部分会验证：$r=0.5$ 时 $\rho(I+rA)=1.0$，$r=0.51$ 时 $1.04$——与 Fourier 分析完全一致。

3.12 小结

方法 输入 输出 适用
直接估计 差分的系数符号 $L^\infty$ 稳定 系数非负的显式格式
矩阵法 转移矩阵的谱 $L^2$ 稳定 可对角化（最好对称）
von Neumann 代入 Fourier 模态 放大了因子 $\lambda(\omega)$ 线性常系数周期

易错点

  1. von Neumann 只适用于线性常系数周期边界，超出范围时结论无效；
  2. $\rho(M)\le1$ 不总等于 $|M^k|$ 有界——非正规矩阵会瞬态增长；
  3. 二维显式格式的条件是 $r\le1/4$，不是 $1/2$（两方向叠加）；
  4. "临界稳定"（$r=1/2$）在实践中往往不够——舍入误差会慢慢累积；
  5. 直接估计法给的界最强（$L^\infty$），但只对特定结构有效。

  下一节 3.3 把 von Neumann 方法完整展开——它是工程实践中最常用的工具，但也是最容易被误用的。会详细讲它的推导、适用范围、以及违反条件时的补救。
