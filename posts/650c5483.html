前置知识：4.1 节（CFL）、4.2 节（耗散与 Godunov 定理）、4.3 节（一阶双曲组与守恒形式）。

中心差分错在哪

  4.2 节证明了：对流方程用中心差分 + 前向 Euler 无条件不稳定。

  根因是违反因果：$u_{j+1}$ 是下游的值，物理上不可能影响 $u_j$。

  迎风的思想：只用信息来的方向。

4.19 一阶迎风格式

4.19.1 标量方程

  对 $u_t+cu_x=0$：

  • 若 $c>0$，信息从左来 → 用 $u_{j-1}$
  • 若 $c<0$，信息从右来 → 用 $u_{j+1}$

  统一写法：

$$u_j^{k+1} = u_j^k - \frac{\Delta t}{h}\left[\max(c,0)(u_j^k-u_{j-1}^k) + \min(c,0)(u_{j+1}^k-u_j^k)\right] \tag{4.19.1}$$

  或记 $c^+ = \max(c,0)$、$c^- = \min(c,0)$：

$$u_j^{k+1} = u_j^k - \frac{\Delta t}{h}\left[c^+(u_j-u_{j-1}) + c^-(u_{j+1}-u_j)\right]$$

4.19.2 稳定性

  设 $c>0$，$\nu = c\Delta t/h$。代入 $u_j^k=\lambda^ke^{i\beta j}$：

$$\lambda = 1 - \nu(1-e^{-i\beta}) \tag{4.19.2}$$

  计算模：

$$|\lambda|^2 = (1-\nu+\nu\cos\beta)^2 + (\nu\sin\beta)^2 = 1 - 2\nu(1-\nu)(1-\cos\beta)$$

  用 $1-\cos\beta = 2\sin^2(\beta/2)$：

$$|\lambda|^2 = 1 - 4\nu(1-\nu)\sin^2\frac\beta2 \tag{4.19.3}$$

  稳定性：$4\nu(1-\nu)\ge0$ 且 $\le2$（后者自动），得

$$0\le\nu\le1 \quad\blacksquare$$

  $|\lambda|<1$ 当 $0<\nu<1$——迎风格式总是有耗散。

迎风的耗散量：

$$1-|\lambda|^2 = 4\nu(1-\nu)\sin^2\frac\beta2$$

  • 低频（$\beta$ 小）：耗散 $\sim \nu(1-\nu)\beta^2$ —— 二阶小
  • 高频（$\beta=\pi$）：耗散 $=4\nu(1-\nu)$ —— 最大

这是"好"的耗散：它只抹掉高频（虚假的锯齿），保留低频（真实的波形）。

对比 Lax-Friedrichs：LF 的耗散是 $O(1)$ 量级对所有频率，连低频也抹——所以 LF 的波形总是糊的。

$\nu=1$ 时耗散为零——迎风格式格点精确（与 4.1 节的显式中心格式一样）。

4.19.3 精度

  迎风格式是一阶精度：截断误差 $O(\Delta t+h)$。

  为什么只有一阶？因为它是单侧差分——只有 $O(h)$ 逼近。

  Godunov 定理的解释（4.2 节）：迎风是单调的（不会产生新极值），所以最多一阶。

4.20 守恒型格式与数值通量

4.20.1 标准形式

$$\frac{\partial u}{\partial t} + \frac{\partial F(u)}{\partial x} = 0$$

  守恒型离散：

$$u_j^{k+1} = u_j^k - \frac{\Delta t}{h}\left(\hat F_{j+1/2} - \hat F_{j-1/2}\right) \tag{4.20.1}$$

  $\hat F_{j+1/2}$ 是数值通量，是 $u_j$ 与 $u_{j+1}$ 的函数。

  守恒性的含义：把整个网格求和：

$$\sum_j u_j^{k+1} = \sum_j u_j^k - \frac{\Delta t}{h}\left(\hat F_{N+1/2}-\hat F_{1/2}\right)$$

  内部通量全部抵消，只剩两端——总质量只通过边界变化。这正是守恒律。

4.20.2 常见数值通量

Lax-Friedrichs 通量：

$$\hat F_{j+1/2} = \frac{F_j+F_{j+1}}{2} - \frac{h}{2\Delta t}\left(u_{j+1}-u_j\right) \tag{4.20.2}$$

迎风通量（$c>0$）：

$$\hat F_{j+1/2} = F(u_j) = cu_j \tag{4.20.3}$$

Godunov 通量：解 Riemann 问题，取界面上的实际通量。对线性方程，Godunov 通量退化为迎风。

守恒型格式的价值在激波：

对线性方程，守恒与非守恒给出相同的解（因为解光滑）。但对非线性方程（如 Burgers），激波是弱解，只有守恒型格式才能给出正确的激波速度。

经典反例：Burgers 方程 $u_t+\left(\frac{u^2}{2}\right)_x=0$ 的激波速度满足 Rankine-Hugoniot 条件：

$$s = \frac{F(u_R)-F(u_L)}{u_R-u_L}$$

非守恒型离散（如 $u_t+uu_x=0$ 除以点值）不满足这个条件，激波会跑错位置，或产生膨胀激波（物理上不存在）。

规则：只要原方程来自守恒律，就必须用通量差分。

4.21 粘性消去法

  思路：让格式模拟人工粘性，用耗散压制振荡。

  构造：在中心差分格式上加一个人工粘性项：

$$u_t + cu_x = \epsilon u_{xx}, \qquad \epsilon\sim\frac{h^2}{\Delta t}\cdot\text{small} \tag{4.21.1}$$

  效果：奇数阶导数被偶数阶导数"平滑"——振荡被压制。

  代价：引入 $O(\epsilon)$ 的额外误差，通常降为一阶。

  这是早期 CFD 的主流做法（von Neumann 本人提出）。现代则更多用 TVD/WENO。

"粘性差分"与"迎风"的等价性：

对线性方程，迎风格式可以写成

$$u_j^{k+1} = u_j^k - \frac{\nu}{2}(u_{j+1}-u_{j-1}) + \frac{\nu}{2}\left[(1-\nu)\text{?...}\right]$$

更准确地说：

$$\text{迎风} = \text{中心差分} + \frac{\nu}{2}\left(\frac{h^2}{\Delta t}\right)u_{xx}\ \text{的离散}$$

迎风格式本质上是"中心差分 + 人工粘性"，粘性系数恰好是 $\frac{\nu}{2}$ 倍的二阶差分项。

这解释了两件事：

  1. 为什么迎风总是有耗散（粘性永远在）
  2. 为什么迎风在 $\nu=1$ 时无耗散（粘性系数 $\propto\nu(1-\nu)$，$\nu=1$ 时为零）

4.22 应对 Godunov 定理：TVD 与限制器

  困境：想要二阶精度（不能一阶），又不想振荡（违反 Godunov）。

  出路：非线性格式——格式本身依赖解。这样"线性"前提被破坏，Godunov 定理不适用。

4.22.1 TVD 条件

  总变差（Total Variation）：

$$TV(u^k) = \sum_j |u_{j+1}^k - u_j^k| \tag{4.22.1}$$

  TVD 性质：$TV(u^{k+1})\le TV(u^k)$——总变差不增加。

  等价于不产生新极值——这正是"不振荡"的数学刻画。

4.22.2 限制器（Limiter）

  思路：在光滑区域用高阶重构，在激波附近降为一阶（加限制）。

  考虑重构：

$$u_{j+1/2}^- = u_j + \frac12\phi(r_j)(u_j-u_{j-1}), \qquad r_j = \frac{u_j-u_{j-1}}{u_{j+1}-u_j} \tag{4.22.2}$$

  $\phi(r)$ 是限制器：

限制器 $\phi(r)$ 特点
minmod $\max(0,\min(1,r))$ 最保守，耗散大
superbee $\max(0,\min(2r,1),\min(r,2))$ 最激进，可能产生"阶梯"
van Leer $\dfrac{r+ r

  $\phi\equiv0$：一阶迎风。$\phi\equiv1$：Lax-Wendroff（不满足 TVD）。

  TVD 条件：$0\le\frac{\phi(r)}{r}\le2$ 且 $0\le\phi(r)\le2$。

限制器的工作方式（直观理解）：

  • 光滑区域：$r\approx1$（相邻梯度相近），限制器取 $\phi\approx1$ → 二阶精度
  • 激波附近：$r$ 很小或为负，限制器取 $\phi\to0$ → 降为一阶（加耗散压振荡）

所以 TVD 格式是"自适应的"：在需要的地方降阶，其他地方保持二阶。

代价：在极值点附近（$r<0$）会强制 $\phi=0$，导致极值被削平——这叫 clipping。这是 TVD 的固有缺陷，WENO 通过加权组合多个模板部分解决了它。

4.24 第 4 章小结

格式 阶 单调 耗散 用途
中心差分 2 ✗ 负（反耗散） 不稳定，不直接用
一阶迎风 1 ✓ 大 简单问题、限制器的基底
Lax-Friedrichs 1 ✓ 很大 教学、联立格式的基底
Lax-Wendroff 2 ✗ 小 光滑解
MUSCL/TVD 2 ✓ 局部可控 现代主流
WENO 5 近似 ✓ 极小 高精度激波捕捉

易错点

  1. 迎风格式的方向必须与波速符号一致，$c<0$ 时要反向；
  2. 守恒型格式的通量必须成对（$\hat F_{j+1/2}-\hat F_{j-1/2}$），否则不守恒；
  3. 非守恒离散在激波处给出错误解——Burgers 的激波速度会错；
  4. TVD 限制器在极值点会削平（clipping），这是固有缺陷；
  5. "加了限制器就是 TVD"是错的——必须验证 $0\le\phi(r)/r\le2$ 且 $0\le\phi\le2$。

  第 4 章完结。 下一章进入变分方法与有限元——完全不同的思路：不再"逐点逼近"，而是"在函数空间里找最优近似"。
