一、基础：两条直线交于一点

  （这一部分只需要会解二元一次方程组。）

方程组的几何意义

  考虑两个方程

$$\begin{cases}2x+y=4\\ x-y=1\end{cases}$$

  每个方程都是一条直线。 第一个方程说"$(x,y)$ 必须在这条线上"，第二个说"必须在那条线上"。

  所以解方程组 = 找两条直线的交点。

  用代入法：由第二式 $y=x-1$，代入第一式得 $2x+(x-1)=4$，即 $3x=5$，$x=\frac53$。

  于是 $y=\frac23$。解是唯一的 ✓

情况不止一种

  两条直线的关系有三种：

关系 方程组的解 例子
相交 唯一解 $x+y=2$，$x-y=0$
平行 无解 $x+y=1$，$x+y=2$
重合 无穷多解 $x+y=1$，$2x+2y=2$

  注意后两种：

  • 无解：两条线平行，永远不会碰
  • 无穷多解：其实是同一条线，线上每一点都是解

  这三句话在三维、$n$ 维里同样成立——只是"直线"变成"平面"或"超平面"。

为什么"无穷多解"不是"没答案"

  初学者常觉得"无穷多解"等于"没解出来"。

  但数学上它是一个完美的答案——所有解都可以用一个公式写出来。

  比如 $x+y=1$，解集是 ${(t,1-t):t\in\mathbb{R}}$——一个自由参数 $t$，所有解都在里面。

  这就叫"通解"——本文后面会讲怎么系统地写出它。

为什么关心方程组

  线性方程组是最基本的数学模型：

  • 电路分析（基尔霍夫定律）
  • 结构力学（节点受力平衡）
  • 数据拟合（最小二乘）
  • 有限元（刚度矩阵方程 $Ku=f$）

  而且它几乎是所有高等代数概念的来源：

概念 从方程组来
矩阵 系数排成的表
秩 有效方程的个数
行列式 唯一解存在的判据
向量空间 所有可能的右端项
特征值 特殊情形（$Ax=\lambda x$）

  所以从这里开始是对的。

二、标准：高斯消元、秩与解的判定

  （这一部分达到标准教材深度。）

矩阵与增广矩阵

  方程组

$$\begin{cases}a_{11}x_1+\cdots+a_{1n}x_n=b_1\\ \vdots\\ a_{m1}x_1+\cdots+a_{mn}x_n=b_m\end{cases}$$

  写成矩阵形式：

$$A\vec x=\vec b,\qquad A=(a_{ij})\in\mathbb{R}^{m\times n}$$

  增广矩阵：把 $\vec b$ 加到 $A$ 右边，记作 $(A|\vec b)$。

初等行变换

  三种操作：

  1. 交换两行
  2. 某行乘以非零常数
  3. 某行加上另一行的倍数

  核心定理：初等行变换不改变方程组的解集。

  （这就是为什么可以"消元"——每一步都是等价变形。）

高斯消元

  目标：把矩阵化成行阶梯形（每行的首个非零元素依次向右）。

  步骤：

  1. 第一列找一个非零元作主元
  2. 用它消去下面的元素
  3. 移到第二列，重复
  4. 最后回代求解

例：

$$(A|\vec b)=\begin{pmatrix}2&1&4\\ 1&-1&1\end{pmatrix}\xrightarrow{R_2-\frac12R_1}\begin{pmatrix}2&1&4\\ 0&-\frac32&-1\end{pmatrix}$$

  回代：$-\frac32y=-1$ ⟹ $y=\frac23$；$2x+\frac23=4$ ⟹ $x=\frac53$ ✓

秩与解的判定

  定义：矩阵的秩 $\operatorname{rank}(A)$ = 行阶梯形中非零行的个数。

判定定理：对 $A\vec x=\vec b$（$A$ 是 $m\times n$），

  1. $\operatorname{rank}(A)<\operatorname{rank}(A|\vec b)$ ⟹ 无解
  2. $\operatorname{rank}(A)=\operatorname{rank}(A|\vec b)=n$ ⟹ 唯一解
  3. $\operatorname{rank}(A)=\operatorname{rank}(A|\vec b)<n$ ⟹ 无穷多解（$n-r$ 个自由参数）

  直觉解释：

  • 情况 1：方程之间矛盾（比如 $x+y=1$ 与 $x+y=2$ 一起）
  • 情况 2：方程"够多且独立"
  • 情况 3：有冗余方程，剩下 $n-r$ 个变量可以自由取

秩到底在说什么

  秩 = 有效方程的个数 = 线性无关的行的最大个数。

  例：三个方程

$$x+y+z=1,\quad 2x+2y+2z=2,\quad x-y=0$$

  第二个方程是第一个的 2 倍——没有提供新信息。

  所以有效方程只有 2 个，而变量有 3 个 ⟹ 无穷多解（$3-2=1$ 个自由参数）。

  自由参数怎么选：取"非主元列"对应的变量，通常是 $z$。于是

$$x=y,\qquad 2x+z=1\ \Longrightarrow\ x=\frac{1-z}{2}$$

  通解：$\left(\dfrac{1-t}{2},\dfrac{1-t}{2},t\right)$，$t\in\mathbb{R}$ ✓

齐次与非齐次

  齐次：$A\vec x=\vec 0$——永远有零解。

  非齐次：$A\vec x=\vec b$——可能无解。

  关键关系（下一章会严格证明）：

非齐次的通解 = 一个特解 + 齐次的通解

  例：上面那个方程组，特解取 $t=0$ 得 $\left(\frac12,\frac12,0\right)$；齐次解是 $A\vec x=0$ 的 $t$ 方向。

常见错误

错误一：消元时用了"非初等"操作

  比如"把第一行减去第二行，同时把第二行减去第一行"——这不是初等行变换（同时改两行），可能改变解集。

  正确做法：一次只改一行。

错误二：以为"方程个数 ≥ 变量个数"就有唯一解

  还要看秩。三个方程可能只有两个独立。

错误三：行变换写成列变换

  初等行变换保持解集，初等列变换不保持（列变换相当于换变量，会改变解）。

错误四：混淆"无穷多解"与"无解"

  判据是 $\operatorname{rank}(A)$ 与 $\operatorname{rank}(A|\vec b)$ 是否相等。

错误五：用 $|A|$ 判断非方阵方程组

  行列式只对方阵有定义。非方阵没有"$|A|$"。

错误六：求解后不回代检验

  把解代回原方程——这是最便宜的检错。

三、深入：行变换为什么保持解集

  （这一部分是严格证明。）

三种初等行变换的证明

完整证明

  行变换 $A\mapsto EA$ 等价于左边乘一个"初等矩阵" $E$。 所以只要证：对任何可逆矩阵 $E$，

$$A\vec x=\vec b\iff EA\vec x=E\vec b$$

方向一：若 $A\vec x=\vec b$，两边左乘 $E$ 即得 $EA\vec x=E\vec b$ ✓

方向二：若 $EA\vec x=E\vec b$，两边左乘 $E^{-1}$（存在，因为初等矩阵可逆）得 $A\vec x=\vec b$ ✓

  所以关键在于：三种初等行变换对应的 $E$ 都可逆。

  1. 交换两行：$E$ 是置换矩阵，$E^{-1}=E$（对换两次回到原样）
  2. 某行乘 $c\ne0$：$E$ 是对角矩阵，$E^{-1}$ 是把 $c$ 换成 $1/c$
  3. 某行加另一行的 $k$ 倍：$E^{-1}$ 是同一行加 $-k$ 倍

  三种都可逆 ⟹ 解集不变 ✓ $\blacksquare$

  注意：这里"某行乘 $c$"要求 $c\ne0$——若允许乘 0，$E$ 不可逆，可能丢解。

为什么"列变换"不行

  右乘 $A\mapsto AE$ 相当于换变量：$\vec x\mapsto E^{-1}\vec x$。

  解集确实变了——但它变的方式是"重新标记变量"，不是"丢解"。

  所以：行变换保解集，列变换保"解的维数"但不保解本身。

  实用含义：解方程组只能用行变换。

秩的两种定义等价

  定义 A（行秩）：非零行的最大个数。
  定义 B（列秩）：线性无关的列的最大个数。

定理：行秩 = 列秩。

  这个定理不平凡——它说"行与列这两个方向给出的秩一样"。

  证明思路：高斯消元把矩阵变成行阶梯形，行数减少到 $r$；同时列也只剩下 $r$ 个独立列（其余列是前 $r$ 列的组合）。

  实用推论：$\operatorname{rank}(A)=\operatorname{rank}(A^\top)$。

解的结构定理

定理：若 $A\vec x=\vec b$ 有解，$\vec x_0$ 是一个特解，则全体解是

$${\vec x_0+\vec h:\ A\vec h=\vec 0}$$

证明

包含关系 1：若 $\vec h$ 是齐次解，则

$$A(\vec x_0+\vec h)=A\vec x_0+A\vec h=\vec b+\vec 0=\vec b\quad\checkmark$$

包含关系 2：若 $\vec x$ 是任意解，则

$$A(\vec x-\vec x_0)=\vec b-\vec b=\vec 0$$

所以 $\vec h=\vec x-\vec x_0$ 是齐次解 ✓ $\blacksquare$

  几何意义：解集是一条经过 $\vec x_0$、方向平行于齐次解空间的仿射子空间。

  二维时它是"不过原点的直线"，三维时是"不过原点的平面"。

四、拓展

  （这一部分真正可选。）

历史：中国比欧洲早一千八百年

  线性方程组的系统解法，最早出现在中国的《九章算术》。

时间 来源 内容
约公元前 1 世纪 《九章算术》第八章"方程" 用"遍乘直除"解三元一次方程组
263 刘徽注 给出了完整的算法说明
1247 秦九韶 推广到高次方程组
1750 克莱姆 给出"克莱姆法则"（用行列式表示解）
1809 高斯 最小二乘与消元法
1873 若尔当 把消元法推广到完全约化形式

  《九章算术》里的具体例子（第八章第一题）用现代记号写是：

$$\begin{cases}3x+2y+z=39\\ 2x+3y+z=34\\ x+2y+3z=26\end{cases}$$

  书中给出的解法是：把系数排成表（这就是矩阵的雏形），然后按固定的步骤消去。

"方程"这个词的来源

  《九章算术》里的"方程"二字，本义就是"用算筹摆成的方阵"。

  "方"= 排列成方形，"程"= 摆列。

  所以"方程"原本指的是矩阵，不是今天的"含有未知数的等式"。

  这个术语的流变很有意思：今天"方程（equation）"和"方程组（system of equations）"的用法，和古人不同的。

  而"高斯消元法"这个名字，虽然是西方的，但中国在牛顿出生前 1700 年就有了完整的算法。

联系：数值方法的视角

  理论上的消元与计算机上的消元，差别很大。

  理论：消元是"精确的"，只要主元非零就能做下去。

  数值：计算机有舍入误差，主元太小会导致除法放大误差。

  例：

$$\begin{pmatrix}10^{-20}&1\\ 1&1\end{pmatrix}\begin{pmatrix}x\\ y\end{pmatrix}=\begin{pmatrix}1\\ 2\end{pmatrix}$$

  按教科书顺序：用 $10^{-20}$ 作主元，第二行减去 $10^{20}$ 倍的第一行——$10^{20}$ 会让舍入误差完全淹没真解。

  实用做法：部分主元选取（partial pivoting）——每次选绝对值最大的元素作主元。

  实用后果：这一步把误差从 $O(\kappa^2)$ 降到 $O(\kappa)$（$\kappa$ 是条件数）。

  这就是为什么数值库（LAPACK、MATLAB）默认都做 pivoting。

应用：LU 分解与"一次分解多次求解"

  高斯消元做完之后，其实已经得到了一个分解：

$$A=LU$$

  其中 $L$ 是下三角（记录消元的乘数），$U$ 是上三角（行阶梯形的结果）。

  为什么有用：

  • 若要先解 $A\vec x=\vec b_1$，再解 $A\vec x=\vec b_2$……
  • 分解只需一次，之后每次只需两次三角回代（$O(n^2)$ 而不是 $O(n^3)$）

  这就是为什么：

  • 结构工程里刚度矩阵 $K$ 分解一次，然后对不同载荷反复求解
  • 迭代法的预处理（ILU）也用这个思想

  与本站的联系：「微分方程数值解」系列的刚度矩阵求解也是这个套路。

小结

概念 要点
矩阵形式 $A\vec x=\vec b$，增广矩阵 $(A|\vec b)$
初等行变换 交换 / 非零倍 / 行加法，保持解集
秩 非零行个数 = 行秩 = 列秩
判定 秩增 ⟹ 无解；秩满 ⟹ 唯一；秩不足 ⟹ 无穷多
解的结构 通解 = 特解 + 齐次通解
数值要点 部分主元选取，LU 分解一次多次求解

下一节预告

本节里反复出现"独立""组合""张成"这些词，但都没有精确定义。

下一节把它们抽象出来，得到向量空间——然后会发现：

$n$ 维空间里的一切，都可以用"基 + 坐标"描述。

  而"维数唯一"这个看起来显然的事实，其实需要证明。
