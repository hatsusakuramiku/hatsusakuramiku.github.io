前置知识：4.1 节（显式格式与 CFL 条件）、3.1 节（隐式格式的构造）。

能否摆脱 CFL 限制

  CFL 条件 $\nu\le1$ 对显式格式是致命的：网格加密一倍，时间步也要减半，计算量与 $N^2$ 成正比。

  隐格式能把 $u_j^{k+1}$ 与邻居同时求解，让信息在一个时间步内传播多格——理论上可以突破 CFL。

  代价是什么？本节回答。

4.7 隐式格式

4.7.1 构造

  把 (4.1.1) 的空间二阶导数取 $t_{k}$ 与 $t_{k+1}$ 两层的平均（Crank-Nicolson 式的做法）：

$$\frac{u_j^{k+1}-2u_j^k+u_j^{k-1}}{\Delta t^2} = \frac{a^2}{2}\left[\frac{\delta_x^2u_j^{k+1}}{h^2}+\frac{\delta_x^2u_j^{k-1}}{h^2}\right] \tag{4.7.1}$$

  整理：

$$-\frac{\nu^2}{2}u_{j-1}^{k+1} + (1+\nu^2)u_j^{k+1} - \frac{\nu^2}{2}u_{j+1}^{k+1} = 2u_j^k - (1+\nu^2)u_j^{k-1} + \frac{\nu^2}{2}(u_{j-1}^{k-1}+u_{j+1}^{k-1}) \tag{4.7.2}$$

  每步解一个三对角方程组——追赶法 $O(N)$。

4.7.2 稳定性

  代入 $u_j^k = \lambda^k e^{i\beta j}$，设 $B = 2\nu^2\sin^2(\beta/2)$：

$$\left(1+B\right)\lambda^2 - \left(2+B\right)\lambda + 1 = 0 \tag{4.7.3}$$

  两根之积仍为 1（因为格式关于 $k$ 与 $k-1$ 对称）。所以稳定要求 $|\lambda|=1$。

  判别：$\lambda$ 是共轭复数 ⟺ 判别式 $\le0$：

$$\left(2+B\right)^2 - 4(1+B) = 4+4B+B^2-4-4B = B^2 \ge 0$$

  判别式恒 $\ge0$（且为 $B^2$）！所以 λ 是实根：

$$\lambda_{1,2} = \frac{(2+B)\pm B}{2(1+B)} = \frac{1+B\pm B}{1+B} = \frac{2+B\quad\text{或}\quad 1}{1+B}$$

  即

$$\lambda_1 = 1, \qquad \lambda_2 = \frac{1}{1+B} \tag{4.7.4}$$

  两者都是实数，且 $|\lambda_2|\le1$（因为 $B\ge0$）——无条件稳定 ✓

但注意：$\lambda_1 = 1$ 精确成立，不依赖 $\beta$。

这意味着所有频率的模态都有同一个根 $\lambda=1$，永远不衰减也不增长。看起来是好事？

问题在于：$\lambda_2 = 1/(1+B)$ 依赖 $\beta$。高频模态（$\beta$ 大，$B$ 大）的 $\lambda_2$ 很小——它们被强烈衰减。

而真解中所有模态都应该以 $|\lambda|=1$ 传播（波动方程无耗散）。

所以这个格式会人为地"抹掉"高频分量——这就是数值耗散。

具体表现：陡峭的波前（含大量高频成分）会被抹平；长时间积分后，波形变得"圆滑"，能量减少。

4.8 数值耗散与数值色散

  这是双曲型数值方法中最重要的定性概念（比稳定性更难把握）。

4.8.1 数值耗散（Dissipation）

  定义：$|\lambda| < 1$ 的模态在被衰减。

  物理上，真解没有耗散。所以数值耗散总是假的——它让波的幅值减小。

  表现：波峰变矮、波形变平滑。

4.8.2 数值色散（Dispersion）

  定义：不同频率的模态以不同速度传播。

  真解中，所有波都以速度 $a$ 传播（无频散）。若数值格式的相速度 $\tilde a(\beta)$ 依赖 $\beta$，就产生色散。

  表现：波包被"散开"，高波数分量跑得慢（或快），波形后面出现振荡尾。

为什么这两个概念比稳定性更重要：

稳定性只说明"不发散"，但一个稳定的格式可能给出完全扭曲的波形：

  • 强耗散：波峰被抹平，模拟不出激波
  • 强色散：波形后面拖着虚假的振荡

实际工程中，选格式的关键往往不是"稳不稳定"，而是"耗散和色散是否可接受"。

这也是为什么 CFD 领域发展了 TVD、WENO 等复杂格式（4.4 节会提）——它们的核心目标就是控制耗散与色散，而不是简单地追求高阶。

4.8.3 定量刻画

  设放大因子 $\lambda(\beta) = |\lambda|e^{-i\beta\nu_{\text{num}}(\beta)}$（写成模 + 相角）。则：

  • 耗散：$|\lambda|-1$
  • 相速度误差：$\nu_{\text{num}}$ 与真值 $\nu$ 的差

  对 4.7 节的隐格式：$\lambda_1=1$（无耗散），$\lambda_2\approx0$（强耗散）——一半模态被杀死。

4.9 Lax-Wendroff 格式

  目标：二阶精度 + 可控的耗散/色散。

  思路：把 $u^{k+1}$ 做泰勒展开到二阶：

$$u^{k+1} = u^k + \Delta t,u_t + \frac{\Delta t^2}{2}u_{tt}+\cdots$$

  用方程消去时间导数：

$$u_t = a^2u_{xx}\ \text{（这是波动方程，但 Lax-Wendroff 更常用在一阶对流方程）}$$

  对一阶对流方程 $u_t+c u_x=0$：

$$u^{k+1} = u^k - c\Delta t,u_x + \frac{c^2\Delta t^2}{2}u_{xx} + \cdots$$

  用中心差分近似 $u_x$ 与 $u_{xx}$：

$$u_j^{k+1} = u_j^k - \frac{\nu}{2}(u_{j+1}^k-u_{j-1}^k) + \frac{\nu^2}{2}(u_{j+1}^k-2u_j^k+u_{j-1}^k) \tag{4.9.1}$$

  （$\nu = c\Delta t/h$。）这是 Lax-Wendroff 格式。

4.9.1 稳定性与性质

  放大因子：

$$\lambda = 1 - i\nu\sin\beta - 2\nu^2\sin^2\frac\beta2 \tag{4.9.2}$$

  计算模：

$$|\lambda|^2 = 1 - 4\nu^2(1-\nu^2)\sin^4\frac\beta2 \tag{4.9.3}$$

  稳定性：$|\lambda|\le1$ ⟺ $1-\nu^2\ge0$ ⟺ $\nu\le1$ ——同样是 CFL 条件。

Lax-Wendroff 的关键特点：

  1. 二阶精度（比一阶迎风高）
  2. 满足 CFL（$\nu\le1$）
  3. 模 $|\lambda|<1$ 当 $\nu<1$——有耗散，但只对高频（$\sin^4$ 意味着低阶衰减慢）
  4. $\nu=1$ 时 $|\lambda|=1$——无耗散，且可验证格点精确

它比一阶迎风好在哪：迎风的耗散是 $O(\nu(1-\nu))$ 量级且对所有频率，Lax-Wendroff 的耗散是 $O(\nu^2(1-\nu^2)\sin^4)$ ——对低频几乎没有耗散，只抹掉高频。

它的问题：在激波附近会产生非物理振荡（Gibbs 现象），因为它是线性二阶格式，不满足 TVD 性质。

4.9.2 一个重要的定理

Godunov 定理（1959）：

线性格式：若满足单调性（不产生新极值），则精度至多一阶。

推论：想要二阶精度，就必然会在激波附近振荡。

这是不可突破的理论限制，与 Dahlquist 障碍定理同级别的结论。

出路：

  1. 接受振荡（Lax-Wendroff）
  2. 降为一阶（迎风）
  3. 用非线性格式（TVD/WENO——格式本身依赖解，绕开"线性"前提）

这就是现代激波捕捉格式（4.4 节）的由来。Godunov 本人给出的解法是精确 Riemann 求解器 + 分段常数重构——非线性、守恒、一阶但能正确捕捉激波。

4.10 代码：对比显式与隐式

运行后会看到：

隐格式确实突破了 CFL——$\nu=5$ 时依然稳定。

但误差随之增大：$\nu=5$ 时误差 $4\times10^{-2}$，而 $\nu=1$ 时是机器精度。

原因：CFL 违反后，虽然数值上稳定，但物理上信息传不到——数值解在"追赶"真解，产生相位误差。误差随 $\nu$ 增大而增大。

4.11 小结

格式 稳定性 精度 耗散 特点
显式中心 $\nu\le1$ 2 阶 无（中性） 简单，格点精确（$\nu=1$）
隐式 CN 无条件 2 阶 强（一半模态被杀死） 突破 CFL，但波形被抹平
Lax-Wendroff $\nu\le1$ 2 阶 弱（低频几乎无） 激波附近振荡

易错点

  1. 隐格式能突破 CFL，但不能突破物理——$\nu$ 大时误差增大；
  2. "稳定"不等于"正确"——隐格式的数值耗散会抹平波形；
  3. A 稳定 ≠ 无耗散——两者是不同概念；
  4. Godunov 定理：线性格式精度与单调性不可兼得；
  5. 误差不衰减（显式格式）——长期积分会累积。
