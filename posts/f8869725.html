前置知识：5.6 节（一维有限元的完整流程）。本节是整个系列最后一篇。

从一维到二维，多出来的三件事

  5.6 节的流程（选基函数 → 单元矩阵 → 组装 → 边界 → 求解）在二维完全一样。多出来的是三个"二维特有"的麻烦：

麻烦 一维怎么做 二维要怎么做
单元形状 只有线段 三角形/四边形，形状各异
区域边界 两个端点 任意曲线
线性方程组 三对角，$O(N)$ 稀疏且更大，直接法太贵

  这一节依次解决这三个。

5.19 三角形单元与面积坐标

直观：用"三棱锥"做帐篷

  一维的帐篷是两个斜面的"∧"。二维的对应物是一个三棱锥：

  • 在三角形的某个顶点处等于 1
  • 在其他两个顶点处等于 0
  • 在三角形内部线性过渡

  这就是二维的基函数 $\phi_i^{(e)}$。把每个顶点放一个这样的"帐篷"，整个区域就被完全覆盖。

面积坐标（重心坐标）

  三角形内任一点 $P$ 可以用三个面积比描述：

$$L_1 = \frac{[\triangle P23]}{[\triangle 123]},\quad
L_2 = \frac{[\triangle 1P3]}{[\triangle 123]},\quad
L_3 = \frac{[\triangle 12P]}{[\triangle 123]} \tag{5.19.1}$$

  关键性质：

  • $L_1+L_2+L_3=1$（总是成立）
  • 在顶点 1 处：$L_1=1$，$L_2=L_3=0$
  • 三角形内 $L_i\in[0,1]$

  所以 $L_i$ 本身就是基函数！$\phi_i^{(e)}=L_i$。

为什么用面积坐标而不用 $x,y$

一维时基函数是 $\phi_1=1-x/h$、$\phi_2=x/h$——用一个局部坐标就能写得很干净。

二维如果用 $x,y$，每个三角形的公式都不一样（取决于它的形状和朝向）。

用面积坐标 $L_i$，所有三角形的基函数都是同一个式子"$\phi_i=L_i$"，积分也有统一公式。

这是有限元代码能通用的关键。

面积坐标与 $x,y$ 的关系（线性）：

$$L_i(x,y) = \frac{a_i+b_ix+c_iy}{2\Delta}$$

其中 $\Delta$ 是三角形面积，系数由顶点坐标决定。

单元刚度矩阵：一维那个的推广

  一维时 $K^e=\frac1h\begin{pmatrix}1&-1\-1&1\end{pmatrix}$。二维三角形单元（面积 $\Delta$）是：

$$K^e_{ij} = \Delta\cdot\left(\nabla L_i\cdot\nabla L_j\right) \tag{5.19.2}$$

  因为 $L_i$ 是线性的，$\nabla L_i$ 是常向量（每个单元内不变）。所以 $K^e$ 是 $3\times3$ 常矩阵。

  质量矩阵（三角形上 $\int L_iL_j$）：

$$M^e = \frac{\Delta}{12}\begin{pmatrix}2&1&1\1&2&1\1&1&2\end{pmatrix} \tag{5.19.3}$$

三角形质量矩阵的推导（可选读）

面积坐标下的积分有通式：

$$\int_\triangle L_1^{a}L_2^{b}L_3^{c}\quad dS = \frac{a!,b!,c!}{(a+b+c+2)!}\cdot 2\Delta$$

验证：$\int L_1,dS$（$a=1,b=c=0$）：

$$\frac{1!\cdot0!\cdot0!}{(1+0+0+2)!}\cdot2\Delta = \frac{1}{3!}\cdot2\Delta = \frac{\Delta}{3}$$

正确——三角形被三条中线分成三个等面积的小三角形，每个重心恰好位于其中一个，$L_1$ 的平均值确实是 $1/3$。

验证：$\int L_1^2,dS$（$a=2$）：

$$\frac{2!}{4!}\cdot2\Delta = \frac{2}{24}\cdot2\Delta = \frac{\Delta}{6}$$

验证：$\int L_1L_2,dS$（$a=b=1$）：

$$\frac{1}{4!}\cdot2\Delta = \frac{\Delta}{12}$$

所以 $M^e=\Delta\begin{pmatrix}1/6&1/12&1/12\\cdots\end{pmatrix} = \frac{\Delta}{12}\begin{pmatrix}2&1&1\1&2&1\1&1&2\end{pmatrix}$ ✓

行和检查：$2+1+1=4$，乘以 $\Delta/12$ 得 $\Delta/3$——这正是常数函数的积分，正确。

5.20 等参变换：处理曲边

问题：真实的边界是弯的

  三角形单元是直边的。但真实的区域（如机翼、圆孔）边界是曲线。

  如果只用直边三角形逼近，边界误差是 $O(h)$——和 2.4 节的阶梯边界一个毛病。

解法：把标准单元"弯曲"过去

  分两步：

  1. 在一个标准单元（参考单元）上定义形函数
  2. 用一个映射把它"拉"到实际的曲边单元上

  一维的例子（最容易看懂）：

  标准单元 $[-1,1]$ 上的线性形函数：$N_1=\frac{1-\xi}{2}$，$N_2=\frac{1+\xi}{2}$。

  映射：

$$x(\xi) = N_1(\xi)x_1+N_2(\xi)x_2 \tag{5.20.1}$$

  这就是普通的线性插值。但若想表示曲边，加一个中间节点 $x_3$，用二次形函数：

$$x(\xi) = N_1x_1+N_2x_2+N_3x_3,\qquad N_3 = 1-\xi^2 \tag{5.20.2}$$

  这就弯了——$x(\xi)$ 不再线性。

"等参"的含义

等参（isoparametric）= 用同一套形函数描述几何与场变量

  刚才 $N_i$ 被用了两次：

  • 描述坐标 $x(\xi)$（几何）
  • 描述解 $u(\xi)=\sum N_i u_i$（场）

好处：

  1. 代码统一，不用写两套
  2. 几何与场变量同阶逼近——不会出现"几何很准但解不准"或反过来
  3. 曲边可以精确表示

代价：需要雅可比行列式（映射的伸缩因子）：

$$\int f(x)\quad dx = \int f(x(\xi))\left|\frac{dx}{d\xi}\right|d\xi$$

在二维要算 $2\times2$ 的雅可比矩阵行列式，而且它在单元内变化（不再简单）——所以数值积分（高斯求积）必须用。

5.21 大型稀疏方程组：多重网格

现实的困境

  二维网格 $N\times N$（$h=1/N$），未知数 $n\approx N^2$。

  5.3 节说过：五点格式的条件数 $\kappa=O(N^2)$。

  迭代法的困境（2.5 节）：

方法 迭代次数
Jacobi / Gauss-Seidel $O(N^2)$
SOR（最优 $\omega$）/ CG $O(N)$

  总共 $O(N^3)$（$n=N^2$ 个未知数 × $O(N)$ 次迭代）——网格加密一倍，工作量增 8 倍。

多重网格的核心洞察

  关键观察：迭代法（GS/Jacobi）在抹掉高频误差上极快，在低频上极慢。

  直观：GS 每次只"看到"相邻的点。误差的尖锐部分（相邻点差异大）几下就被抹平；但缓慢的大起伏（整个区域一起高低）它看不出，只能一点点磨。

  多重网格的想法：

在细网格上抹高频，把剩下的低频问题搬到粗网格上去——在粗网格上，那个"缓慢起伏"相对就变成了高频！

  两重网格的一次循环（V-cycle）：

  1. 细网格：做几次 GS，抹掉高频
  2. 限制（restrict）：把残差投影到粗网格
  3. 粗网格：解那个小得多的方程（或递归多重网格）
  4. 插值（prolongate）：把修正量传回细网格
  5. 细网格：再做几次 GS，抹掉插值带来的高频

为什么多重网格能做到 $O(n)$

因为每一层的迭代次数是常数（不是随网格增长），而层数只有 $\log N$ 层，每层的工作量几何递减：

$$n + n/4 + n/16+\cdots < \frac43 n$$

总工作量 $\approx O(n)$——这是渐进最优的，不可能更快（至少要读一遍所有未知数）。

这是数值 PDE 领域最重要的算法之一。它的提出（1970s-80s，Brandt、Hackbusch 等）让大规模问题第一次真正可行。

代价：实现复杂（要管理多层网格、限制/插值算子），且对不规则几何与变系数不友好——所以工程里常与有限元结合成"几何多重网格"或退而用代数多重网格（AMG）。

为什么迭代法抹低频慢（可选读）

用一维模型看。GS 的误差演化：

$$e_j^{(k+1)} = \frac12\left(e_{j-1}^{(k)}+e_{j+1}^{(k)}\right)$$

（这是 GS 对 Poisson 误差方程的一维形式。）

代入 Fourier 模态 $e_j=\lambda^k e^{i\omega jh}$：

$$\lambda = \frac12\left(e^{-i\omega h}+e^{i\omega h}\right)\cdot\frac{1}{1} \to \lambda = \cos^2\frac{\omega h}{2}$$

（更精确地，GS 的一维光滑因子是 $\lambda=\cos^2(\omega h/2)$。）

高低频对比：

  • 高频（$\omega h\approx\pi$）：$\lambda\approx0$ → 一次迭代就抹掉
  • 低频（$\omega h\ll1$）：$\lambda\approx1-\frac{(\omega h)^2}{4}$ → 几乎不动

具体数字：$\omega h = 0.1$ 时 $\lambda\approx0.9975$——要 280 次迭代才降到 $1/2$。

为什么会这样：低频误差在相邻点几乎相等，GS 的"取邻居平均"改变不了它。只有把问题搬到别的尺度上才能处理。

这就解释了为什么网格加密后收敛这么慢：最慢的模态频率 $\sim1/N$，接近 1 的 $\lambda$ 也就越来越接近。

5.22 代码：二维三角形有限元

运行后会看到：

  1. 收敛阶稳定在 2.00——三角形线性单元与一维分片线性一样是二阶
  2. 自检 max|A·1| 在 $10^{-16}$ 量级

第 2 点又一次验证了 5.6 节那个自检的通用性——它对任何椭圆型有限元都成立，无论一维、二维、三角形还是四边形。

注意 $N=32$ 时未知数已近 1000，np.linalg.solve 用满矩阵还撑得住；$N=100$ 时约 1 万未知数，满矩阵就要几十秒了——这时必须换稀疏求解器或迭代法（这就是多重网格存在的意义）。

5.23 数值解系列总结

  五章，28 篇。回看整条脉络：

数值解系列

第 1 章

常微分初值问题：Euler → 多步法 → RK → 刚性。
核心是相容性 + 稳定性 ⟹ 收敛性（Dahlquist 等价定理）。

第 2 章

椭圆型差分：差商 → 五点格式 → 极值原理 → 迭代法。
核心是离散极值原理给出 $O(h^2)$ 收敛，以及条件数 $O(N^2)$ 带来的迭代困境。

第 3 章

抛物型差分：显/隐/CN → 稳定性三法 → von Neumann → ADI。
核心是步长比 $r=a^2\Delta t/h^2$ 与三种稳定性的等价判据。

第 4 章

双曲型差分：CFL → 耗散色散 → 双曲组 → 迎风守恒。
核心是数值依赖域必须包含物理依赖域，以及 Godunov 定理的精度-单调性制约。

第 5 章

变分与有限元：弱形式 → Sobolev → Ritz-Galerkin → 谱方法 → 一二维有限元。
核心是Cea 引理把数值误差转化为逼近误差。

三个贯穿全系列的主线

① 相容 + 稳定 ⟹ 收敛
这条链在第 1、2、3 章反复出现，只是"稳定性"的含义不同：

  • ODE：时间推进不放大误差
  • 椭圆：离散算子逆有界
  • 抛物：每步的放大因子 $\le1$

② 稳定性约束的本质是"信息传播"

  • 抛物型 $r\le1/2$：凸组合（离散极值原理）
  • 双曲型 $\nu\le1$：依赖域包含
  • 椭圆型：条件数

③ 精度与性质的取舍

  • Godunov 定理：线性 + 单调 ⟹ 至多一阶
  • Dahlquist 第二障碍：A 稳定 ⟹ 至多二阶
  • 谱方法：指数精度 ⟹ 稠密矩阵 + 简单几何

没有"全面最优"的方法，只有"适合问题"的方法。

如果要从这一系列里只记住五句话

  1. CFL 不是数值技巧，是物理必要条件——信息传不到就是错的
  2. 稳定性 $\ne$ 正确性——数值耗散会抹平波形（4.2 节）
  3. 凸组合结构是显式格式稳定的根源——中心系数 = 邻居系数之和
  4. Cea 引理把数值误差变成逼近误差——有限元理论的全部枢纽
  5. 条件数 $O(N^2)$ 是椭圆问题的固有困难——多重网格是唯一的最优解

  系列完结。 下一阶段转入数学基础（数学分析 → 高等代数 → 实变/泛函 → 复变），采用「先直观后严格、证明可折叠」的写法。
