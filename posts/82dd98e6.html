前置知识：1.1 节（Euler 法的数值积分推导）、1.2 节（特征方程与稳定性判据）、数值积分基础。

为什么需要多步法

  1.1 节我们看到，把方程写成积分形式

$$y(t_{k+1}) - y(t_k) = \int_{t_k}^{t_{k+1}}f(t,y(t)),dt \tag{1.3.1}$$

  然后用不同的数值积分公式近似右端积分，就得到不同的格式。

  Euler 法 = 左矩形公式（用 $f(t_k,y_k)$ 近似整个区间）。这是最粗糙的积分——只用了区间一个端点的信息。

  能不能用更多点的信息，得到更高阶的公式？当然可以——这就是线性多步法。

  "多步"的含义：计算 $y_{k+1}$ 时用到前面多个已算出的值 $y_k, y_{k-1}, \dots, y_{k-r+1}$。而 Euler 法、Runge-Kutta 法都只用到 $y_k$（单步法）。

多步法 vs 单步法的取舍：

单步法 多步法
起步 自带（$y_0$ 已知即可） 需要额外起步值（用单步法算前几步）
每步计算量 由阶数决定（RK 要多次算 $f$） 每步只算一次 $f$
存储 只需最近一个值 需要保存前 $r$ 个值
阶数 提高阶要加中间级（更贵） 提高阶只需多用几个历史值（便宜）
变步长 容易 麻烦

结论：多步法在"每步很便宜"上占优，但起步和变步长是它的软肋。实际工程中常把两者混用（如 RK 起步 + PECE 主体）。

1.3 用插值构造多步法

  基本思路：用 $t_k, t_{k-1}, \dots$ 处的 $f$ 值构造插值多项式 $P_{r-1}(t)$，用 $\int_{t_k}^{t_{k+1}}P_{r-1}(t)dt$ 近似真积分。

  由于 $f(t_j, y_j) = f_j$ 是已知的（数值解在第 $j$ 步已经算出），插值点是现成的。

1.3.1 Adams-Bashforth（显式）：插值点在积分区间左侧

  一阶（用 $f_k$ 一个点，零次插值常数）：

$$y_{k+1} = y_k + h f_k$$

  就是 Euler 法。

  二阶（用 $f_k, f_{k-1}$ 两点，线性插值）：过 $(t_k,f_k)$、$(t_{k-1},f_{k-1})$ 的直线，在 $[t_k,t_{k+1}]$ 上积分。做变量代换 $s = (t-t_k)/h\in[0,1]$：

$$y_{k+1} = y_k + h\left(\frac{3}{2}f_k - \frac{1}{2}f_{k-1}\right) \tag{1.3.2}$$

  三阶（用三个点）：

$$y_{k+1} = y_k + \frac{h}{12}\left(23f_k - 16f_{k-1} + 5f_{k-2}\right) \tag{1.3.3}$$

  四阶：

$$y_{k+1} = y_k + \frac{h}{24}\left(55f_k - 59f_{k-1} + 37f_{k-2} - 9f_{k-3}\right) \tag{1.3.4}$$

  记法：用 $r$ 个历史点得到 $r$ 阶 Adams-Bashforth 格式（AB$r$）。

系数的规律与验算：

AB$r$ 的系数 $b_j$ 满足必和条件

$$\sum_{j=0}^{r-1} b_j = 1$$

因为若 $f \equiv 1$（常数），积分应为 $h$，而公式给出 $h\sum b_j$。验算：

  • AB2：$3/2 - 1/2 = 1$ ✓
  • AB3：$(23-16+5)/12 = 12/12 = 1$ ✓
  • AB4：$(55-59+37-9)/24 = 24/24 = 1$ ✓

这个和式必须满足——如果自己手算的系数不满足，一定算错了。这是快速验算的第一道关。

1.3.2 Adams-Moulton（隐式）：积分区间内含插值点

  若插值点包含 $t_{k+1}$（即用到尚未算出的 $f_{k+1}$），得到隐式格式。

  二阶（用 $f_{k+1}, f_k$，梯形插值）——正是 1.1 节的梯形格式：

$$y_{k+1} = y_k + \frac{h}{2}(f_{k+1} + f_k)$$

  三阶（用 $f_{k+1},f_k,f_{k-1}$）：

$$y_{k+1} = y_k + \frac{h}{12}\left(5f_{k+1} + 8f_k - f_{k-1}\right) \tag{1.3.5}$$

  四阶：

$$y_{k+1} = y_k + \frac{h}{24}\left(9f_{k+1} + 19f_k - 5f_{k-1} + f_{k-2}\right) \tag{1.3.6}$$

  关键规律：同为 $r$ 个插值点，Adams-Moulton 比 Adams-Bashforth 高一阶。 因为隐式格式的积分区间更长（含 $t_{k+1}$），误差更小。

1.3.3 待定系数法：不用插值也能算出系数

  上面的系数可以用插值多项式积分算出，但更简洁的做法是待定系数法——直接要求格式对尽可能高的次数多项式精确。

  以 AB2 为例。设

$$y_{k+1} = y_k + h(b_0f_k + b_1f_{k-1})$$

  要求：当 $y$ 是二次多项式时，公式精确。

  取 $y=t$（此时 $f \equiv 1$）：左边 $h$，右边 $h(b_0+b_1)$ ⟹ $b_0+b_1=1$。

  取 $y=t^2$（此时 $f = 2t$）：左边 $t_{k+1}^2-t_k^2 = 2t_kh+h^2$；右边 $h(2b_0t_k + 2b_1t_{k-1}) = h(2b_0t_k+2b_1(t_k-h)) = 2h t_k(b_0+b_1) - 2b_1h^2$。

  用 $b_0+b_1=1$ 化简右边 $=2t_kh - 2b_1h^2$。比较 $h^2$ 项：

$$1 = -2b_1 ;\Longrightarrow; b_1 = -\frac12, \quad b_0 = \frac32$$

  与插值法结果一致 ✓

待定系数法的标准流程：

  1. 写出格式的一般形式（未知系数 $b_j$），数出未知量个数 $m$
  2. 依次取 $y=1, t, t^2, \dots, t^{m-1}$，要求精确成立
  3. 解出 $m$ 个方程得系数

得到的阶数是 $m$（对 $p\le m$ 次多项式精确）——这就是为什么 $r$ 个点的 AB 格式是 $r$ 阶。

若要求更高阶（超过未知量个数），会得到超定方程组，通常无解——除非改变格式结构（如用更多历史点）。

1.4 稳定性：多步法的特征方程

  1.2 节讲的特征方程现在派上用场了。

  把多步法作用于试验方程 $y^{\prime}=\lambda y$。以 AB2 为例：

$$y_{k+1} = y_k + h\lambda\left(\frac32y_k - \frac12y_{k-1}\right) \tag{1.4.1}$$

  设 $y_k = r^k$，代入：

$$r^{k+1} = r^k + z\left(\frac32r^k - \frac12r^{k-1}\right), \qquad z = h\lambda$$

  两边除以 $r^{k-1}$：

$$r^2 = r + z\left(\frac32r - \frac12\right) ;\Longrightarrow; r^2 - \left(1+\frac32z\right)r + \frac12z = 0 \tag{1.4.2}$$

  这就是 AB2 的特征方程。由 1.2 节的判据，稳定性要求两个根都满足 $|r|\le1$。

多步法特有的现象：寄生根。

$r$ 阶多步法有 $r$ 个特征根。其中一个是"主根"（$z\to0$ 时 $r\to1$，它对应精确解 $e^{\lambda t}\approx1+\lambda t$），另 $r-1$ 个是寄生根（extraneous roots）。

寄生根的物理来源：多步法需要 $r$ 个初始值，但实际只有一个真实的 $y_0$。多给的那些"起步值"带来的误差会激发寄生根。

即使主轴稳定，寄生根也可能导致不稳定——这是多步法分析比单步法复杂的地方。

  稳定性区域：在复平面上，使所有根都满足 $|r|\le1$（且模为 1 的根单重）的 $z=h\lambda$ 的集合。

  具体数值：可以证明 AB2 的绝对稳定区间是

$$-1 \le z \le 0 \quad\text{（实轴部分）}$$

但精确的稳定区间是 $z\in[-1,0]$，比 Euler 法的 $[-2,0]$ 更小！——阶数更高的多步法，稳定域反而更小，这是多步法的一个反直觉性质。

这是数值分析里一个重要的权衡：显式多步法的阶越高，绝对稳定区域越小。

方法 阶 实轴稳定区间
Euler（AB1） 1 $[-2, 0]$
AB2 2 $[-1, 0]$
AB3 3 $[-6/11, 0]\approx[-0.55,0]$
AB4 4 $[-3/10, 0]$

阶数从 1 升到 4，稳定区间从 2 缩到 0.3——缩了将近 7 倍。这意味着对刚性问题，高阶显式多步法几乎没法用。

1.6 小结

格式 类型 阶 用点数 特征
AB1（Euler） 显式 1 1 最简单
AB2~AB4 显式 2~4 2~4 每步一次 $f$，稳定域随阶数缩小
AM2（梯形） 隐式 2 2 A 稳定
AM3~AM5 隐式 3~5 3~5 高阶且稳定性好，需迭代求解

易错点

  1. AB 与 AM 的点数—阶数关系差一：$r$ 个点的 AB 是 $r$ 阶，AM 是 $r+1$ 阶；
  2. 系数必和条件 $\sum b_j = 1$——快速验算的第一道关；
  3. 寄生根：多步法的特征根有多个，只看主根会误判稳定性；
  4. 阶数高 ≠ 稳定域大：显式多步法阶越高稳定域越小，与 RK 法不同；
  5. 起步值精度不足会毁掉高阶——用 RK4 或更高阶起步。

  下一节 1.4 讲待定系数法的系统化与预估-校正（PECE）——把显式格式当预测器、隐式格式当校正器，既避免迭代又拿到隐式格式的精度。
