本文结构（四层，可以只读前两层）

部分 适合谁
一、基础 完全初学者——用"给集合称重"建立直觉
二、标准 有基础、要学扎实的读者——外测度、勒贝格测度、可测集
三、深入 想看清"为什么有不可测集"的读者
四、拓展 对历史、概率论、信息论感兴趣的读者

一、基础：给集合称重

  （这一部分只需要知道"区间长度"。）

区间有长度

  闭区间 $[a,b]$ 的长度是 $b-a$。 这很自然。

  开区间 $(a,b)$ 的长度也是 $b-a$——端点的"长度"是 0。

  那更复杂的集合呢？

集合 长度是多少？
$[0,1]$ 1
$[0,1]\cup[2,3]$ $1+1=2$
有理数 $\mathbb{Q}\cap[0,1]$ ？
Cantor 集 ？

  有理数在 $[0,1]$ 里"到处都是"，但能不能给个"长度"？

有理数集的长度是 0

  这是第一个反直觉的结论：$\mathbb{Q}\cap[0,1]$ 的长度是 0。

  为什么：有理数可数，可以排成一列 $q_1,q_2,q_3,\dots$。

  对每个 $q_n$，用长度 $\varepsilon/2^n$ 的小区间盖住它。

  总长度：

$$\sum_{n=1}^{\infty}\frac{\varepsilon}{2^n}=\varepsilon$$

  因为 $\varepsilon$ 可以任意小，所以这个集合的"长度"只能是 0 ✓

  所以："到处都有"（稠密）不等于"很大"（测度正）。

这是"测度"与"基数"的区别

  基数：$\mathbb{Q}$ 是可数无穷，$\mathbb{R}$ 是不可数——所以 $\mathbb{R}$"更大"。

  测度：$\mathbb{Q}$ 的测度是 0，$\mathbb{R}$ 的测度是 $\infty$。

  两个概念回答的不是同一个问题：

  • 基数问"有多少个"
  • 测度问"占了多大地方"

  所以："有理数比无理数少"（基数）与"两者都很稠密"（拓扑）与"有理数没长度"（测度）——三句话都对。

Cantor 集：没有长度但有很多点

  Cantor 集的构造：

  1. 从 $[0,1]$ 开始
  2. 去掉中间三分之一 $(1/3,2/3)$——剩两个区间，总长 $2/3$
  3. 再各去掉中间三分之一——剩四个区间，总长 $4/9$
  4. 无限做下去

  剩下的点集就是 Cantor 集。

  它的长度：$1\to\dfrac23\to\dfrac49\to\cdots\to0$——测度是 0。

  但它有多少个点？ 不可数多个（与 $\mathbb{R}$ 等势）！

  所以：Cantor 集是"测度为零、但点数与整个区间一样多"的集合。

  这是"基数"与"测度"分离的最戏剧性的例子。

二、标准：外测度与可测集

  （这一部分达到标准教材深度。）

外测度

定义：对 $E\subseteq\mathbb{R}$，其外测度为

$$m^*(E)=\inf\left{\sum_{n=1}^{\infty}l(I_n):E\subseteq\bigcup_{n=1}^{\infty}I_n\right}$$

其中 $I_n$ 是开区间，$l(I_n)$ 是长度。

  也就是说：用可数个区间去"盖住" $E$，所有覆盖方式总长度的下确界。

  外测度的性质：

性质 说明
非负 $m^*(E)\ge0$
单调 $E\subseteq F\implies m^(E)\le m^(F)$
次可加 $m^\big(\bigcup_n E_n\big)\le\sum_n m^(E_n)$
平移不变 $m^(E+t)=m^(E)$

  唯独缺了"可加性"——即"若 $E_i$ 互不相交，$m^\big(\bigcup E_i\big)=\sum m^(E_i)$"。

  这个缺失是本质的（第三节讲）。

可测集（Carathéodory 条件）

定义：$E$ 叫可测集，若对一切 $A\subseteq\mathbb{R}$，

$$\mathrm{m}^{\ast}(A)=\mathrm{m}^{\ast}(A\cap E)+\mathrm{m}^{\ast}(A\cap E^{\mathrm{c}})$$

  （这里 $\mathrm{m}^{\ast}$ 表示外测度，用 \ast 而不是 *，避免和星号运算混淆。）

  直觉：$E$ 把任何集合"干净地切开"——两边加起来正好等于原来的。

  注意：由次可加性，总有 $\le$；所以这个条件等价于"$\ge$"部分。

  定理：可测集全体构成**$\sigma$-代数**：

  • $\varnothing$ 可测
  • 可测集的补可测
  • 可数个可测集的并、交可测

  而在这个 $\sigma$-代数上，$m^*$ 满足可加性——此时记作 $m$，叫勒贝格测度。

哪些集可测

  好消息：几乎所有"能描述出来"的集合都可测。

集合 可测？
开集、闭集 ✓
可数集 ✓（测度 0）
Cantor 集 ✓（测度 0）
博雷尔集（由开集经可数并交补得到） ✓
维塔利集 ✗

  所以"不可测集"必须用选择公理才能构造出来——它们不是"能画出来的"。

常见错误

错误一：以为"外测度可加"

  外测度只有次可加。可加性是可测集的特权。

错误二：以为"可数集测度为 0 ⟹ 可数集都不重要"

  测度 0 不等于"没用"。有理数集测度 0，但它处处稠密——拓扑上很重要。

错误三：把"稠密"与"测度大"混为一谈

  $\mathbb{Q}$ 稠密但测度 0；Cantor 集不稠密但不可数。

错误四：以为 Cantor 集"很小"

  测度 0，但基数与 $\mathbb{R}$ 相同——它非常多"点"。

错误五：以为勒贝格测度是唯一的测度

  还有 Stieltjes 测度、Hausdorff 测度、概率测度……

错误六：用 $m^(A\cap E)+m^(A\cap E^c)$ 验证可测时只检查几个 $A$

  必须对一切 $A$ 成立（实际计算时通常用等价条件）。

三、深入：不可测集的构造

  （这一部分是完整推导。）

维塔利集的构造

用选择公理

  在 $[0,1)$ 上定义等价关系：$x\sim y$ 当 $x-y\in\mathbb{Q}$。

  每个等价类是 ${x+q:q\in\mathbb{Q}}$——可数多个，且在 $[0,1)$ 里"处处稠密"。

  由选择公理，从每个等价类里选一个代表，组成集合 $V$。

  考虑 $V$ 的有理平移：

$$V+q={v+q:v\in V},\qquad q\in\mathbb{Q}\cap[-1,1]$$

  关键事实：

  1. 这些 $V+q$ 两两不交（若 $V+q_1$ 与 $V+q_2$ 有交，则对应元素同属一个等价类，与"每类只选一个"矛盾）
  2. 它们的并覆盖 $[0,1)$（每个 $x$ 与某个 $v$ 同等价类，即 $x=v+q$）

  现在用反证：假设 $V$ 可测，且 $m(V)=a$。

  由平移不变：$m(V+q)=a$ 对一切 $q$。

  由可加性（$V+q$ 互不相交）：

$$m\left(\bigcup_{q}V+q\right)=\sum_{q}a$$

  而并覆盖 $[0,1)$，所以 $m\ge1$；同时并含在 $[-1,2)$ 里，所以 $m\le3$。

  若 $a=0$：$\sum a=0$，与 $m\ge1$ 矛盾。

  若 $a>0$：$\sum a=\infty$，与 $m\le3$ 矛盾。

  两边都矛盾 ⟹ $V$ 不可测 ✓ $\blacksquare$

为什么必须用选择公理

  索洛维（Solovay, 1970）证明：

若放弃选择公理（接受 ZF + "所有集合都勒贝格可测"），可以构造一个一致的集合论。

  所以"不可测集"的存在性等价于选择公理的一部分力量。

  这就是著名的"Banach-Tarski 悖论"的来源：用选择公理，可以把一个球拆成有限块，再拼成两个同样大小的球。

  （这不是数学的 bug，而是"测度 vs 分解"的边界。）

可测性的等价条件

  实用上不直接验证 Carathéodory 条件，而用：

定理：$E$ 可测 ⟺ 对任意 $\varepsilon>0$，存在开集 $O\supseteq E$ 与闭集 $F\subseteq E$ 使 $m^*(O\setminus F)<\varepsilon$。

  直觉：可测集"几乎"是开集（也是闭集）——用开闭集可以任意逼近。

  推论：可测集可写成 $F_\sigma$（可数个闭集的并） 与 $G_\delta$（可数个开集的交） 的"差一个零测集"。

  这叫"结构定理"——它说明勒贝格可测集的结构其实很简单。

四、拓展

  （这一部分真正可选。）

历史：从"面积"到"测度"

时间 人物 贡献
1881 哈纳克 集合"内容"（容度）的初步思想
1898 博雷尔 博雷尔测度（可数可加）
1902 勒贝格 测度与积分的完整理论（博士论文）
1905 维塔利 不可测集
1914 豪斯多夫 Hausdorff 测度（维数）
1924 巴拿赫、塔斯基 分球悖论
1970 索洛维 不可测集与选择公理

  勒贝格的博士论文《积分、长度与面积》（1902）只有 130 页，却重建了整个积分理论。

  它一开始被相当排斥——因为"不可测集"的概念太反直觉。

"测度"这个词的词源

  measure 来自拉丁语 mensura（测量）。

  而勒贝格用的法语词是 mesure——同一个词。

  中文"测度" 是"测量 + 度量"的组合——直译了英文。

  小知识："概率"就是"全空间测度为 1 的测度"——这也是概率论的现代基础（柯尔莫哥洛夫 1933）。

联系：概率论就是测度论

  柯尔莫哥洛夫 1933 年的《概率论基础》 把概率定义为测度：

概率论 测度论
样本空间 $\Omega$ 全空间
事件 可测集
概率 $P(A)$ 测度 $m(A)$
$P(\Omega)=1$ 归一化
随机变量 $X$ 可测函数
数学期望 $E[X]$ 勒贝格积分

  所以"概率论"是"测度论 + 归一化"。

  而这解释了很多初学概率时的困惑：

  • 为什么"概率为 0 的事件"也可能发生？（比如在 $[0,1]$ 上随机取到 0.5）
    ——因为那是"测度为 0"，不是"不可能"。
  • 为什么"概率为 1"不等于必然？
    ——因为零测集可以非空。

应用：Cantor 集与分形维数

  Cantor 集的勒贝格测度是 0——但它的"维数"不是 0。

  Hausdorff 维数：

$$d=\frac{\ln 2}{\ln 3}\approx0.6309$$

  为什么：Cantor 集由 2 份（左、右）各缩小到 1/3 的拷贝组成。

  一般地：若分形由 $N$ 份各缩小到 $1/s$，则维数是 $\dfrac{\ln N}{\ln s}$。

  例：

分形 $N$ $1/s$ 维数
Cantor 集 2 1/3 0.631
Sierpinski 三角 3 1/2 1.585
Sierpinski 地毯 8 1/3 1.893
Koch 曲线 4 1/3 1.262

  所以"测度为 0"不等于"简单"——它只是说"一维长度"这个度量不合适。

  要描述分形，必须用"维数不是整数"的测度——这就是 Hausdorff 测度。

  [3]AXLER S. Measure, Integration & Real Analysis[M]. Cham: Springer, 2020.参考资料——第 2 章测度（含大量图示，最适合入门）。

小结

概念 要点
外测度 可数区间覆盖的总长度下确界；只次可加
可测集 Carathéodory 条件；构成 $\sigma$-代数
勒贝格测度 在可测集上满足可数可加
有理数集 稠密但测度 0
Cantor 集 测度 0 但不可数
不可测集 维塔利集（需选择公理）
概率 归一化的测度

下一节预告

有了测度，就能定义"集合的大小"。

  下一步是"函数"：

什么样的函数，才能"横着切"？

  答案是可测函数——它的定义是：

$f^{-1}((a,\infty))$ 对一切 $a$ 都是可测集。

  这个定义看起来抽象，但它是"横着切"的严格表述。
