前置知识：3.1 节（三个基本格式）、3.2 节（三种稳定性方法概览）、复变函数基础（单位圆、幅角）。

为什么单开一节讲它

  3.2 节已经介绍过 von Neumann 方法的步骤，也给出了三个格式的结果。但它是工程实践中最常用、也最容易被误用的工具——很多论文和代码里的稳定性结论其实是错的，原因正是在不满足条件时硬套。

  本节把它的完整理论、操作细节、失效场景讲透。

3.13 理论基础：Fourier 分解

3.13.1 为什么可以逐模态分析

  关键在于线性性：若格式是线性的，则误差的每个 Fourier 模态独立演化，互不干扰。

  设周期区域 $[0,l]$，网格 $x_j=jh$。任何网格函数可以展开成离散 Fourier 级数：

$$u_j = \sum_{\omega}\hat u(\omega)e^{i\omega x_j}, \qquad \omega = \frac{2\pi m}{l} \tag{3.13.1}$$

  由于格式线性，作用在每项上的结果是乘一个放大因子：

$$u_j^{k+1} = \sum_\omega \lambda(\omega)\hat u^k(\omega)e^{i\omega x_j} \tag{3.13.2}$$

  稳定性（$L^2$ 意义）等价于

$$|\lambda(\omega)| \le 1 \quad\text{对所有 } \omega \tag{3.13.3}$$

  （严格说是 $|\lambda|\le1+O(\Delta t)$，允许"弱不稳定"；下面会澄清。）

三个前提缺一不可：

  1. 线性 —— 非线性格式没有 Fourier 模态的概念
  2. 常系数 —— 变系数时 $\lambda$ 依赖 $j$，不能全局分解
  3. 周期边界 —— 非周期边界下，$e^{i\omega x}$ 不是 边界条件的特征函数

第 3 条最容易被忽略。举例：Dirichlet 边界 $u(0)=u(l)=0$ 下，真正的本征函数是 $\sin(m\pi x/l)$，不是 $e^{i\omega x}$。用指数做分析相当于假设了周期延拓，与真实边界不符。

实践中：内部区域足够大时，边界影响可以忽略，von Neumann 结论"通常"成立。但边界附近可能出现局部不稳定——这就是为什么实际计算中会看到"内部正常但边界附近振荡"。

3.13.2 与 Lax-Richtmyer 等价定理的关系

  回顾 Lax 等价定理（3.2 节提过）：

$$\text{相容} + \text{稳定} \iff \text{收敛}$$

  von Neumann 条件给出的正是"稳定"这一项（在上述三个前提下）。

  但注意范围：Lax-Richtmyer 定理的严格叙述要求：

  • 线性
  • 常系数（或至少足够光滑）
  • 适定的初值问题
  • 一对范数下的相容性

超出这个范围时，即使用 von Neumann 算出 $|\lambda|\le1$，也不能断言收敛。反过来，von Neumann 不稳定则一定不收敛（这个方向是安全的）。

3.14 完整操作流程

3.14.1 五步法

第 1 步：写出差分格式，只保留齐次部分（去掉源项与非齐次边界），因为它决定误差的演化。

第 2 步：设误差模态
$$e_j^k = \lambda^k e^{i\beta j}, \qquad \beta = \omega h \in [-\pi,\pi]$$

  （用 $\beta$ 代替 $\omega h$，因为只有 $\beta$ 出现在格式里。）

第 3 步：代入，消去公共因子 $\lambda^k e^{i\beta j}$，得到关于 $\lambda$ 的代数方程。

第 4 步：解出 $\lambda(\beta)$。

第 5 步：求 $\max_{\beta\in[-\pi,\pi]}|\lambda(\beta)|$，要求 $\le1$。

一个实用技巧：$\lambda(\beta)$ 通常可以写成

$$\lambda = a_0 + a_1\cos\beta + a_2\cos2\beta + \cdots$$

或者用半角公式化成 $s = \sin^2(\beta/2)$ 的多项式。

因为 $\cos\beta = 1-2\sin^2(\beta/2) = 1-2s$，而 $s\in[0,1]$ 单调遍历。

于是问题变成"多项式在 $[0,1]$ 上是否有界" ——这比直接对 $\beta$ 求极值容易得多。

3.14.2 算例：对流方程（暴露 von Neumann 的局限）

  考虑一阶对流方程：

$$u_t + c,u_x = 0, \qquad c>0 \tag{3.14.1}$$

  用中心差分（空间）+ 前向 Euler（时间）：

$$\frac{u_j^{k+1}-u_j^k}{\Delta t} + c\frac{u_{j+1}^k-u_{j-1}^k}{2h} = 0 \tag{3.14.2}$$

  代入模态，设 $\nu = c\Delta t/h$（Courant 数）：

$$\lambda = 1 - \nu\frac{e^{i\beta}-e^{-i\beta}}{2} = 1 - i\nu\sin\beta \tag{3.14.3}$$

  放大因子的模：

$$|\lambda|^2 = 1 + \nu^2\sin^2\beta \ge 1 \tag{3.14.4}$$

  对任何 $\nu\ne0$、$\beta\ne0,\pi$，都有 $|\lambda|>1$——无条件不稳定！

这是一个非常著名的结果：中心差分 + 前向 Euler 求解对流方程，永远不稳定。

物理原因：中心差分是"对称"的，它不知道该往哪个方向传播信息。而真实的对流是单向的（信息从上游传到下游）。

对策是迎风格式（4.4 节详述）：差分方向与波传播方向一致。

这个例子说明：von Neumann 分析能正确地发现不稳定，但它不告诉你"为什么"，也不告诉你"该怎么改"。稳不稳定的机理要靠物理直觉。

3.15 常见的失效场景

3.15.1 情形一：变系数

  考虑 $u_t = a(x)u_{xx}$，$a(x)$ 随位置变化。

  若在每点用局部 $r_i = a(x_i)\Delta t/h^2$ 做 von Neumann 分析，得到"每点都稳定"——但这个结论不成立。

  原因：Fourier 模态在变系数介质里会散射（不同频率之间耦合），不再是独立演化。局部分析只能给出必要条件。

  正确的做法：用能量法（乘以 $u$ 再积分）或冻结系数法（取 $a$ 的最大值给一个保守的界）。

3.15.2 情形二：非周期边界

  Dirichlet 边界下，$e^{i\beta j}$ 不满足 $u_0=0$。

  边界处的行为可能比内部差。经典例子：显式格式 + Neumann 边界 + 虚拟点法，边界点的有效 $r$ 是内部的两倍，所以边界先失稳。

怎么发现这种局部失稳：

  1. 算边界点的等效系数——如果它比内部更"危险"（比如更大的 $r$），就调整边界格式
  2. 实际跑数值实验——取一个高频初值，看边界附近是否振荡
  3. 用矩阵法（3.2 节）——它自动包含边界的影响，给出真正的最小/最大特征值

这就是为什么矩阵法虽然麻烦，但在边界复杂时更可靠。

3.15.3 情形三：多步法 / 多层时间格式

  对三层时间格式（如 leapfrog），代入 $u_j^k=\lambda^ke^{i\beta j}$ 后得到的是关于 $\lambda$ 的二次方程：

$$a_2\lambda^2 + a_1\lambda + a_0 = 0 \tag{3.15.1}$$

  两个根都必须满足 $|\lambda_{1,2}|\le1$。

  常见的陷阱：只看主根。副根（寄生根）往往对应物理上不存在的高频振荡，但它会让格式不稳定。这与第 1 章多步法的寄生根问题完全同构。

3.15.4 情形四：非线性

  非线性方程（如 Burgers 方程 $u_t+uu_x=\nu u_{xx}$）没有全局 Fourier 分解。

  工程做法：冻结系数——在某个典型解 $u_0$ 处把系数当作常数，做 von Neumann 分析。这给出局部稳定性条件，通常够用，但不能保证全局。

  反例：某些格式局部稳定，但因为非线性项的能量级联导致爆破解（湍流模拟中的"数值爆炸"）。

3.16 代码：自动判定稳定性

运行结果的关键看点：

  1. 热传导：$r=0.5$ 时恰好 $|\lambda|=1$；$r=0.51$ 立刻 $>1$。
  2. 对流中心差分：任何 $\nu>0$ 都是不稳定的——验证了 (3.14.4)。
  3. 迎风：$\nu\le1$ 稳定（这就是 CFL 条件 $c\Delta t\le h$），$\nu>1$ 不稳定。
  4. Lax-Friedrichs：同样要求 $\nu\le1$。

同样是对流方程，三种空间离散给出完全不同的稳定性——这就是为什么"选对方差格式"比"调步长"更重要。

3.17 小结

要点 内容
理论基础 线性 + 常系数 + 周期 → Fourier 模态独立演化
判据 $\max_\beta\vert\lambda(\beta)\vert\le1$
计算技巧 用 $s=\sin^2(\beta/2)\in[0,1]$ 化多项式
与 Lax-Richtmyer von Neumann 只解决"稳定"这一项
失效场景 变系数、非周期边界、多步法寄生根、非线性

易错点

  1. 必须有周期边界——非周期时 $e^{i\beta j}$ 不是本征函数，结论只是必要条件；
  2. 多步法要检查所有根，不能只看主根；
  3. 变系数不能用局部分析下结论，得用最大值给保守界；
  4. von Neumann 不稳定 ⟹ 必然不收敛（这个方向可靠），稳定 ⟹ 收敛（需额外条件）；
  5. 它不告诉你如何改 ——中心差分不稳定的解法是换迎风，不是调步长。

  下一节 3.4 讲变系数与分数步长法：ADI、LOD、预测-校正——如何在二维/三维保持高效与稳定。
