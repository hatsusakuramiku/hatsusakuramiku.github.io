前置知识：多元微积分（散度定理、格林公式）、高斯定理。

1.2.3 拉普拉斯方程

  上一节末尾已经看到，热传导方程的稳态（ut=0u_t=0ut​=0、无源）就是拉普拉斯方程。但拉普拉斯方程的物理来源不止一个——它是**所有"无源稳态场"**的通用方程。本节从两个独立角度推导，再看它的解（调和函数）有哪些特殊性质。

1.2.3.1 静电场：从高斯定理出发

  静电学的高斯定理（无源区域）：通过任意闭合曲面的电通量等于其内部电荷除以介电常数。无电荷时：

∯∂VE⃗⋅dS⃗=0(1.2.15)\oiint_{\partial V}\vec{E}\cdot d\vec{S} = 0 \tag{1.2.15} ∬​∂V​E⋅dS=0(1.2.15)

  由散度定理，对任意 VVV：

∭V∇⋅E⃗ dV=0  ⟹  ∇⋅E⃗=0(1.2.16)\iiint_V \nabla\cdot\vec{E}\,dV = 0 \;\Longrightarrow\; \nabla\cdot\vec{E} = 0 \tag{1.2.16} ∭V​∇⋅EdV=0⟹∇⋅E=0(1.2.16)

  另由静电场的无旋性（可引入电势 uuu）：

E⃗=−∇u(1.2.17)\vec{E} = -\nabla u \tag{1.2.17} E=−∇u(1.2.17)

  两者结合：

∇⋅(−∇u)=0  ⟹  Δu=0(1.2.18)\nabla\cdot(-\nabla u) = 0 \;\Longrightarrow\; \Delta u = 0 \tag{1.2.18} ∇⋅(−∇u)=0⟹Δu=0(1.2.18)

  这就是静电场中的电势方程。

两个基本性质的分工：

  • 无旋（∇×E⃗=0\nabla\times\vec E = 0∇×E=0）→ 存在势函数 E⃗=−∇u\vec E = -\nabla uE=−∇u；
  • 无源（∇⋅E⃗=0\nabla\cdot\vec E = 0∇⋅E=0）→ 势函数满足 Δu=0\Delta u=0Δu=0。

如果区域内有电荷（密度 ρe\rho_eρe​），则第一式变为 ∇⋅E⃗=ρe/ε0\nabla\cdot\vec E = \rho_e/\varepsilon_0∇⋅E=ρe​/ε0​，得到泊松方程：

Δu=−ρeε0\Delta u = -\frac{\rho_e}{\varepsilon_0} Δu=−ε0​ρe​​

1.2.3.2 稳态温度场：从能量守恒出发

  直接回到 1.2.2 节的 (1.2.12)：

cρut+∇⋅q⃗=Fc\rho u_t + \nabla\cdot\vec{q} = F cρut​+∇⋅q​=F

  稳态（ut=0u_t=0ut​=0）、无热源（F=0F=0F=0）时，∇⋅q⃗=0\nabla\cdot\vec q = 0∇⋅q​=0，再由 q⃗=−k∇u\vec q = -k\nabla uq​=−k∇u 得 Δu=0\Delta u = 0Δu=0 ✓

  与静电场完全同构——傅里叶定律 q⃗=−k∇u\vec q=-k\nabla uq​=−k∇u 对应 E⃗=−∇u\vec E=-\nabla uE=−∇u，能量守恒对应高斯定理。这不是巧合，而是所有"势场 + 守恒律"系统共有的数学结构。

1.2.3.3 三维与二维形式

Δu=∂2u∂x2+∂2u∂y2+∂2u∂z2=0（三维）(1.2.19)\Delta u = \frac{\partial^2u}{\partial x^2}+\frac{\partial^2u}{\partial y^2}+\frac{\partial^2u}{\partial z^2} = 0 \quad\text{（三维）} \tag{1.2.19} Δu=∂x2∂2u​+∂y2∂2u​+∂z2∂2u​=0（三维）(1.2.19)

Δu=∂2u∂x2+∂2u∂y2=0（二维）(1.2.20)\Delta u = \frac{\partial^2u}{\partial x^2}+\frac{\partial^2u}{\partial y^2} = 0 \quad\text{（二维）} \tag{1.2.20} Δu=∂x2∂2u​+∂y2∂2u​=0（二维）(1.2.20)

  二维情形有丰富的复分析背景：二元调和函数恰好是某个解析函数的实部或虚部（柯西-黎曼方程直接给出）。这使得二维拉普拉斯方程可以用复变函数方法求解——这是 2.3 节极坐标解法之外的另一条路。

  极坐标与球坐标形式（2.3、2.5 节已用）：

∂2u∂r2+1r∂u∂r+1r2∂2u∂θ2=0（极坐标）\frac{\partial^2u}{\partial r^2}+\frac{1}{r}\frac{\partial u}{\partial r}+\frac{1}{r^2}\frac{\partial^2u}{\partial\theta^2} = 0 \quad\text{（极坐标）} ∂r2∂2u​+r1​∂r∂u​+r21​∂θ2∂2u​=0（极坐标）

r2urr+2rur+1sin⁡θ∂∂θ(sin⁡θuθ)+1sin⁡2θuφφ=0（球坐标，乘 r2 后）r^2u_{rr}+2ru_r+\frac{1}{\sin\theta}\frac{\partial}{\partial\theta}(\sin\theta u_\theta)+\frac{1}{\sin^2\theta}u_{\varphi\varphi} = 0 \quad\text{（球坐标，乘 }r^2\text{ 后）} r2urr​+2rur​+sinθ1​∂θ∂​(sinθuθ​)+sin2θ1​uφφ​=0（球坐标，乘 r2 后）

1.2.3.4 调和函数的三个核心性质

  满足 Δu=0\Delta u=0Δu=0 的函数称为调和函数。它们有一系列性质，这些性质正是后面"极值定理"“最大值原理”（差分法收敛性证明的关键）的来源。

性质一：平均值定理

  设 uuu 在球 B(M0,R)B(M_0,R)B(M0​,R) 内调和，则 uuu 在球心处的值等于球面上的平均值：

u(M0)=14πR2∯∂Bu(M) dS(1.2.21)u(M_0) = \frac{1}{4\pi R^2}\oiint_{\partial B}u(M)\,dS \tag{1.2.21} u(M0​)=4πR21​∬​∂B​u(M)dS(1.2.21)

  同时也等于球体内的体积平均值：

u(M0)=34πR3∭Bu(M) dV(1.2.22)u(M_0) = \frac{3}{4\pi R^3}\iiint_B u(M)\,dV \tag{1.2.22} u(M0​)=4πR33​∭B​u(M)dV(1.2.22)

直观理解：假设把 uuu 理解成"温度"。球心温度等于球面平均温度——这意味着不可能有局部最高点或最低点（如果有，平均值就不等于中心值）。这个"不可能有极值"就是下面的极值原理。

  证明思路（球面平均）：记

I(R)=14πR2∯∂B(M0,R)u dSI(R) = \frac{1}{4\pi R^2}\oiint_{\partial B(M_0,R)}u\,dS I(R)=4πR21​∬​∂B(M0​,R)​udS

  作变量代换化为单位球上的积分，对 RRR 求导，利用格林公式与 Δu=0\Delta u=0Δu=0 得 I′(R)=0I'(R)=0I′(R)=0，即 III 是常数；再令 R→0R\to0R→0，I(0)=u(M0)I(0)=u(M_0)I(0)=u(M0​)。

性质二：极值原理（强形式）

  定理：若 uuu 在有界区域 Ω\OmegaΩ 内调和且在闭区域 Ωˉ\bar\OmegaΩˉ 上连续，则 uuu 的最大值与最小值都在边界上取得；若最大值同时在内部某点取得，则 uuu 恒为常数。

  证明：设 uuu 在内部 M0M_0M0​ 处取最大值 MMM。由平均值定理，$M = u(M_0) = $ 球面平均。而球面上各点 ≤M\le M≤M，平均值等于 MMM 当且仅当所有点都等于 MMM。于是邻域内 u≡Mu\equiv Mu≡M，再用连通性推广到整个 Ω\OmegaΩ。

极值原理的作用在后头：第 2 章椭圆型方程差分法的敛速估计（教材第 2 章第 5 节）完全依赖离散版的极值原理。连续版本的这个定理，就是它的来源。理解这个连续证明，离散证明几乎可以照抄（把积分换成求和）。

性质三：解析性与唯一性

  调和函数是无穷次可微的，甚至是解析的（在区域内每点可展开为收敛的幂级数）。这是椭圆型方程的一个特殊"好"性质——与抛物型（瞬时后光滑）和双曲型（只保留初始正则性）都不同。

  唯一性定理（狄利克雷问题的适定性）：边值问题

{Δu=0,M∈Ωu∣∂Ω=f\begin{cases}\Delta u=0, & M\in\Omega \\\\ u|_{\partial\Omega}=f\end{cases} ⎩⎪⎨⎪⎧​Δu=0,u∣∂Ω​=f​M∈Ω

至多有一个解。

  证明：设 u1,u2u_1,u_2u1​,u2​ 都是解，则 w=u1−u2w=u_1-u_2w=u1​−u2​ 调和且边界为零。由极值原理，www 的最大值与最小值都在边界上，而边界上 w=0w=0w=0，故 0≤w≤00\le w\le00≤w≤0，即 w≡0w\equiv0w≡0 ✓

  这个"用极值原理证唯一性"的套路，会直接搬到差分格式上——数值解的唯一性和收敛性估计用的就是同一条思路。

1.2.3.5 与波动、热传导方程的对照

波动方程 热传导方程 拉普拉斯方程
形式 utt=a2Δuu_{tt}=a^2\Delta uutt​=a2Δu ut=a2Δuu_t=a^2\Delta uut​=a2Δu Δu=0\Delta u=0Δu=0
类型 双曲型 抛物型 椭圆型
定解条件 初值 + 边界 初值 + 边界 只需边界（无初始条件）
时间方向 有（可逆） 有（不可逆） 无时间
解的光滑性 保留初始正则性 瞬时后光滑 无穷光滑（解析）
名字 振动 扩散 稳态/平衡

  关键差异：拉普拉斯方程是静态的（不含时间），所以定解问题只需要边界条件，不需要初始条件。这也是为什么 2.3 节圆域问题只给了 u(R,θ)=f(θ)u(R,\theta)=f(\theta)u(R,θ)=f(θ) 一条边界条件就足够。

1.2.3.6 一个例子

  例 1.2.2 求半径 RRR 的球内电势，球面电势为 u(R,θ)=cos⁡θu(R,\theta)=\cos\thetau(R,θ)=cosθ。

  解：由 2.5 节的球坐标分离变量，球内解为

u(r,θ)=∑ℓ=0∞Aℓ(rR)ℓPℓ(cos⁡θ)u(r,\theta) = \sum_{\ell=0}^\infty A_\ell\left(\frac{r}{R}\right)^\ell P_\ell(\cos\theta) u(r,θ)=ℓ=0∑∞​Aℓ​(Rr​)ℓPℓ​(cosθ)

  边界条件 cos⁡θ=P1(cos⁡θ)\cos\theta = P_1(\cos\theta)cosθ=P1​(cosθ)，由正交性直接读出 A1=1A_1=1A1​=1，其余为零：

u(r,θ)=rRP1(cos⁡θ)=rcos⁡θR=zRu(r,\theta) = \frac{r}{R}P_1(\cos\theta) = \frac{r\cos\theta}{R} = \frac{z}{R} u(r,θ)=Rr​P1​(cosθ)=Rrcosθ​=Rz​

  验证：rcos⁡θ=zr\cos\theta = zrcosθ=z，所以 u=z/Ru=z/Ru=z/R 是一个一次多项式，Δ(z/R)=0\Delta(z/R)=0Δ(z/R)=0 ✓

  物理意义：均匀外电场中的导体球（无净电荷时），球内电势是均匀场 E⃗0\vec E_0E0​ 的势——这是静电屏蔽的数学表述。

易错点

  1. 拉普拉斯方程无初始条件——它不含时间，别多此一举加 u(x,0)u(x,0)u(x,0)；
  2. 极值原理要求 uuu 连续到边界——不连续时结论可能不成立；
  3. 调和函数无穷光滑，但不能由此推出"边界上的连续性会传递到内部"（边界可以有跳变，内部仍光滑，但边界点本身不连续）；
  4. 二维情形可用复解析函数构造调和函数，但三维不行——复数只有二维，"复分析简化求解"是二维特有。

下一节预告

  三类方程的建立已齐：波动（双曲）、热传导（抛物）、拉普拉斯（椭圆）。下一步 1.3 节要回答一个更关键的问题：给定一个偏微分方程，还需要附加哪些条件，解才唯一且稳定？ 这就是"定解条件"与"适定性"的内容。
