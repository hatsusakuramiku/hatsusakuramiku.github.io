前置知识：5.4 节（Ritz/Galerkin 法）。5.2 节可选读。

这一节做什么

  5.4 节说"选基函数 $\phi_j$，算矩阵 $A_{ij}$，解方程"。听起来简单，但实际写代码时会撞上三件事：

  1. 基函数怎么选才方便算？
  2. 积分怎么算？$\int\phi_i^{\prime}\phi_j^{\prime}$ 这种复合函数，手算不现实。
  3. 边界条件怎么加？Dirichlet 和 Neumann 处理方式完全不同。

  这一节把一维有限元从头到尾走一遍，最后能直接跑出结果。

5.13 基函数：为什么用"帐篷"

直观：每个点一把"小伞"

  把 $[a,b]$ 分成 $N$ 段，节点 $x_0<x_1<\dots<x_N$。

  在第 $j$ 个节点上放一个帐篷函数（hat function）：

  • 在 $x_j$ 处等于 1
  • 在 $x_{j\pm1}$ 处等于 0
  • 在两个相邻单元内线性变化，其余地方为 0

$$\phi_j(x) = \begin{cases}
\dfrac{x-x_{j-1}}{h}, & x_{j-1}\le x\le x_j \[6pt]
\dfrac{x_{j+1}-x}{h}, & x_j\le x\le x_{j+1} \[6pt]
0, & \text{其他}
\end{cases} \tag{5.13.1}$$

为什么选它

性质 好处
$\phi_j(x_i)=\delta_{ij}$ 系数 $c_j$ 直接就是节点值——物理意义清楚
支集只有两个单元宽 矩阵稀疏（只有三对角）
分片线性、连续 属于 $H^1$（5.2 节），合法
局部构造 单元刚度矩阵可以复用——这是有限元效率的核心

"系数就是节点值"这一条特别重要：

$$u_h(x_i) = \sum_j c_j\phi_j(x_i) = c_i$$

所以解出来的向量 $\mathbf{c}$ 就是各节点上的函数值——不需要额外插值。

这解释了为什么有限元的结果可以直接画成折线图：向量 $\mathbf{c}$ 就是折线图的顶点。

对比谱方法：Fourier 系数 $\hat u_k$ 没有直接的物理意义，要合成回来才知道函数长什么样。

5.14 单元刚度矩阵：可复用的最小积木

核心思想：把大问题拆成小积木

  关键观察：$\phi_j$ 只在 $[x_{j-1},x_j]$ 与 $[x_j,x_{j+1}]$ 上非零。所以

$$A_{ij} = \int_a^b(\phi_j^{\prime}\phi_i^{\prime}+q\phi_j\phi_i)dx$$

  只有当 $|i-j|\le1$ 时非零——这就是三对角矩阵的由来。

  而且，每个单元上的积分长得都一样（只要单元长度相同）：

单元刚度矩阵（在单元 $[x_{e},x_{e+1}]$ 上，长度 $h$）：

$$K^e = \frac1h\begin{pmatrix}1&-1\\-1&1\end{pmatrix} \qquad\text{（来自 }\int\phi^{\prime}\phi^{\prime}\text{）} \tag{5.14.1}$$

单元质量矩阵（来自 $\int\phi\phi$，当 $q$ 为常数时）：

$$M^e = \frac h6\begin{pmatrix}2&1\\1&2\end{pmatrix} \tag{5.14.2}$$

  整个大矩阵就是把这两块积木拼起来：

$$A = \frac1h\begin{pmatrix}
2&-1&&\\-1&2&-1&\\&-1&2&-1\\&&&\ddots\end{pmatrix} + \frac{qh}{6}\begin{pmatrix}
4&1&&\\1&4&1&\\&1&4&1\\&&&\ddots\end{pmatrix}$$

单元刚度矩阵的推导（可选读）

单元 $[0,h]$ 上的两个基函数：

$$\phi_1(x) = 1-\frac xh, \qquad \phi_2(x) = \frac xh$$

导数：$\phi_1^{\prime}=-1/h$，$\phi_2^{\prime}=1/h$（都是常数）。

刚度矩阵：

$$K^e_{ij} = \int_0^h\phi_j^{\prime}\phi_i^{\prime}\quad dx = \left(\pm\frac1h\right)\left(\pm\frac1h\right)\cdot h$$

逐项算：

$$K^e_{11} = \frac1{h^2}\cdot h = \frac1h,\quad
K^e_{12} = -\frac1{h^2}\cdot h = -\frac1h$$

$$K^e_{21} = -\frac1h,\quad K^e_{22} = \frac1h$$

质量矩阵：

$$M^e_{11} = \int_0^h\left(1-\frac xh\right)^2dx = \frac h3,\quad
M^e_{12} = \int_0^h\left(1-\frac xh\right)\frac xh\quad dx = \frac h6$$

$$M^e_{21} = \frac h6,\quad M^e_{22} = \frac h3$$

注意 $M^e$ 的行和 $=h$——这保证常数函数的积分 $=h$（正确的物理量）。

验证 $M^e$ 与 (5.14.2) 一致：$\frac h3 = \frac{2h}{6}$，对。$\blacksquare$

5.15 组装：把积木拼成大厦

  设单元 $e$ 连接节点 $e$ 与 $e+1$。把它贡献的项加到全局矩阵的对应位置：

  伪代码（这是所有有限元程序的核心）：

  注意是 += 不是 =——节点 $e$ 同时属于单元 $e-1$ 与 $e$，它的贡献要被累加两次。

这是新手最常犯的错误：写成 = 而不是 +=

症状：结果看起来"差不多对"但精度只有一半，或者随着网格加密反而不收敛。

原因：每个节点被两个单元共享，只赋值会丢掉一半贡献。

自检方法：常数函数必须被精确表示。若取 $u\equiv1$（即所有系数为 1），则刚度矩阵乘以全 1 向量应得零（因为 $u^{\prime}=0$）：
  $A\cdot\mathbf{1} = 0$

这是一个不用真解就能做的检查。

5.16 边界条件：两类的处理完全不同

Dirichlet（第一类）：改矩阵

  $u(a)=\alpha$。做法：把对应行清空，对角置 1，右端改为 $\alpha$：

$$A_{00}=1,\quad A_{0j}=0\ (j\ne0),\quad b_0=\alpha \tag{5.16.1}$$

  注意：其他行的右端也要减掉 $A_{i0}\alpha$（因为 $u_0$ 已知）：

$$b_i \leftarrow b_i - A_{i0}\alpha,\qquad i\ne0 \tag{5.16.2}$$

Neumann（第二类）：什么都不用做

  $u^{\prime}(b)=\gamma$。5.1 节说过这是自然边界条件——它已经被弱形式包含了：

$$b_N \leftarrow b_N + \gamma \tag{5.16.3}$$

  只改右端，不动矩阵。 这就是"自然"的意思。

这两者的对比是有限元最优雅的地方：

Dirichlet Neumann
本质 强制约束 自动满足
改哪里 矩阵 + 右端 只改右端
物理类比 把端点钉死 端点受到给定力的作用

对工程的意义：结构力学里大量边界是"自由的"（Neumann），有限元处理起来几乎是零成本。这就是有限元在结构分析中碾压差分法的原因（2.2 节差分法要做虚拟点）。

  2. 自检 max|A·1| 在 $10^{-16}$ 量级——常数函数被精确表示，说明组装正确

第 2 点是调试有限元代码的第一道关。如果你的代码自检不通过，一定是组装或边界处理写错了，不用去查别的地方。

这个自检的通用性：任何"无源、常数边界"的问题，解都应该是常数。所以这个检查对任意椭圆型有限元都适用，不限一维。

5.18 小结

步骤 内容 关键点
1. 选基函数 帐篷函数 系数 = 节点值
2. 单元矩阵 $K^e$、$M^e$ 可复用，与位置无关
3. 组装 += 累加 不能写成 =
4. 右端 数值积分 $\int f\phi_i$
5. 边界 Dirichlet 改矩阵、Neumann 只改右端 自然 vs 本质
6. 求解 解三对角方程组 $O(N)$

易错点

  1. 组装必须 +=——节点被两个单元共享；
  2. Dirichlet 边界要同时改矩阵和右端，漏掉右端修正会导致边界不精确；
  3. Neumann 边界不碰矩阵——碰了就说明搞错了；
  4. 自检用 $A\cdot\mathbf{1}=0$——这是最有效的调试手段；
  5. $f$ 的积分用中点公式时误差是 $O(h^2)$——与基函数同阶，不会拖后腿。
