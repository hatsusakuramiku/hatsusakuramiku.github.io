前置知识：泰勒展开、中值定理、一阶常微分方程初值问题的适定性。

1.1 一阶常微分方程初值问题

  本系列从最简单的问题开始：

$$\begin{cases} y^{\prime}(t) = f(t,y), & a \le t \le b \ y(a) = y_0 \end{cases} \tag{1.1.1}$$

  这是一阶常微分方程（ODE）的初值问题，也叫 Cauchy 问题。

  解的存在唯一性：若 $f(t,y)$ 在区域 $D = {(t,y): a\le t\le b,\ |y|<\infty}$ 上连续，且关于 $y$ 满足 Lipschitz 条件——存在常数 $L$ 使

$$|f(t,y_1) - f(t,y_2)| \le L|y_1-y_2| \tag{1.1.2}$$

  则初值问题 (1.1.1) 在 $[a,b]$ 上有唯一解。$L$ 称为 Lipschitz 常数。

为什么必须有 Lipschitz 条件？反例：$y^{\prime} = \sqrt{|y|}$，$y(0)=0$。它有两个解：$y\equiv0$ 和 $y = t^2/4$（当 $t\ge0$）。这是因为 $\sqrt{|y|}$ 在 $y=0$ 附近不满足 Lipschitz 条件。

几乎所有数值方法的误差估计都要用到 $L$——它衡量了"解对初值扰动的敏感程度"。

1.2 Euler 法的推导

  数值解的基本思路：把连续区间 $[a,b]$ 离散化，只求有限个点上的近似值。

  取步长 $h = (b-a)/n$，节点 $t_k = a + kh$（$k=0,1,\dots,n$）。记 $y_k \approx y(t_k)$。

1.2.1 从泰勒展开出发

  把精确解 $y(t)$ 在 $t_k$ 处做泰勒展开：

$$y(t_{k+1}) = y(t_k) + h y^{\prime}(t_k) + \frac{h^2}{2}y^{\prime\prime}(\xi_k) \tag{1.2.1}$$

  由方程 $y^{\prime}(t_k) = f(t_k, y(t_k))$，代入：

$$y(t_{k+1}) = y(t_k) + h f(t_k, y(t_k)) + \frac{h^2}{2}y^{\prime\prime}(\xi_k)$$

  丢掉二阶项，并用 $y_k$ 代替 $y(t_k)$，得到Euler 法（显式 Euler、前向 Euler）：

$$y_{k+1} = y_k + h f(t_k, y_k), \qquad k = 0,1,\dots,n-1 \tag{1.2.2}$$

几何意义：Euler 法用切线近似曲线。

在点 $(t_k, y_k)$ 处，解曲线的切线斜率是 $f(t_k,y_k)$。沿着这条切线走一小步 $h$，到达 $y_k + hf(t_k,y_k)$——这就是 $y_{k+1}$。

误差的来源很清楚：曲线是弯的，切线是直的。步长越小，弯曲的影响越小。

1.2.2 局部截断误差

  定义：把精确解代入格式后，两边之差称为局部截断误差（LTE, local truncation error）。

  对 Euler 法，设 $y(t_k)$ 精确满足到第 $k$ 步，考察第 $k+1$ 步的误差：

$$T_{k+1} = y(t_{k+1}) - \left[y(t_k) + hf(t_k, y(t_k))\right] = \frac{h^2}{2}y^{\prime\prime}(\xi_k) \tag{1.2.3}$$

  所以

$$T_{k+1} = O(h^2)$$

  注意阶数的说法：$T = O(h^{p+1})$ 时，称方法为 $p$ 阶方法。Euler 法的局部截断误差是 $O(h^2)$，所以是 1 阶方法。

"局部截断误差阶" 与 "整体误差阶" 差一阶，这是最容易混淆的地方。

原因：局部误差是每步产生的 $O(h^{p+1})$，而总共走 $n = (b-a)/h$ 步，误差累积约

$$E = n\cdot O(h^{p+1}) = \frac{b-a}{h}\cdot O(h^{p+1}) = O(h^p)$$

所以局部 $O(h^2)$ → 整体 $O(h)$。记住这个"降一阶"的规律。

1.2.3 另一种推导：数值积分

  把方程两边在 $[t_k, t_{k+1}]$ 上积分：

$$y(t_{k+1}) - y(t_k) = \int_{t_k}^{t_{k+1}}f(t,y(t))dt \tag{1.2.4}$$

  右边用左矩形公式近似：$\int_{t_k}^{t_{k+1}}f \approx h f(t_k, y(t_k))$，得 Euler 法。

  换用其他积分公式，就得到其他方法——这是下一节"线性多步法"的统一出发点：

积分公式 得到的方法
左矩形 Euler 法（显式）
右矩形 隐式 Euler 法
梯形 梯形格式（二阶）
Simpson 更高阶

1.3 隐式 Euler 法与梯形格式

1.3.1 隐式 Euler 法

  用右端点的斜率：

$$y_{k+1} = y_k + h f(t_{k+1}, y_{k+1}) \tag{1.3.1}$$

  注意 $y_{k+1}$ 出现在两边——这是隐式格式，每步需要解一个方程。

  局部截断误差：展开 $f(t_{k+1},y(t_{k+1}))$ 并利用 $y^{\prime}=f$：

$$T_{k+1} = y(t_{k+1}) - y(t_k) - hf(t_{k+1}, y(t_{k+1})) = -\frac{h^2}{2}y^{\prime\prime}(\xi_k) + O(h^3)$$

  同样是一阶，但符号相反。

  隐式格式的代价与收益：每步需解方程 $y_{k+1} - hf(t_{k+1},y_{k+1}) = y_k$（通常用牛顿迭代）。收益在稳定性——下面会看到。

1.3.2 梯形格式

  用梯形公式近似积分：

$$y_{k+1} = y_k + \frac{h}{2}\left[f(t_k,y_k) + f(t_{k+1},y_{k+1})\right] \tag{1.3.2}$$

  局部截断误差：梯形积分公式的误差是 $-\frac{h^3}{12}y^{\prime\prime\prime}$，所以

$$T_{k+1} = O(h^3)$$

  梯形格式是 2 阶方法——比 Euler 法高一阶，但代价是隐式。

梯形格式还有另一种来历：它是 Euler 法（1 阶显式）和隐式 Euler（1 阶隐式）的平均。

$$y_{k+1} = y_k + \frac{h}{2}\left[f(t_k,y_k)+f(t_{k+1},y_{k+1})\right]$$

两个 1 阶方法的"平均"竟然得到 2 阶——因为两者的误差主项符号相反，平均后相消。这个现象在高阶方法构造里反复出现。

1.4 稳定性：一个关键的对比

  为什么隐式格式值得付出求解方程的代价？用最简单的试验方程来说明：

$$y^{\prime} = \lambda y, \qquad \operatorname{Re}\lambda < 0 \tag{1.4.1}$$

  （$\operatorname{Re}\lambda<0$ 保证精确解 $y = y_0e^{\lambda t}$ 衰减。这是"模型问题"。）

  Euler 法：

$$y_{k+1} = y_k + h\lambda y_k = (1+h\lambda)y_k ;\Longrightarrow; y_k = (1+h\lambda)^k y_0$$

  稳定的条件：$|1+h\lambda| \le 1$。对实数 $\lambda<0$：

$$-1 \le 1+h\lambda \le 1 ;\Longrightarrow; h|\lambda| \le 2$$

  这是对步长的硬性限制：若 $|\lambda|$ 很大（方程"刚性"），$h$ 必须极小。

  隐式 Euler 法：

$$y_{k+1} = y_k + h\lambda y_{k+1} ;\Longrightarrow; y_{k+1} = \frac{1}{1-h\lambda}y_k$$

  稳定的条件：$\left|\frac{1}{1-h\lambda}\right|\le1$，即 $|1-h\lambda|\ge1$。对 $\operatorname{Re}\lambda<0$：

$$|1-h\lambda|^2 = (1-h\operatorname{Re}\lambda)^2 + (h\operatorname{Im}\lambda)^2 \ge 1 \quad\text{恒成立！}$$

  隐式 Euler 对任意步长都稳定。 这叫 A 稳定（绝对稳定）。

  梯形格式：

$$y_{k+1} = y_k + \frac{h\lambda}{2}(y_k + y_{k+1}) ;\Longrightarrow; y_{k+1} = \frac{1+h\lambda/2}{1-h\lambda/2}y_k$$

  稳定性：$\left|\frac{1+h\lambda/2}{1-h\lambda/2}\right| \le 1$。对 $\operatorname{Re}\lambda<0$，分子模长小于分母，比值恒小于 1。也是 A 稳定。

关键对比：

方法 阶 显/隐 A 稳定
Euler 1 显式 ❌ 需 $h
隐式 Euler 1 隐式 ✅ 无条件
梯形 2 隐式 ✅ 无条件

显式方法便宜但受稳定性限制，隐式方法稳定但每步要解方程。 这个权衡贯穿整个数值 ODE 理论。

1.5 代码实现

跑一下这个例子：$y^{\prime} = -50y$ 时，Euler 法的稳定条件要求 $h\le2/50=0.04$。

  • $n=50$ 时 $h=0.02$，满足 → 收敛
  • $n=200$ 时 $h=0.005$ → 也满足

试把 $n$ 改成 $20$（$h=0.05$，违反条件），你会看到 Euler 法剧烈振荡并发散，而隐式 Euler 和梯形格式仍然给出正确答案。这就是稳定性的实际意义。

1.6 小结

方法 格式 局部截断误差 阶 稳定性
显式 Euler $y_{k+1}=y_k+hf(t_k,y_k)$ $O(h^2)$ 1 受 $h\vert\lambda\vert\le2$ 限制
隐式 Euler $y_{k+1}=y_k+hf(t_{k+1},y_{k+1})$ $O(h^2)$ 1 A 稳定
梯形 $y_{k+1}=y_k+\frac{h}{2}[f_k+f_{k+1}]$ $O(h^3)$ 2 A 稳定

易错点

  1. 局部截断误差的阶比方法阶高一阶——$O(h^{p+1})$ ↔ $p$ 阶，别写反；
  2. 隐含格式每步要解方程，不是迭代几次就行——牛顿迭代必须收敛到足够精度，否则"解"本身不准；
  3. 试验方程 $y^{\prime}=\lambda y$ 中的 $\lambda$ 是复数，实部为负才是衰减问题；
  4. A 稳定的方法仍然有精度问题——隐式 Euler 是 A 稳定但只有 1 阶，长期积分会积累误差。

  下一节 1.2 会建立分析这些方法所需的工具：线性差分方程理论与 Gronwall 不等式——它们是后面所有收敛性证明的基础。
