一、基础：只看奇点

  （这一部分只需要 2.2 节的"洛朗级数"。）

一个关键系数

  洛朗级数（2.2）：

$$f(z)=\sum_{n=-\infty}^{\infty}c_n(z-z_0)^n$$

  其中 $c_{-1}$ 特别重要——它叫"留数"（residue）：

$$\operatorname{Res}(f,z_0)=c_{-1}$$

  为什么特别：因为只有它在"沿闭合路径积分"时不为零（见下）。

留数定理

定理：$f$ 在闭曲线 $\gamma$ 内部解析（除有限个奇点 $z_1,\dots,z_n$），则

$$\oint_\gamma f(z),\mathrm{d}z=2\pi\mathrm{i}\sum_{k=1}^{n}\operatorname{Res}(f,z_k)$$

  读法：

闭路积分 = $2\pi\mathrm{i}\times$（围内所有留数之和）

  这就是本节的全部内容——而它极其好用。

为什么只有 $c_{-1}$ 有贡献

  对每一项 $(z-z_0)^n$ 单独积分：

$$\oint_{\lvert z-z_0\rvert=r}(z-z_0)^n,\mathrm{d}z=\begin{cases}2\pi\mathrm{i},&n=-1\\0,&n\ne-1\end{cases}$$

  所以：只有 $n=-1$ 项留下 $2\pi\mathrm{i}$，其余全是 0 ✓

  这就是"为什么叫留数"——它是"唯一留下来的那个系数"。

这个事实为什么这么重要

  它把"积分"变成了"取系数"。

  积分原本是"累加整个函数"——而留数定理说：只有奇点附近的 $-1$ 次项有贡献。

  所以：复积分的值，完全由"局部"决定——不需要知道函数在别处是什么样。

  这就是"解析函数"的刚性——而这个刚性在工程里极有用（见 ④ 层）。

二、标准：留数的计算

  （这一部分达到标准教材深度。）

三种情形的留数公式

情形 留数
可去奇点 $0$
$1$ 阶极点 $\lim_{z\to z_0}(z-z_0)f(z)$
$m$ 阶极点 $\dfrac{1}{(m-1)!}\lim_{z\to z_0}\dfrac{\mathrm{d}^{m-1}}{\mathrm{d}z^{m-1}}\left[(z-z_0)^mf(z)\right]$

  最常用的是 $1$ 阶极点——而它还有一个更方便的形式：

若 $f(z)=\dfrac{g(z)}{h(z)}$，$h(z_0)=0$、$h'(z_0)\ne0$、$g(z_0)\ne0$，则

$$\operatorname{Res}(f,z_0)=\frac{g(z_0)}{h'(z_0)}$$

计算示例

例 1：$f(z)=\dfrac{\mathrm{e}^z}{z}$ 在 $z=0$。

1 阶极点，留数 $=\lim_{z\to0}z\cdot\dfrac{\mathrm{e}^z}{z}=\mathrm{e}^0=1$ ✓

例 2：$f(z)=\dfrac{1}{z\sin z}$ 在 $z=0$。

$\sin z=z-\dfrac{z^3}{6}+\cdots$，所以 $z\sin z=z^2-\dfrac{z^4}{6}+\cdots$——2 阶极点。

用公式：留数 $=\lim_{z\to0}\dfrac{\mathrm{d}}{\mathrm{d}z}\left[z^2f(z)\right]=\lim\dfrac{\mathrm{d}}{\mathrm{d}z}\left[\dfrac{z}{\sin z}\right]$

$=0$ ✓（因为 $\dfrac{z}{\sin z}$ 是偶函数，在 0 处导数为 0）

例 3：$f(z)=\dfrac{1}{z^2+1}$ 在 $z=\mathrm{i}$。

用 $g/h'$：$g=1$，$h=z^2+1$，$h'=2z$，所以在 $z=\mathrm{i}$：

$$\operatorname{Res}=\frac{1}{2\mathrm{i}}=\frac{-\mathrm{i}}{2}$$ ✓

常见错误

错误一：把留数当成"函数值"

  留数是系数，不是函数值。

错误二：$m$ 阶极点用 1 阶公式

  必须用 $\dfrac{1}{(m-1)!}$ 那个公式（或展开级数）。

错误三：$g/h'$ 公式在 $h'(z_0)=0$ 时照用

  要求 $h'(z_0)\ne0$——否则是更高阶极点。

错误四：忘记乘 $2\pi\mathrm{i}$

  积分是 $2\pi\mathrm{i}\sum$，不是 $\sum$。

错误五：把围外的奇点也算进去

  只算围内——或"围外取负"（见下）。

错误六：以为本性奇点没有留数

  有（$c_{-1}$ 可能非零）——只是计算要用级数展开。

三、深入：证明与围道技巧

  （这一部分是完整推导。）

留数定理的证明

用柯西定理和形变

  思路：把每个奇点用小圆围起来。

  第一步：用"多连通区域的柯西定理"，把 $\gamma$ 换成"若干小圆"：

  具体：在 $\gamma$ 内部画小圆 $\gamma_k$ 围住 $z_k$，然后在"$\gamma$ 与小圆之间"的区域，$f$ 解析——所以积分为 0（但方向要处理）。

  结果：

$$\oint_\gamma f=\sum_k\oint_{\gamma_k}f$$

  （这里 $\gamma_k$ 都取逆时针。）

  第二步：在每个小圆上，用洛朗展开：

$$f(z)=\sum_{n=-\infty}^{\infty}c_n^{(k)}(z-z_k)^n$$

  逐项积分（一致收敛允许）：

$$\oint_{\gamma_k}f=\sum_n c_n^{(k)}\oint_{\gamma_k}(z-z_k)^n,\mathrm{d}z=2\pi\mathrm{i}c_{-1}^{(k)}$$

  第三步：加起来：

$$\oint_\gamma f=2\pi\mathrm{i}\sum_k\operatorname{Res}(f,z_k)$$ ✓ $\blacksquare$

  注意：这个证明把 2.1 的"形变原理"与 2.2 的"洛朗展开"结合了——逻辑链条完整了。

围道算法：算实积分

  问题：算 $\displaystyle\int_{-\infty}^{\infty}f(x),\mathrm{d}x$（$f$ 是实函数）。

  方法：围道取"上半平面的大半圆"：

$$\oint_\gamma f(z),\mathrm{d}z=\int_{-R}^{R}f(x),\mathrm{d}x+\int_{\text{大弧}}f(z),\mathrm{d}z$$

  当 $R\to\infty$：

  • 大弧的积分 $\to0$（若 $f$ 在无穷远衰减得够快）
  • 实轴积分 $\to$ 所求

  所以：

$$\int_{-\infty}^{\infty}f(x),\mathrm{d}x=2\pi\mathrm{i}\sum_{\text{上半平面的留数}}$$

例：$\displaystyle\int_{-\infty}^{\infty}\frac{\mathrm{d}x}{x^2+1}$。

  上半平面只有一个奇点 $z=\mathrm{i}$，留数 $=\dfrac{1}{2\mathrm{i}}$。

  所以：

$$=2\pi\mathrm{i}\cdot\frac{1}{2\mathrm{i}}=\pi$$ ✓

  验证：由数学分析，$\int_{-\infty}^{\infty}\frac{\mathrm{d}x}{x^2+1}=\big[\arctan x\big]_{-\infty}^{\infty}=\pi$ ✓

大弧为何趋于 0

  用 ML 不等式（2.1）：

$$\left\lvert\int_{\text{大弧}}f(z),\mathrm{d}z\right\rvert\le\max_{\text{大弧}}\lvert f\rvert\cdot\pi R$$

  所以只要 $\lvert f(z)\rvert=O(R^{-2})$（如 $\dfrac{1}{z^2+1}$），乘积 $\pi R\cdot O(R^{-2})=O(R^{-1})\to0$ ✓

  这就是"围道算法"能成立的关键条件。

"围外取负"的简化

  当围内的奇点很多、而围外的很少时，可以"反过来算"。

  依据：若 $f$ 在无穷远处足够好（如 $\lvert f(z)\rvert=O(\lvert z\rvert^{-2})$），则

$$\sum_{\text{所有奇点}}\operatorname{Res}(f,z_k)=0$$

  （含"无穷远点的留数"，它在上述衰减条件下为 0。）

  所以：围内留数之和 $=-$（围外留数之和）。

  实用价值：若上半平面有 10 个奇点、下半平面只有 2 个，就算下半平面的然后取负。

四、拓展

  （这一部分真正可选。）

历史：留数的"命名"

时间 人物 贡献
1826 柯西 "积分留数"（résidu intégral）
1827 柯西 留数定理
1846 柯西 系统化
1890s 米塔-列夫勒 留数计算实积分的方法

  "留数"（residue）这个名字是柯西起的——法语 résidu = "剩余物"。

  为什么叫"剩余"：因为积分时只有 $c_{-1}$ 这一项"留下来"了——其余都被积成 0。

  所以这个名字非常贴切 ✓

柯西的"积分留数"

  柯西 1826 年在论文中用了 "résidu intégral"——字面意思是"积分的剩余"。

  他当时的概念是："沿闭合路径积分时，除奇点外处处为 0，只有奇点处有'剩余'"。

  所以"留数"最初的名字就是"剩下没被抵消的那部分"。

  这个命名一直用到现在——是数学命名里少见的"直观又准确"的例子。

联系：算数学分析里难的积分

  数学分析 3.4 节的几个例子：

积分 用留数
$\displaystyle\int_0^\infty\frac{\sin x}{x},\mathrm{d}x$ 取 $f=\dfrac{\mathrm{e}^{\mathrm{i}z}}{z}$，分数值算得 $\dfrac{\pi}{2}$
$\displaystyle\int_0^\infty\frac{x^{a-1}}{1+x},\mathrm{d}x$ 用"钥匙孔围道"，得 $\dfrac{\pi}{\sin\pi a}$
$\displaystyle\sum\frac{1}{n^2}$ 用"$\cot$ 的留数"证出 $\dfrac{\pi^2}{6}$

  这些在数学分析里要"绕路"（有的甚至算不出来）——而用留数几乎是机械的。

  所以：复变函数是"实分析的计算器"。

应用：拉普拉斯逆变换

  拉普拉斯变换：

$$F(s)=\int_0^{\infty}f(t)\mathrm{e}^{-st},\mathrm{d}t$$

  逆变换：

$$f(t)=\frac{1}{2\pi\mathrm{i}}\int_{c-\mathrm{i}\infty}^{c+\mathrm{i}\infty}F(s)\mathrm{e}^{st},\mathrm{d}s$$

  这是一个"复平面上的积分"——用留数算：

$$f(t)=\sum_{\text{极点}}\operatorname{Res}\left[F(s)\mathrm{e}^{st}\right]$$

  这就是工程里"查表"的数学依据。

  而"极点"决定了 $f(t)$ 的形状：

极点位置 $f(t)$ 的形状
实极点 $s=-a$ $\mathrm{e}^{-at}$
共轭极点 衰减振荡
右半平面极点 发散（不稳定）

  所以："拉普拉斯逆变换 = 数极点"——而这就是控制论里的"极点配置"。

应用：留数的数值检验

  数值上算 $\oint_\gamma f$ 可以用参数化 + 实数值积分。

  而留数定理给出"真值"——两者对比可检验数值精度。

  更实用的检查：取 $f(z)=\dfrac{1}{z}$，$\gamma$ 为单位圆——数值积分应得 $2\pi\mathrm{i}$。

  如果数值结果接近 $2\pi\mathrm{i}$，说明参数化和积分都正确。

  这就是"用解析解检验数值实现"的典型做法。

小结

概念 要点
留数 洛朗级数的 $c_{-1}$
留数定理 $\oint=2\pi\mathrm{i}\sum\operatorname{Res}$
1 阶极点 $\lim(z-z_0)f(z)$ 或 $g(z_0)/h'(z_0)$
$m$ 阶极点 求 $m-1$ 次导
实积分 上半平面围道，大弧趋 0
拉普拉斯逆变换 数极点

下一节预告

留数定理已经能算大部分实积分了。

  下一节（3.2 保形映射） 会讲复变函数最"漂亮"的部分：

解析函数保持角度——这叫"保形"。

  而保形映射可以把"复杂形状"变成"简单形状"——所以能用来解"复杂区域上的 Laplace 方程"。

  这是复变函数与「数学物理方程」系列的接口。
