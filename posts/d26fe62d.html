第 2 章 分离变量法

  从本章起，我们正式进入数学物理方程的核心：求解。第 1 章讨论了如何把一个物理问题"翻译"成一个偏微分方程的定解问题，但只有少数特殊情形才能直接求解。绝大多数定解问题都需要借助某种方法把偏微分方程降维或转化。

  分离变量法（method of separation of variables，又称 Fourier 方法）是求解线性偏微分方程定解问题最基本、最经典的方法之一。它的核心思想异常简单：把一个多元未知函数假设成若干个一元函数的乘积，从而使偏微分方程被拆解成若干常微分方程。本章以吴小庆教授《数学物理方程》[1]第 2 章为基础，先讲清基本思想和直角坐标系下的完整求解流程。

2.1 分离变量法的基本思想

2.1.1 一个直观的例子

  考虑一维弦振动方程

$$u_{tt} = a^2 u_{xx}, \quad 0 < x < l, \quad t > 0 \tag{2.1.1}$$

  假设解可以写成

$$u(x, t) = X(x)T(t) \tag{2.1.2}$$

  即空间部分与时间部分可以分离。把它代入方程 (2.1.1)：

$$X(x)T''(t) = a^2 X''(x)T(t)$$

  两边同时除以 $a^2 X(x)T(t)$（假设不为零）：

$$\frac{T''(t)}{a^2 T(t)} = \frac{X''(x)}{X(x)} \tag{2.1.3}$$

  到这里，关键的一步来了：等式左边只含 $t$，右边只含 $x$。既然 $x$ 和 $t$ 是两个独立的自变量，这个等式要在整个定义域内恒成立，唯一的可能就是两边都等于同一个常数。设这个常数为 $-\lambda$：

$$\frac{T''(t)}{a^2 T(t)} = \frac{X''(x)}{X(x)} = -\lambda \tag{2.1.4}$$

  于是得到一个偏微分方程被拆成了两个常微分方程：

$$T''(t) + a^2 \lambda T(t) = 0 \tag{2.1.5}$$
$$X''(x) + \lambda X(x) = 0 \tag{2.1.6}$$

  这就是分离变量法的全部"魔法"。剩下的问题有两个：

  1. $\lambda$ 取什么值？ 不是任意值都能满足边界条件；
  2. 怎么把无穷多个解组装成满足初始条件的那个解？

  第一个问题引出本征值问题，第二个问题引出叠加原理与广义傅里叶级数。

2.1.2 为什么必须要求边界条件是齐次的

  分离变量法有一个硬性前提：边界条件必须是齐次的（即等号右边为零）。

  以弦的两端固定为例：

$$u(0, t) = 0, \quad u(l, t) = 0 \tag{2.1.7}$$

  代入 $u = X(x)T(t)$：

$$X(0)T(t) = 0, \quad X(l)T(t) = 0$$

  要求对任意 $t$ 都成立，只能有：

$$X(0) = 0, \quad X(l) = 0 \tag{2.1.8}$$

  这样边界条件就被"吸收"进了 $X(x)$ 的常微分方程里，可以单独求解。

  但如果边界条件是非齐次的，例如左端固定、右端按某种规律运动：

$$u(0, t) = 0, \quad u(l, t) = \mu(t) \neq 0 \tag{2.1.9}$$

  代入后得到 $X(l)T(t) = \mu(t)$，而 $\mu(t)$ 不是 $X$ 与 $T$ 的乘积形式，无法分离。此时需要先做变量代换把非齐次边界条件齐次化，这部分内容留到后续小节展开。

一句话总结：分离变量法要求方程与边界条件都是齐次线性的。方程非齐次可以用本征函数展开处理；边界条件非齐次则必须先做代换。

2.1.3 三种情形与本征值问题

  回到方程 (2.1.6) 配合边界条件 (2.1.8)：

$$\begin{cases} X''(x) + \lambda X(x) = 0, & 0 < x < l \ X(0) = 0, \quad X(l) = 0 \end{cases} \tag{2.1.10}$$

  这是一个带边界条件的常微分方程，称为施图姆-刘维尔（Sturm-Liouville）型本征值问题。$\lambda$ 称为本征值，对应的非零解 $X(x)$ 称为本征函数。

  分三种情况讨论（这是本章必须掌握的推理框架）：

情形一：$\lambda < 0$，记 $\lambda = -\mu^2 \quad(\mu > 0)$。

$$X'' - \mu^2 X = 0 \Rightarrow X(x) = C_1 e^{\mu x} + C_2 e^{-\mu x}$$

代入边界条件：$X(0) = C_1 + C_2 = 0$，$X(l) = C_1 e^{\mu l} + C_2 e^{-\mu l} = 0$。

解得 $C_1 = C_2 = 0$，只有零解，舍去。

情形二：$\lambda = 0$。

$$X'' = 0 \Rightarrow X(x) = C_1 x + C_2$$

$X(0) = C_2 = 0$，$X(l) = C_1 l = 0 \Rightarrow C_1 = 0$。仍只有零解，舍去。

情形三：$\lambda > 0$，记 $\lambda = \mu^2 \quad(\mu > 0)$。

$$X'' + \mu^2 X = 0 \Rightarrow X(x) = C_1 \cos\mu x + C_2 \sin\mu x$$

由 $X(0) = 0$ 得 $C_1 = 0$，于是 $X(x) = C_2 \sin \mu x$。

由 $X(l) = 0$ 得 $C_2 \sin \mu l = 0$。要找非零解必须 $C_2 \neq 0$，故

$$\sin \mu l = 0 \Rightarrow \mu l = n\pi, \quad n = 1, 2, 3, \cdots$$

于是

$$\lambda_n = \left(\frac{n\pi}{l}\right)^2, \quad X_n(x) = \sin\frac{n\pi x}{l}, \quad n = 1, 2, 3, \cdots \tag{2.1.11}$$

  注意 $n = 0$ 时 $X_0 \equiv 0$，不是本征函数，所以 $n$ 从 1 开始。

2.1.4 本征值问题的几个重要性质

  上面这个具体例子体现了施图姆-刘维尔问题的几条一般性质，后面会反复使用：

性质 内容 本例中的体现
本征值存在性 存在可数个本征值，且趋于无穷 $\lambda_n = (n\pi/l)^2 \to \infty$
非负性 对 $q(x) \ge 0$ 的问题，$\lambda_n \ge 0$ $\lambda_n > 0$
正交性 不同本征值对应的本征函数正交 $\int_0^l \sin\frac{m\pi x}{l}\sin\frac{n\pi x}{l}dx = 0 \quad(m \neq n)$
完备性 本征函数系构成 $L^2[0,l]$ 的完备基 任意"足够好"的函数可展开为傅里叶正弦级数

  正交性的证明非常直接，留作练习：

$$\int_0^l \sin\frac{m\pi x}{l}\sin\frac{n\pi x}{l}dx = \frac{l}{2}\delta_{mn} \tag{2.1.12}$$

其中 $\delta_{mn}$ 是克罗内克符号。这个式子被称为正交归一化条件，它的平方形式记作 $N_n$（模的平方），在本例中 $N_n = l/2$。

2.2 直角坐标系下弦的自由振动

2.2.1 定解问题的完整提法

  现在回到完整的弦振动问题：一根长为 $l$ 的均匀弦，两端固定，初始位移为 $\varphi(x)$，初始速度为 $\psi(x)$，求弦的振动规律。

$$\begin{cases} u_{tt} = a^2 u_{xx}, & 0 < x < l, \quad t > 0 \ X(0,t) = 0, \quad u(l,t) = 0, & t \ge 0 \ u(x,0) = \varphi(x), \quad u_t(x,0) = \psi(x), & 0 \le x \le l \end{cases} \tag{2.2.1}$$

这是数学物理方程中最经典的一个模型。它包含了三类定解条件：方程本身（偏微分方程）、边界条件（两端固定）、初始条件（初始位移与速度）。

2.2.2 分离变量与时间方程的求解

  设 $u(x,t) = X(x)T(t)$，代入方程和齐次边界条件，得到本征值问题 (2.1.10)，其解为 (2.1.11)。

  再解时间方程 (2.1.5)。代入 $\lambda_n = (n\pi/l)^2$，令 $\omega_n = \frac{n\pi a}{l}$（称为第 $n$ 阶固有频率）：

$$T_n''(t) + \omega_n^2 T_n(t) = 0 \tag{2.2.2}$$

其通解为

$$T_n(t) = A_n \cos\omega_n t + B_n \sin\omega_n t \tag{2.2.3}$$

  于是对每个 $n$ 得到一个特解：

$$u_n(x,t) = \left(A_n \cos\frac{n\pi a}{l}t + B_n \sin\frac{n\pi a}{l}t\right)\sin\frac{n\pi x}{l} \tag{2.2.4}$$

  这被称为弦振动的第 $n$ 阶驻波（normal mode）。物理上，它表示弦以一种固定的"节拍"振动，$x = k l/n$（$k = 1,\cdots,n-1$）处始终保持不动，称为波节；相邻波节中点为波腹。

2.2.3 叠加原理与初始条件的满足

  第 1 章已经证明过叠加原理：线性齐次方程的解的任意有限线性组合仍是解。因此

$$u(x,t) = \sum_{n=1}^{\infty} \left(A_n \cos\frac{n\pi a}{l}t + B_n \sin\frac{n\pi a}{l}t\right)\sin\frac{n\pi x}{l} \tag{2.2.5}$$

  （在级数一致收敛且可逐项求导的条件下）也是解。

  剩下的任务是确定系数 $A_n, B_n$，使解满足初始条件：

  由 $u(x,0) = \varphi(x)$：

$$\sum_{n=1}^{\infty} A_n \sin\frac{n\pi x}{l} = \varphi(x) \tag{2.2.6}$$

  由 $u_t(x,0) = \psi(x)$，先对 (2.2.5) 关于 $t$ 求导再令 $t = 0$：

$$\sum_{n=1}^{\infty} \frac{n\pi a}{l} B_n \sin\frac{n\pi x}{l} = \psi(x) \tag{2.2.7}$$

  这两个式子正是 $\varphi(x)$ 与 $\psi(x)$ 在 $[0,l]$ 上的傅里叶正弦级数展开。利用正交性 (2.1.12)，两边同乘 $\sin\frac{m\pi x}{l}$ 并在 $[0,l]$ 上积分：

$$A_n = \frac{2}{l}\int_0^l \varphi(x)\sin\frac{n\pi x}{l}dx \tag{2.2.8}$$
$$B_n = \frac{2}{n\pi a}\int_0^l \psi(x)\sin\frac{n\pi x}{l}dx \tag{2.2.9}$$

  至此，定解问题 (2.2.1) 的形式解就得到了：把 (2.2.8)(2.2.9) 算出的系数代回 (2.2.5)。

2.2.4 一个完整例题

  例 2.2.1 求解

$$\begin{cases} u_{tt} = a^2 u_{xx}, & 0 < x < l, \quad t > 0 \ u(0,t) = u(l,t) = 0 \ u(x,0) = x(l - x), \quad u_t(x,0) = 0 \end{cases}$$

解： 初始速度为 0，由 (2.2.9) 知 $B_n = 0$，只需求 $A_n$：

$$A_n = \frac{2}{l}\int_0^l x(l - x)\sin\frac{n\pi x}{l}dx$$

  计算这个积分需要分部积分两次。先算不定式：记 $I = \int x(l-x)\sin(kx)dx$，$k = n\pi/l$。

  第一次分部积分（取 $u = x(l-x)$，$dv = \sin kx\thinspacedx$）：

$$I = -x(l-x)\frac{\cos kx}{k} + \int (l - 2x)\frac{\cos kx}{k}dx$$

  第二次分部积分：

$$\int (l-2x)\frac{\cos kx}{k}dx = (l-2x)\frac{\sin kx}{k^2} + \frac{2}{k^2}\int \sin kx \thinspacedx = (l-2x)\frac{\sin kx}{k^2} - \frac{2\cos kx}{k^3}$$

  代回并代入上下限 $x = 0$ 与 $x = l$。由于 $\sin(n\pi) = 0$，含 $\sin$ 的项全部消失；在 $x = l$ 与 $x = 0$ 处 $\cos(kx)$ 分别为 $\cos n\pi = (-1)^n$ 与 $1$：

$$A_n = \frac{2}{l}\left[-\frac{2(-1)^n}{k^3} + \frac{2}{k^3}\right] = \frac{4}{l k^3}\left[1 - (-1)^n\right]$$

  可见 $n$ 为偶数时 $A_n = 0$；$n$ 为奇数时（记 $n = 2m-1$），$1 - (-1)^n = 2$：

$$A_n = \frac{8}{l k^3} = \frac{8l^2}{n^3\pi^3}, \quad n = 1, 3, 5, \cdots$$

  于是

$$u(x,t) = \frac{8l^2}{\pi^3}\sum_{m=1}^{\infty} \frac{1}{(2m-1)^3}\cos\frac{(2m-1)\pi a}{l}t \cdot \sin\frac{(2m-1)\pi x}{l}$$

  验证：令 $t = 0$，得到 $\frac{8l^2}{\pi^3}\sum_{m=1}^\infty \frac{\sin(2m-1)\pi x/l}{(2m-1)^3}$。这正是 $x(l-x)$ 在 $[0,l]$ 上的傅里叶正弦展开，与初始条件一致。

观察：系数的衰减速度决定级数的收敛快慢。本例中 $A_n \sim 1/n^3$，收敛非常快；而如果初始位移有"折角"（一阶导不连续），衰减通常只有 $1/n^2$。这也解释了为什么真实弦的振动里高频分量的能量总是很小。

2.2.5 形式的比较：驻波与行波

  第 1 章提到，弦振动方程的通解可以用达朗贝尔公式写成行波形式：

$$u(x,t) = f(x - at) + g(x + at)$$

  而分离变量法给出的是驻波叠加：

$$u(x,t) = \sum_n \left[A_n\cos\omega_n t + B_n\sin\omega_n t\right]\sin\frac{n\pi x}{l}$$

  两种形式描述的是同一个解，只是分解方式不同。可以把 (2.2.5) 中的每一项用和差化积改写：

$$\cos\omega_n t \sin\frac{n\pi x}{l} = \frac{1}{2}\left[\sin\frac{n\pi(x + at)}{l} + \sin\frac{n\pi(x - at)}{l}\right]$$

  于是每个驻波都分解成了一对相向传播的行波。物理上，所谓"驻波"，就是两列振幅相同、传播方向相反的行波叠加的结果，它们的波节固定不动。这个视角在讨论反射与共振时非常有用。

形式 表达式 适用场景
行波 $f(x-at) + g(x+at)$ 无界弦、半无界弦、反射问题
驻波 $\sum A_n \cos\omega_n t \sin \frac{n\pi x}{l}$ 有界弦、两端固定/自由

2.3 小结与易错点

  本节把分离变量法的完整流程走了一遍。把它抽象出来后，标准步骤是：

  1. 判断前提：方程与边界条件是否齐次？不齐次要先处理；
  2. 分离变量：令 $u = X(x)T(t)$，把偏微分方程拆成两个常微分方程，引入分离常数 $\lambda$；
  3. 求解本征值问题：由边界条件确定 $\lambda$ 的可取值与本征函数；
  4. 求解时间方程：得到每个本征值对应的含两个待定常数的解；
  5. 叠加：把无穷多个特解线性组合；
  6. 代入初始条件：利用本征函数的正交性，用积分公式求出所有系数。

易错点提醒

  1. 不要漏掉 $\lambda \le 0$ 的讨论——虽然结果通常只有正的本征值，但不讨论会被认为不完整；
  2. 本征函数的下标从 $n = 1$ 开始，$n = 0$ 在本例中是平凡解；
  3. 求 $B_n$ 时容易忘掉分母的 $n\pi a$，这是最常见的笔误；
  4. 级数形式解只是形式解，要说明解确实成立还需要的收敛性与逐项求导的正当性——这部分涉及能量方法，后续再展开。

  下一节将处理两个方向：一是非齐次边界条件的齐次化（自由端、弹性支撑端等），二是非齐次方程本征函数展开法。

  分离变量法的完整理论见[1]吴小庆.数学物理方程及其应用参考资料。
