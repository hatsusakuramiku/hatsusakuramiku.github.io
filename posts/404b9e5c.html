4.3 球面调和函数

  2.5 节我们把球坐标下的拉普拉斯方程分离成了径向方程与角向方程。角向部分的解是

$$Y_\ell^m(\theta,\varphi) = P_\ell^m(\cos\theta)e^{im\varphi}$$

  这一节把角向部分当成球面上的一个独立问题系统处理。

4.3.1 球面拉普拉斯算子与球谐函数

  球坐标下的拉普拉斯算子 (2.5.1) 可以写成

$$\Delta = \frac{1}{r^2}\frac{\partial}{\partial r}\left(r^2\frac{\partial}{\partial r}\right) + \frac{1}{r^2}\Delta_S$$

  其中

$$\Delta_S = \frac{1}{\sin\theta}\frac{\partial}{\partial\theta}\left(\sin\theta\frac{\partial}{\partial\theta}\right) + \frac{1}{\sin^2\theta}\frac{\partial^2}{\partial\varphi^2} \tag{4.3.1}$$

  是球面拉普拉斯算子（Laplace-Beltrami 算子）。它只作用在角度变量上，且是一个球面上的自伴算子。

  于是拉普拉斯方程 $\Delta u = 0$ 等价于：当 $u = R(r)Y(\theta,\varphi)$ 时，

$$\frac{(r^2R^{\prime})^{\prime}}{R} = -\frac{\Delta_S Y}{Y} = \text{常数}$$

  这个常数按惯例记作 $\ell(\ell+1)$。于是

$$\Delta_S Y + \ell(\ell+1)Y = 0 \tag{4.3.2}$$

  这就是球面本征值问题。它的解正是

$$Y_\ell^m(\theta,\varphi) = P_\ell^m(\cos\theta)e^{im\varphi}, \quad m = -\ell,\cdots,\ell \tag{4.3.3}$$

  本征值的重数：对每个 $\ell$，$m$ 可以取 $2\ell+1$ 个值，所以本征值 $\ell(\ell+1)$ 是**$(2\ell+1)$ 重简并**的。

  这与角动量理论中的结论一致——量子力学里 $\ell$ 是角量子数，$m$ 是磁量子数，简并度 $2\ell+1$ 被塞曼效应劈裂。

4.3.2 正交归一化

  球面上自然的内积是

$$\langle f,g\rangle = \int_0^{2\pi}\int_0^{\pi} f(\theta,\varphi)\overline{g(\theta,\varphi)}\sin\theta,d\theta,d\varphi \tag{4.3.4}$$

  注意权重是 $\sin\theta$——球面面积元是 $r^2\sin\theta,d\theta,d\varphi$，去掉 $r^2$ 后剩下 $\sin\theta$。

  由 2.5 节的勒让德正交性 (2.5.15) 与 $e^{im\varphi}$ 的正交性（$\int_0^{2\pi}e^{i(m-m^{\prime})\varphi}d\varphi = 2\pi\delta_{mm^{\prime}}$）：

$$\langle Y_\ell^m, Y_{\ell^{\prime}}^{m^{\prime}}\rangle = 2\pi\cdot\frac{2}{2\ell+1}\cdot\frac{(\ell+m)!}{(\ell-m)!}\delta_{\ell\ell^{\prime}}\delta_{mm^{\prime}} \tag{4.3.5}$$

  通常定义归一化的球谐函数：

$$Y_\ell^m(\theta,\varphi) = \sqrt{\frac{(2\ell+1)(\ell-m)!}{4\pi(\ell+m)!}}P_\ell^m(\cos\theta)e^{im\varphi} \tag{4.3.6}$$

  这样

$$\langle Y_\ell^m, Y_{\ell^{\prime}}^{m^{\prime}}\rangle = \delta_{\ell\ell^{\prime}}\delta_{mm^{\prime}} \tag{4.3.7}$$

  注意：$m<0$ 时要用

$$P_\ell^{-m}(x) = (-1)^m\frac{(\ell-m)!}{(\ell+m)!}P_\ell^m(x) \tag{4.3.8}$$

  $m$ 为负时球谐函数与 $m$ 为正的不同（差一个相位因子），这在量子力学里对应 $Y_\ell^{-m} = (-1)^m\overline{Y_\ell^m}$。

4.3.3 球面调和展开与加法定理

  由于 ${Y_\ell^m}$ 是球面上的完备正交系，任意球面上的光滑函数都可以展开：

$$f(\theta,\varphi) = \sum_{\ell=0}^\infty\sum_{m=-\ell}^{\ell}a_{\ell m}Y_\ell^m(\theta,\varphi), \quad a_{\ell m} = \langle f, Y_\ell^m\rangle \tag{4.3.9}$$

  球谐加法定理（全节最重要的恒等式）：

$$\sum_{m=-\ell}^{\ell}Y_\ell^m(\theta,\varphi)\overline{Y_\ell^m(\theta^{\prime},\varphi^{\prime})} = \frac{2\ell+1}{4\pi}P_\ell(\cos\Theta) \tag{4.3.10}$$

  其中 $\Theta$ 是球面上两点 $(\theta,\varphi)$ 与 $(\theta^{\prime},\varphi^{\prime})$ 之间的球面角距：

$$\cos\Theta = \cos\theta\cos\theta^{\prime} + \sin\theta\sin\theta^{\prime}\cos(\varphi-\varphi^{\prime}) \tag{4.3.11}$$

加法定理的意义：它把"两个方向的 $2\ell+1$ 个分量相乘求和"退化成了"依赖夹角 $\Theta$ 的一个函数"。

物理上，这意味着：两个方向的相互作用只依赖于它们的相对夹角（球对称性）。这就是为什么 $\frac{1}{\lvert\mathbf{r}-\mathbf{r}^{\prime}\rvert}$ 的展开只依赖 $r,r^{\prime},\Theta$ 三个量。

  加法定理的一个直接应用：把 $\cos\Theta$ 当作两点间夹角的余弦，若设第二点为 $\theta^{\prime}=0$（即 $z$ 轴方向），则 $\Theta=\theta$，加法定理 (4.3.10) 直接化简为

$$\sum_{m}Y_\ell^m(\theta,\varphi)\overline{Y_\ell^m(0,0)} = \frac{2\ell+1}{4\pi}P_\ell(\cos\theta)$$

  而 $Y_\ell^m(0,0)\ne0$ 只有当 $m=0$ 时成立（因为 $P_\ell^m(1)=0$ 对 $m>0$），所以等式两边只剩 $m=0$ 项——这给出 $P_\ell(1)=1$ ✓，是一个自洽性检验。

4.3.4 拉普拉斯方程的一般球面解与多极展开

  现在可以把 2.5 节的结论推广到完全含 $\varphi$ 依赖的情形。球内：

$$u(r,\theta,\varphi) = \sum_{\ell=0}^\infty\sum_{m=-\ell}^{\ell}a_{\ell m}\left(\frac{r}{r_0}\right)^\ell Y_\ell^m(\theta,\varphi), \quad r<r_0 \tag{4.3.12}$$

  球外去掉 $r^\ell$ 保留 $r^{-(\ell+1)}$：

$$u(r,\theta,\varphi) = \sum_{\ell,m}b_{\ell m}\left(\frac{r_0}{r}\right)^{\ell+1}Y_\ell^m(\theta,\varphi), \quad r>r_0 \tag{4.3.13}$$

  多极展开：把 $1/\lvert\mathbf{r}-\mathbf{r}^{\prime}\rvert$（三维格林函数的三维空间部分）按本征函数展开。设 $r>r^{\prime}$，用加法定理：

$$\frac{1}{\lvert\mathbf{r}-\mathbf{r}^{\prime}\rvert} = \frac{1}{\sqrt{r^2-2rr^{\prime}\cos\Theta+r^{\prime 2}}$$

  母函数 (4.4.2) 就是它的展开：

$$\frac{1}{\sqrt{1-2xt+t^2}} = \sum_{\ell=0}^\infty P_\ell(x)t^\ell, \quad \lvert t\rvert<1$$

  代入 $x=\cos\Theta$，$t=r^{\prime}/r$：

$$\frac{1}{\lvert\mathbf{r}-\mathbf{r}^{\prime}\rvert} = \frac{1}{r}\sum_{\ell=0}^\infty\left(\frac{r^{\prime}}{r}\right)^\ell P_\ell(\cos\Theta) \tag{4.3.14}$$

  再用加法定理把 $P_\ell$ 换成 $Y_\ell^m$ 的求和：

$$\frac{1}{\lvert\mathbf{r}-\mathbf{r}^{\prime}\rvert} = 4\pi\sum_{\ell=0}^\infty\frac{1}{2\ell+1}\frac{r_{<}^\ell}{r_{>}^{\ell+1}}\sum_{m=-\ell}^{\ell}Y_\ell^m(\hat{\mathbf{r}})\overline{Y_\ell^m(\hat{\mathbf{r}}^{\prime})} \tag{4.3.15}$$

  其中 $r_{<}=\min(r,r^{\prime})$、$r_{>}=\max(r,r^{\prime})$，$\hat{\mathbf{r}}$ 是单位方向向量。

  逐项命名：

$\ell$ 名称 依赖
$0$ 单极（monopole） 与方向无关
$1$ 偶极（dipole） 线性于 $\cos\Theta$
$2$ 四极（quadrupole） 二次
$\ell$ $2^\ell$ 极 $\ell$ 次

  静电场中的物理意义：若把一串电荷集中在原点附近，其在远处的电势多极展开就是上式的逐项。单极项是总电荷；偶极项是偶极矩；项数越高衰减越快——所以远场主要看低阶极矩。

为什么多极展开收敛快：第 $\ell$ 项含因子 $(r^{\prime}/r)^{\ell}$。当观测点远大于源尺寸时这个因子迅速衰减。例如 $r^{\prime}/r = 0.1$ 时，$\ell=4$ 项已衰减到 $10^{-4}$。所以远场计算只需保留前几项。

4.3.5 一个完整算例

  例 4.3.1 求球内拉普拉斯方程，边界 $u(a,\theta,\varphi) = \sin\theta\cos\varphi$ 的解。

  解： 注意 $\sin\theta\cos\varphi$ 在直角坐标下就是 $x/r$，即单位球面上的 $x$ 分量。这提示解应该是 $x$ 的一次函数。

  直接验证：$u = Ax$，则 $\Delta u = A\Delta x = 0$ ✓。边界条件 $x=a\sin\theta\cos\varphi$，故

$$u = \frac{x}{a}\cdot a = a\cdot\frac{r\sin\theta\cos\varphi}{a}\cdot\frac{1}{1} = r\sin\theta\cos\varphi$$

  注意取哪个函数：若取 $u = ax$，边界值为 $a\cdot a\sin\theta\cos\varphi = a^2\sin\theta\cos\varphi$，与径向因子的幂次不匹配。应当改取 $u = x$：

$$u = x = r\sin\theta\cos\varphi$$

  在 $r=a$ 处，$u = a\sin\theta\cos\varphi$ ✓

  用本征展开验证：$\sin\theta\cos\varphi$ 对应的球谐是 $Y_1^1$（差一个常数）。由 (4.3.6)：

$$Y_1^1 = \sqrt{\frac{3\cdot0!}{4\pi\cdot2!}}P_1^1(\cos\theta)e^{i\varphi} = \sqrt{\frac{3}{8\pi}}\cdot\left(-\sin\theta\right)e^{i\varphi}$$

  （用了 $P_1^1(x) = -\sqrt{1-x^2} = -\sin\theta$。）

  于是 $\sin\theta\cos\varphi = \operatorname{Re}\left[\sqrt{\frac{8\pi}{3}}Y_1^1\right]$ 的适当组合。展开后系数自动匹配，结果仍是 $r\sin\theta\cos\varphi$。

  结论：多项式形式的边界条件，对应的解也是同次的多项式（调和多项式）。这类问题不需要真的展开级数，直接构造即可——这是做题时的第一条捷径。

4.4 小结

概念 内容
球面本征值问题 $\Delta_S Y + \ell(\ell+1)Y = 0$
本征函数 $Y_\ell^m = P_\ell^m(\cos\theta)e^{im\varphi}$，$(2\ell+1)$ 重简并
内积权重 $\sin\theta$
加法定理 $\sum_m Y_\ell^m(\Omega)\overline{Y_\ell^m(\Omega^{\prime})} = \frac{2\ell+1}{4\pi}P_\ell(\cos\Theta)$
多极展开 $\frac{1}{\lvert\mathbf{r}-\mathbf{r}^{\prime}\rvert} = 4\pi\sum_\ell\frac{1}{2\ell+1}\frac{r_{<}^\ell}{r_{>}^{\ell+1}}\sum_m Y_\ell^m\overline{Y_\ell^m}$

易错点

  1. 权重是 $\sin\theta$，不是 $1$——球面面积元的雅可比因子；
  2. 简并度是 $2\ell+1$，不是 $\ell+1$——$m$ 从 $-\ell$ 取到 $\ell$；
  3. $m<0$ 时勒让德函数的定义带 $(-1)^m$ 因子 (4.3.8)，容易漏；
  4. 多极展开的 $r_<^{\ell}/r_>^{\ell+1}$——分子分母要分清谁是小的；
  5. 归一化常数 $\sqrt{\frac{(2\ell+1)(\ell-m)!}{4\pi(\ell+m)!}}$——阶乘顺序别写反。

  第 4 章到此结束。第 5 章进入算子级数法，用抽象的算子形式统一前述所有方法——那将是本系列的最后一章。

  球面调和函数的完整理论参见[1]吴小庆.数学物理方程及其应用参考资料。
