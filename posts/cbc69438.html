前置知识：1.1 节、常系数线性常微分方程的解法、数列与极限。

为什么需要这一节

  1.1 节写了三个格式的公式，也做了稳定性分析——但那是针对单个试验方程的"快速判断"。要在一般情形下证明收敛性，需要两个工具：

  1. 线性差分方程——因为数值格式本身就是个差分方程，它的解的行为由特征根决定；
  2. Gronwall 不等式——用来把"每步的小误差"累积成"整体的误差上界"。

  这两个工具是后面所有多步法、Runge-Kutta 法收敛性证明的基础。

1.2 线性差分方程

1.2.1 定义与分类

  差分方程是关于数列 ${y_k}$ 的方程，含 $y_k$ 及其若干偏移：

$$F(k;\ y_k,\ y_{k+1},\ \dots,\ y_{k+m}) = 0$$

  阶数 $m$ = 出现的最大下标差。

  线性（对 $y$ 线性）：

$$a_0(k)y_{k+m} + a_1(k)y_{k+m-1} + \cdots + a_m(k)y_k = g_k \tag{1.2.1}$$

  常系数：$a_i$ 与 $k$ 无关。

  齐次：$g_k \equiv 0$。

  本文只讨论常系数线性差分方程，这已足够覆盖数值格式的稳定性分析。

1.2.2 一阶常系数方程

  最简单的情形：

$$y_{k+1} = \lambda y_k \tag{1.2.2}$$

  递推直接给出 $y_k = \lambda^k y_0$。行为完全由 $\lambda$ 决定：

$\lambda$ 行为
$ \lambda
$\lambda = 1$ 常数
$\lambda = -1$ 交替振荡，幅值不变
$ \lambda

  这正是 1.1 节的稳定性条件：Euler 法的 $|1+h\lambda|\le1$ 就是要求这个"放大因子"落在这个范围内。

1.2.3 二阶常系数齐次方程

$$y_{k+2} + a y_{k+1} + b y_k = 0 \tag{1.2.3}$$

  试探解：设 $y_k = r^k$，代入：

$$r^{k+2} + ar^{k+1}+br^k = 0 ;\Longrightarrow; r^2 + ar + b = 0 \tag{1.2.4}$$

  这是特征方程。分三种情形：

情形一：两个相异实根 $r_1 \ne r_2$

$$y_k = C_1r_1^k + C_2r_2^k \tag{1.2.5}$$

情形二：重根 $r_1 = r_2 = r$

$$y_k = (C_1 + C_2k)r^k \tag{1.2.6}$$

  注意多了个因子 $k$——这与 ODE 重根时多出 $te^{rt}$ 完全平行。

情形三：共轭复根 $r = \rho e^{\pm i\theta}$

$$y_k = \rho^k(C_1\cos k\theta + C_2\sin k\theta) \tag{1.2.7}$$

判定稳定性的核心结论：

齐次方程的解有界（不趋向无穷）当且仅当

  • 所有根的模 $\le 1$，且
  • 模恰为 1 的根都是单根。

如果某个根的模 $>1$，或者模为 1 却是重根，解都会无界。

重根为什么特殊？因为 (1.2.6) 里有因子 $k$，即使 $|r|=1$，$k\cdot r^k$ 也线性增长。这是多步法稳定性分析里最容易被忽略的一点。

  验证：$y_{k+2} = 2y_{k+1} - y_k$，特征方程 $r^2-2r+1=0$，重根 $r=1$。通解 $y_k = C_1 + C_2k$——线性增长，不是常数。若这是某个格式的误差方程，就意味着误差会线性累积。

1.2.4 非齐次方程：常数变易法

  考虑

$$y_{k+1} = \lambda y_k + g_k, \qquad y_0\ \text{已知} \tag{1.2.8}$$

  逐项展开并归纳：

$$y_k = \lambda^k y_0 + \sum_{j=0}^{k-1}\lambda^{k-1-j}g_j \tag{1.2.9}$$

  这是离散版的常数变易公式，与 ODE 的

$$y(t) = e^{\lambda t}y_0 + \int_0^te^{\lambda(t-s)}f(s)ds$$

完全平行：$\lambda^k \leftrightarrow e^{\lambda t}$，求和 $\leftrightarrow$ 积分。

  误差累积的直接体现：若每步引入误差 $\varepsilon$（$g_j = \varepsilon$），则

$$|y_k| \le |\lambda|^k|y_0| + \varepsilon\sum_{j=0}^{k-1}|\lambda|^{k-1-j}$$

  若 $|\lambda|<1$，几何级数求和给出

$$\sum_{j=0}^{k-1}|\lambda|^{k-1-j} = \frac{1-|\lambda|^k}{1-|\lambda|} \le \frac{1}{1-|\lambda|}$$

  误差被放大的倍数有界，为 $\dfrac{1}{1-|\lambda|}$。 这就是为什么稳定性这么重要——不稳定（$|\lambda|>1$）时这个界不存在，误差按指数增长。

1.3 Gronwall 不等式

1.3.1 离散形式

  引理：设非负数列 ${\eta_k}$、${u_k}$ 和非负常数 $C$ 满足

$$u_k \le C + \sum_{j=0}^{k-1}\eta_j u_j, \qquad k = 0,1,2,\dots \tag{1.3.1}$$

  则

$$u_k \le C\exp\left(\sum_{j=0}^{k-1}\eta_j\right) \tag{1.3.2}$$

  证明（这是一个漂亮而标准的技巧）：

  记 $S_k = C + \sum_{j=0}^{k-1}\eta_ju_j$，则 $u_k \le S_k$，且

$$S_{k+1} - S_k = \eta_k u_k \le \eta_k S_k$$

  于是

$$S_{k+1} \le (1+\eta_k)S_k$$

  递推：$S_k \le S_0\prod_{j=0}^{k-1}(1+\eta_j) = C\prod(1+\eta_j)$。

  最后用初等不等式 $1+x \le e^x$：

$$u_k \le C\prod_{j=0}^{k-1}(1+\eta_j) \le C\prod e^{\eta_j} = C\exp\left(\sum_{j=0}^{k-1}\eta_j\right) \qquad \blacksquare$$

这个引理的用途：数值格式的误差 $e_k$ 通常满足

$$|e_k| \le |e_0| + hL\sum_{j=0}^{k-1}|e_j| + \text{(局部误差项)}$$

这正是 (1.3.1) 的形式（取 $\eta_j = hL$，$C$ = 初始误差 + 局部误差累计）。Gronwall 直接给出

$$|e_k| \le C e^{hLk} = Ce^{L(t_k-a)}$$

——误差界是指数型的，增长率就是 Lipschitz 常数 $L$。

1.3.2 连续形式

  对应的连续版本（也叫 Gronwall 引理）：

  引理：若 $u(t)\ge0$ 连续，且

$$u(t) \le C + \int_a^t\beta(s)u(s),ds, \qquad \beta \ge 0 \tag{1.3.3}$$

  则

$$u(t) \le C\exp\left(\int_a^t\beta(s)ds\right) \tag{1.3.4}$$

  证明：设 $V(t) = C + \int_a^t\beta u$，则 $V' = \beta u \le \beta V$，即

$$\left(\ln V\right)^{\prime} \le \beta ;\Longrightarrow; \ln\frac{V(t)}{V(a)} \le \int_a^t\beta ;\Longrightarrow; V(t)\le C e^{\int\beta}$$

  而 $u\le V$，结论成立。$\blacksquare$

Gronwall 不等式只能给出上界，不能给出精确阶。

它说的是"误差不超过某个指数函数"，但实际的误差可能远小于这个界。要得到精确的误差阶，需要更精细的分析（比如直接展开、或者用离散 Green 函数）。

不过对于证明收敛性（误差 → 0）和稳定性（误差有界），Gronwall 已经够用了——这正是它的价值所在。

1.3.3 应用：Euler 法的收敛性

  现在把两个工具结合起来，证明一个完整的结论。

  定理：设 $f$ 关于 $y$ 满足 Lipschitz 条件（常数 $L$），Euler 法的整体误差为 $e_k = y(t_k)-y_k$。则

$$|e_k| \le \frac{h M}{2L}\left(e^{L(t_k-a)}-1\right), \qquad M = \max|y^{\prime\prime}| \tag{1.3.5}$$

  特别地，$e_k = O(h)$——Euler 法收敛，且是 1 阶的。

  证明：

  由 1.1 节的局部截断误差 $T_{k+1} = \frac{h^2}{2}y^{\prime\prime}(\xi_k)$，有 $|T_{k+1}|\le\frac{Mh^2}{2}$。

  而精确解满足 $y(t_{k+1}) = y(t_k)+hf(t_k,y(t_k)) + T_{k+1}$，数值解满足 $y_{k+1}=y_k+hf(t_k,y_k)$。相减：

$$e_{k+1} = e_k + h\left[f(t_k,y(t_k)) - f(t_k,y_k)\right] + T_{k+1}$$

  用 Lipschitz 条件：

$$|e_{k+1}| \le |e_k| + hL|e_k| + \frac{Mh^2}{2} = (1+hL)|e_k| + \frac{Mh^2}{2}$$

  递推并应用离散 Gronwall（把局部误差累加视为常数项）：

$$|e_k| \le \frac{Mh^2}{2}\sum_{j=0}^{k-1}(1+hL)^{k-1-j} = \frac{Mh^2}{2}\cdot\frac{(1+hL)^k-1}{hL}$$

  再用 $(1+hL)^k \le e^{hLk} = e^{L(t_k-a)}$：

$$|e_k| \le \frac{Mh}{2L}\left(e^{L(t_k-a)}-1\right) = O(h) \qquad \blacksquare$$

  注意结论的结构：

  • 误差与 $h$ 成正比（1 阶）
  • 增长率由 $e^{L(t_k-a)}$ 控制——积分区间越长、Lipschitz 常数越大，误差越大
  • 常数中的 $1/L$ 在 $L\to0$ 时会出问题（此时需单独处理，实际用 $\frac{e^{Lt}-1}{L}\to t$ 的极限）

运行结果会显示：

  • Euler 法的"阶"列趋近 1.00
  • 梯形格式的"阶"列趋近 2.00

这就是验证收敛阶的标准做法：每加密一倍网格，误差应该缩小 $2^p$ 倍，取 $\log_2$ 就得到阶数。

如果实测阶数明显低于理论值，通常说明：代码有 bug，或者该网格还不够细（高阶方法的渐近阶要在大 $n$ 时才显现）。

1.5 小结

工具 内容 用途
线性差分方程 特征方程根决定解的行为 判断格式稳定性
根的模 $\le1$ 且模 1 的根单重 解有界 稳定性判据
常数变易法 $y_k=\lambda^ky_0+\sum\lambda^{k-1-j}g_j$ 误差累积估计
Gronwall 不等式 $u_k\le C+\sum\eta_ju_j \Rightarrow u_k\le C e^{\sum\eta_j}$ 误差上界
Euler 收敛性 $ e_k

易错点

  1. 重根时多一个因子 $k$——$|r|=1$ 的重根仍会导致无界增长，这是判断稳定性的关键细节；
  2. Gronwall 给的是上界，不是等号——实际误差通常远小于这个界；
  3. Lipschitz 常数越大，误差界越松，这与物理直觉一致（解对扰动越敏感）；
  4. $1/L$ 在 $L\to0$ 时要取极限，直接代入会得到 $0/0$；
  5. 实测阶数低于理论值是常见的，不一定是代码错——要网格足够细才进入渐近区。
